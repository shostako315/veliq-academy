## 音名

音の高さに付けた名前を音名という。日本の楽典では、ドイツ語、英語、イタリア語（フランス語もほぼ同じ）、日本語の4通りを使い分ける。日本語の音名はハニホヘトイロで、いろは順の仮名を当てたものである。調名には日本語の音名を使い、「ハ長調」「イ短調」と呼ぶ。

| 英語 | ドイツ語 | イタリア語 | フランス語 | 日本語 |
|---|---|---|---|---|
| C | C（ツェー） | Do | Do（Ut） | ハ |
| C♯ | Cis | Do diesis | Do dièse | 嬰ハ |
| D | D | Re | Ré | ニ |
| E♭ | Es | Mi bemolle | Mi bémol | 変ホ |
| E | E | Mi | Mi | ホ |
| F | F | Fa | Fa | ヘ |
| F♯ | Fis | Fa diesis | Fa dièse | 嬰ヘ |
| G | G | Sol | Sol | ト |
| A♭ | As | La bemolle | La bémol | 変イ |
| A | A | La | La | イ |
| B♭ | B | Si bemolle | Si bémol | 変ロ |
| B | H | Si | Si | ロ |

- ドイツ語では、英語の B（ロ）を H と書き、B の一文字は変ロ（B♭）を指す。
- ドイツ語の嬰（♯）は語尾に -is、変（♭）は -es を付ける（Cis、Fis、Des、Ges）。E と A の変音は Es、As と縮める。
- 日本語では♯を「嬰」、♭を「変」と書く。重嬰（𝄪）、重変（𝄫）もある。

## 音程

二つの音の高さの隔たりを音程という。幹音（♯・♭の付かない音）どうしの度数で数え、同じ音を1度、隣を2度とする。同じ度数でも半音の数が違うものがあり、完全・長・短・増・減の語で区別する。

| 音程 | 半音の数 | 例（ハから） |
|---|---|---|
| 完全1度 | 0 | ハ–ハ |
| 短2度 | 1 | ハ–変ニ |
| 長2度 | 2 | ハ–ニ |
| 短3度 | 3 | ハ–変ホ |
| 長3度 | 4 | ハ–ホ |
| 完全4度 | 5 | ハ–ヘ |
| 増4度／減5度 | 6 | ハ–嬰ヘ／ハ–変ト |
| 完全5度 | 7 | ハ–ト |
| 短6度 | 8 | ハ–変イ |
| 長6度 | 9 | ハ–イ |
| 短7度 | 10 | ハ–変ロ |
| 長7度 | 11 | ハ–ロ |
| 完全8度 | 12 | ハ–ハ（1オクターヴ上） |

- 1度・4度・5度・8度は「完全」、2度・3度・6度・7度は「長」「短」で呼ぶ。完全・長の音程を半音広げると「増」、完全・短の音程を半音狭めると「減」になる。
- 音程を上下逆にすること（転回）で、度数は9から引いた数になり、長は短に、増は減に変わり、完全は完全のままである（長3度の転回は短6度）。
- 半音6個の音程は増4度・減5度のどちらにも書け、全音3つ分であることから三全音（トリトヌス）と呼ぶ。

## 音階と調

### 長音階と短音階

長音階は、主音から「全音・全音・半音・全音・全音・全音・半音」の順に並ぶ。ハ長調ではピアノの白鍵だけでできる。

短音階には3つの形がある。

- **自然短音階**：「全・半・全・全・半・全・全」。イ短調では白鍵だけでできる。
- **和声短音階**：自然短音階の第7音を半音上げる。第6音と第7音の間が増2度になる。
- **旋律短音階**：上行で第6音と第7音を半音上げ、下行では自然短音階に戻す。

音階の各音には名前がある。第1音を主音、第4音を下属音、第5音を属音、主音の半音下にある第7音を導音と呼ぶ。

### 調の関係

- **平行調**：同じ調号をもつ長調と短調（ハ長調とイ短調）。短調の主音は長調の主音の短3度下にある。
- **同主調**：同じ主音をもつ長調と短調（ハ長調とハ短調）。
- **属調・下属調**：主音が完全5度上・完全5度下の調（ハ長調に対するト長調・ヘ長調）。

主調、属調、下属調と、それぞれの平行調を合わせた調を近親調と呼ぶ。

### 教会旋法

中世の聖歌の旋律は8つの旋法に分類された。旋法は終止音（フィナリス）と音域で区別され、奇数番号が正格、偶数番号が変格（接頭辞 Hypo- を付ける）である。

| 番号 | 名称 | 終止音 | 種類 |
|---|---|---|---|
| I | ドリア | ニ | 正格 |
| II | ヒポドリア | ニ | 変格 |
| III | フリギア | ホ | 正格 |
| IV | ヒポフリギア | ホ | 変格 |
| V | リディア | ヘ | 正格 |
| VI | ヒポリディア | ヘ | 変格 |
| VII | ミクソリディア | ト | 正格 |
| VIII | ヒポミクソリディア | ト | 変格 |

名称は古代ギリシアの語から取ったが、古代の体系とは意味が一致しない。グラレアヌス（Heinrich Glarean）は『ドデカコルドン』（Dodekachordon, バーゼル, 1547年）で旋法は8つではなく12あるとし、エオリア（イを終止音とする）とイオニア（ハを終止音とする）の正格・変格を加えた。この2つは今日の短音階・長音階に当たる。

今日、白鍵だけで作る7つの旋法は、ハから始めてイオニア、ニからドリア、ホからフリギア、ヘからリディア、トからミクソリディア、イからエオリア、ロからロクリアと呼ばれる。

## 調号と五度圏

調号は、その調で常に変化させる音を、五線の初めにまとめて書いたものである。♯は「ヘ・ハ・ト・ニ・イ・ホ・ロ」の順に、♭は「ロ・ホ・イ・ニ・ト・ハ・ヘ」の順に1つずつ増える。

| 調号 | 長調 | 短調 |
|---|---|---|
| なし | ハ長調 | イ短調 |
| ♯1 | ト長調 | ホ短調 |
| ♯2 | ニ長調 | ロ短調 |
| ♯3 | イ長調 | 嬰ヘ短調 |
| ♯4 | ホ長調 | 嬰ハ短調 |
| ♯5 | ロ長調 | 嬰ト短調 |
| ♯6 | 嬰ヘ長調 | 嬰ニ短調 |
| ♯7 | 嬰ハ長調 | 嬰イ短調 |
| ♭1 | ヘ長調 | ニ短調 |
| ♭2 | 変ロ長調 | ト短調 |
| ♭3 | 変ホ長調 | ハ短調 |
| ♭4 | 変イ長調 | ヘ短調 |
| ♭5 | 変ニ長調 | 変ロ短調 |
| ♭6 | 変ト長調 | 変ホ短調 |
| ♭7 | 変ハ長調 | 変イ短調 |

完全5度上の調に進むごとに♯が1つ増え（または♭が1つ減り）、12回で元に戻る。これを円に並べたものが五度圏である。♯6の嬰ヘ長調と♭6の変ト長調は、平均律の鍵盤では同じ音で、異名同音の調という。

五度圏の図の最初の例は、ディレツキー（Nikolai Diletskii）の『グラマチカ』（1677年）にある。ドイツではハイニヒェン（Johann David Heinichen）が『新しく考案された根本的な手引き』（1711年）で「音楽の円」（Musicalischer Circul）として独自に図示し、『作曲における通奏低音』（1728年）にも載せた。ハイニヒェンは長調の隣に平行短調を置いた。

## 和音

### 三和音

ある音（根音）の上に3度ずつ2つの音を重ねたものを三和音という。下から根音・第3音・第5音と呼ぶ。

| 種類 | 構成（根音からの音程） | 例 |
|---|---|---|
| 長三和音 | 長3度＋完全5度 | ハ・ホ・ト |
| 短三和音 | 短3度＋完全5度 | イ・ハ・ホ |
| 減三和音 | 短3度＋減5度 | ロ・ニ・ヘ |
| 増三和音 | 長3度＋増5度 | ハ・ホ・嬰ト |

長調の音階の各音を根音とする三和音は、ローマ数字で I〜VII と書く。長調では I・IV・V が長三和音、II・III・VI が短三和音、VII が減三和音になる。

### 七の和音

三和音の上にさらに3度を重ね、根音から7度の音を加えたものを七の和音という。最もよく使われるのは属音上の属七の和音（V7）で、ハ長調ではト・ロ・ニ・ヘ。長三和音に短7度を加えた形で、導音（ロ）と第7音（ヘ）の間に三全音を含む。

### 転回形

根音が最低音にある形を基本形という。第3音が最低音にあるものを第1転回形、第5音が最低音にあるものを第2転回形、七の和音では第7音が最低音にあるものを第3転回形と呼ぶ。通奏低音の数字（最低音からの音程）では次のように略記する。

| 形 | 三和音 | 七の和音 |
|---|---|---|
| 基本形 | 5/3（省略） | 7 |
| 第1転回形 | 6 | 6/5 |
| 第2転回形 | 6/4 | 4/3 |
| 第3転回形 | — | 2（4/2） |

### 機能和声——T・S・D

調の中での和音の役割を「機能」と呼ぶ。この語と体系は、リーマン（Hugo Riemann）が『簡約和声学』（Vereinfachte Harmonielehre, 1893年）で導入した。リーマンは数学から「機能」の語を借り、和音の役割をトニカ（T）、ドミナント（D）、サブドミナント（S）の3つにまとめた。ドイツ語圏と北欧・東欧では、この理論が和声教育と分析に今も広く使われている。ドイツ語圏とウィーンの理論はいずれも、ラモー（Jean-Philippe Rameau）の『和声論』（Traité de l'harmonie, 1722年）を一部の土台とする。

長調の主な和音を3つの機能に分けると、一般に次のようになる。

| 機能 | 主な和音（長調） | 役割 |
|---|---|---|
| トニカ（T） | I（代理として VI） | 調の中心。安定 |
| サブドミナント（S） | IV、II | T から離れ、D に向かう |
| ドミナント（D） | V、V7（VII） | T に戻ろうとする |

和音の進行は T→S→D→T、T→D→T、T→S→T を基本の型とする。

## カデンツ（終止）

楽句の終わりの和音の進み方をカデンツ（終止）という。ブリタニカは主な型として次の4つを挙げる。

| 型 | 和音 | 日本語の名称 | 内容 |
|---|---|---|---|
| 正格終止（authentic） | V→I | 全終止 | 楽句の終わりに主和音が来る。上声が順次進行で主音に至り、バスが属音から主音へ跳躍するものが最も強い形（完全終止） |
| 半終止（half） | …→V | 半終止 | 属和音で区切る。緊張が解決されないまま、次の楽句が続く |
| 変格終止（plagal） | IV→I | 変格終止 | キリスト教の賛美歌の終わりの「アーメン」の終止 |
| 偽終止（deceptive） | V→VI | 偽終止 | 正格終止のように始まり、主和音ではなく VI の和音に進む |

## 転調

曲の途中で主調から別の調に移ることを転調という。

- **近親調への転調**：属調、下属調、平行調などへの転調。古典派の曲で最も多い。
- **共通和音による転調**：元の調と新しい調の両方に属する和音を経由して移る。ハ長調からト長調へは、両方に共通する和音（ハ長調の I＝ト長調の IV など）を通り、ト長調の V7（ニ・嬰ヘ・イ・ハ）で新しい調を確定させる。
- **同主調への転調**：ハ長調からハ短調のように、主音を変えずに長短を替える。

新しい調が確定したかどうかは、その調のドミナントからトニカへの終止が現れるかで判断する。

## 拍子とリズム

拍子は、拍のまとまりを分数の形で示す。分母は1拍に当たる音符、分子は1小節の拍の数を表す。

| 種類 | 例 | 内容 |
|---|---|---|
| 単純拍子 | 2/4、3/4、4/4 | 1拍が2つに分かれる |
| 複合拍子 | 6/8、9/8、12/8 | 1拍が付点音符で、3つに分かれる。6/8 は付点4分音符の2拍子 |
| 混合拍子 | 5/4、7/8 | 2と3のまとまりを組み合わせる |

- 4/4 は C、2/2 は縦線を入れた C（アラ・ブレーヴェ）で書くことがある。
- 弱拍や拍の裏に強勢を移すことをシンコペーションという。
- 3拍子の2小節を、3つの2拍のまとまりとして聞かせることをヘミオラという。

## 速度記号と発想記号

17世紀より前の西洋の芸術音楽では、速度の指示はほとんど書かれなかった。拍の速さは、一定の脈、計量記譜の記号、音価の慣習から決まっていた。メルツェル（Johann Nepomuk Maelzel）が1815〜16年にメトロノームを製造して、数値による速度指定が可能になった。メルツェルは1815年12月5日にイギリスで特許を得ている。この装置自体は、ヴィンケル（Dietrich Nikolaus Winkel）が1814年にアムステルダムで作ったものである。楽譜の「M.M.」は「メルツェルのメトロノーム」の略で、♩＝60 は1分間に4分音符60拍を表す。

ベートーヴェンは交響曲第1〜8番のメトロノーム表示を、1817年12月17日の『一般音楽新聞』（Allgemeine musikalische Zeitung）に発表した。

| Lento | 遅く |

| Andante | 歩くほどの中くらいの速さで |

Allegro の原義は「陽気な」「生き生きとした」、Andante は「歩いている」である。

## 楽式

### 二部形式と三部形式

- **二部形式（A–B）**：17世紀から19世紀に多く使われた、ほぼ同じ長さの2つの部分からなる形。18世紀の作品では各部分に反復記号が付き、AABB と演奏される。長調では A が属調に転調して終わり、B が属調から始まって主調に戻る。短調では A が平行長調に向かう。B の後半で A の旋律が主調で戻るものを「再現部をもつ二部形式（rounded binary）」と呼び、D. スカルラッティ（Domenico Scarlatti）のソナタに多い。
- **三部形式（A–B–A）**：対照的な中間部を、最初の部分の再現が囲む。メヌエットとトリオ、スケルツォとトリオはこの形を大きな規模で使う。

### ロンド形式

主題（A）が、対照的な部分をはさんで何度も戻る形。5部の ABACA と7部の ABACABA が一般的である。7部のロンドで、2回目の A–B が展開と転調を伴って C に入り込むものをソナタ・ロンド形式という。18世紀後半から19世紀初めに、ソナタ、交響曲、室内楽、協奏曲の終楽章に多く使われた。フランス・バロックの鍵盤曲のロンドー（ABACAD…と続く）から発展した。

### 変奏曲

主題を、旋律・リズム・和声・対位法・音色などを変えて繰り返す形。主題は8〜32小節が多く、18世紀以前の作品では各変奏が主題の長さと構造を保つ。モーツァルトの《「ああ、ママに言うわ」による12の変奏曲》では、第1変奏が旋律を装飾し、第5変奏がシンコペーションで拍を崩し、第7変奏が和声を下行する5度の連鎖に替え、第8変奏が同主短調に移る。短い低音の反復（オスティナート）の上で変奏を続けるものに、パッサカリアとシャコンヌがある。

### ソナタ形式

18世紀後半から交響曲・ソナタ・室内楽の第1楽章に多く使われた形で、提示部・展開部・再現部からなり、遅い序奏と終結部（コーダ）を伴うことがある。

| 部分 | 内容 |
|---|---|
| 序奏（任意） | 遅いテンポのことが多い |
| 提示部 | 第1主題（主調）→推移（転調）→第2主題（長調の曲では属調、短調の曲では平行長調）→終結部。古典派ではほぼすべて提示部の反復が指示される |
| 展開部 | 提示部の素材を、遠い調を含むさまざまな調で扱う |
| 再現部 | 第1主題・第2主題とも主調で戻る |
| コーダ（任意） | 古典派では任意だが、ロマン派の多くの作品では欠かせない部分となった |

この形の型は、レイハ（Anton Reicha）『高等作曲論』（1826年）、マルクス（Adolf Bernhard Marx）『作曲法』（1845年）、チェルニー（Carl Czerny、1848年）が、主にベートーヴェンのピアノ・ソナタの研究から記述した。「ソナタ形式」の語はマルクスが最初に使った可能性がある。この型は作品が書かれた後に理論家がまとめたものである。

### フーガ

フーガは一つの主題を複数の声部が模倣しながら展開する書法で、決まった構造の形式というより作曲の様式に近い。語はラテン語の fuga（逃走）に由来する。

| 用語 | 内容 |
|---|---|
| 主題（subject、独 Dux） | 冒頭で一つの声部が単独で示す主要な旋律 |
| 応答（answer、独 Comes） | 第2の声部が主題を別の調（多くは属調）で示すもの。主題をそのまま移すものを真正応答、主題の冒頭が属音で始まるときなどに音程を一部変えるものを調的応答という |
| 対主題（countersubject） | 主題や応答に添えられ、後の登場でも繰り返し使われる対旋律。上下を入れ替えても成り立つ転回対位法で書かれる |
| 提示部（exposition） | 全声部が順に主題または応答を示す冒頭の部分 |
| 嬉遊部（episode） | 主題の登場の間にあって、次の調へ転調する経過部分 |
| ストレッタ（stretto） | 一つの声部が主題を終える前に、別の声部が主題を始めて重なる部分 |

中間の主題の登場は近親調で行われ、最後の登場で主調に戻り、しばしばコーダが続く。主音や属音の保続音（オルゲルプンクト）の上で終わり近くを書くこともある。J. S. バッハ（Johann Sebastian Bach）の《平均律クラヴィーア曲集》（第1巻1722年、第2巻1744年）は、各巻が24の長調・短調すべてによる前奏曲とフーガからなる。

## 総譜の読み方

### 楽器の並び

管弦楽の総譜は、上から木管楽器、金管楽器、打楽器、ハープと鍵盤楽器、弦楽器の順に並ぶ。各群の中では高い楽器から低い楽器へ並べる。独奏の声部は、ふつう弦楽器のすぐ上に置く。

| 群 | 上からの並び（例） |
|---|---|
| 木管 | ピッコロ、フルート、オーボエ、イングリッシュ・ホルン、クラリネット、バス・クラリネット、ファゴット、コントラファゴット |
| 金管 | ホルン、トランペット、トロンボーン、テューバ |
| 打楽器 | ティンパニ、その他の打楽器 |
| ハープ・鍵盤 | ハープ、チェレスタ、ピアノ、オルガン |
| 独奏・合唱 | 独奏楽器、独唱、合唱 |
| 弦 | 第1ヴァイオリン、第2ヴァイオリン、ヴィオラ、チェロ、コントラバス |

金管ではホルンがトランペットより上に置かれ、音域の高低の順の例外になっている。

### 音部記号

- ト音記号：ヴァイオリン、フルート、オーボエ、クラリネット、トランペットなど
- ハ音記号（アルト記号）：ヴィオラ
- ハ音記号（テノール記号）：チェロ、ファゴット、トロンボーンの高音域
- ヘ音記号：チェロ、コントラバス、ファゴット、トロンボーン、テューバ、ティンパニ

### 移調楽器の記譜

楽譜に書かれた音と実際に鳴る音が違う楽器を移調楽器という。「B♭管」「in F」などの表記は、楽譜のハ（C）を吹いたときに鳴る音を表す。

| 楽器 | 楽譜のハに対して鳴る音 |
|---|---|
| クラリネット（B♭管） | 長2度下の変ロ |
| クラリネット（A管） | 短3度下のイ |
| クラリネット（E♭管） | 短3度上の変ホ |
| バス・クラリネット（B♭管） | 長9度下の変ロ |
| ホルン（F管） | 完全5度下のヘ |
| トランペット（B♭管） | 長2度下の変ロ |
| イングリッシュ・ホルン（F管） | 完全5度下のヘ |
| アルト・サクソフォン（E♭管） | 長6度下の変ホ |
| テナー・サクソフォン（B♭管） | 長9度下の変ロ |
| ピッコロ、チェレスタ、シロフォン | 1オクターヴ上 |
| グロッケンシュピール | 2オクターヴ上 |
| コントラバス、コントラファゴット、ギター | 1オクターヴ下 |

- ホルンをヘ音記号で書く場合、古い記譜では実音が5度下でなく4度上になるものがある。どちらの書き方かは作曲家によって異なる。
- 20世紀初めから、総譜全体を実音で書く作曲家も現れた。プロコフィエフ（Sergei Prokofiev）のピアノ協奏曲第1番 変ニ長調がその例である。
- 替え管を用いた時代のホルンの楽譜は、すべてハを基音とするように書かれ、替え管によって一つの楽器がほぼどの調の移調楽器にもなった。

総譜をピアノで読むことは、移調楽器の声部を実音に直し、複数の音部記号を同時に読み替える作業を伴う。

### 総譜を読む手順

指揮の学習で一般に行われる総譜の読み方は、次のような順序をとる。

1. 冒頭の頁で、楽器編成、各楽器の管の調（移調）、音部記号、調号と拍子を確かめる。
2. 楽曲全体の形式（提示部・展開部・再現部などの区切り、主題の位置）と調の移り変わりを把握する。
3. 楽句の区切りとカデンツの位置を確かめ、和声の機能（T・S・D）を追う。
4. 旋律、対旋律、和声を担う声部、低音を声部ごとに分けて読み、どの楽器が何を受け持つかを確かめる。
5. 速度記号、メトロノーム表示、強弱、奏法の指示を、楽器ごとに書き分けられている箇所も含めて確かめる。
