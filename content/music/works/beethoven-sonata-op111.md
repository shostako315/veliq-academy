> 要点
> - ベートーヴェンが**最後に書いたピアノ・ソナタ**。作品109・110とともにベルリンの出版者シュレージンガーに提供された3曲の3曲目で、1821年秋から集中して書かれ、**1822年春**に完成した。
> - **2楽章構成**。第1楽章はハ短調の序奏付きソナタ形式、第2楽章はハ長調の主題《アリエッタ》と変奏。
> - **1823年4月にパリ**のモーリス・シュレージンガー、**5月にベルリン**のアドルフ・マルティン・シュレージンガーから出版された。献呈は**ルドルフ大公**。
> - 第2楽章の第1〜第3変奏は、拍子を9/16、6/16、12/32と変えていく。

## 成立

### 3曲のソナタの約束

ヘンレ版（2026年）の序文によれば、ベートーヴェン（Ludwig van Beethoven）は1820年4月30日、まだ書き上がっていない3曲のピアノ・ソナタをベルリンの出版者アドルフ・マルティン・シュレージンガー（Adolph Martin Schlesinger）に提供した。[（Henle 序文）](https://www.henle.de/media/12/9a/ae/1781773221/HN_1118_Vorwort.pdf)ロサンゼルス・フィルハーモニックのジョン・ヘンケン（John Henken）の解説は、1820年5月にベートーヴェンが3曲を書くことを約束したとしている。1曲目の作品109は1820年秋に完成したが、残る2曲は、病気とミサ・ソレムニスの作業のために中断された。[（LA Phil / Hollywood Bowl）](https://www.hollywoodbowl.com/musicdb/pieces/3553/piano-sonata-no-32-in-c-minor-op-111)

ボンのベートーヴェン・ハウスは、作品109〜111を、ベートーヴェンが三部作として構想し、シュレージンガーに提供したものとしている。ベートーヴェンは1821年、遅れの理由の一つに体調を挙げており、1821年夏には重い黄疸を患った。[（Beethoven-Haus Bonn）](https://www.beethoven.de/en/work/view/5820734521737216)

### 作曲の時期

ベートーヴェン・ハウスの作品データは、作曲時期を1821年末から1822年初めとしている。スケッチによれば、ベートーヴェンは1821年夏に作品110に着手し、1821年秋には作品111に集中した。2曲の作業はスケッチ帳の上で重なっている。作品111は作品110の少し後、1822年春に完成した。[（Beethoven-Haus Bonn）](https://www.beethoven.de/en/work/view/5820734521737216)ピティナ・ピアノ曲事典の岡田安樹浩の解説も、作品110と並行して1821年から1822年にかけて作曲されたとしている。[（ピティナ・ピアノ曲事典）](https://enc.piano.or.jp/en/musics/438)

### 自筆譜

ベートーヴェン・ハウスは、第1楽章の自筆譜（所蔵記号 BH 71）と、作曲者が目を通した筆写譜（HCB Mh 54）を所蔵している。同館のデータには、ソナタ全体の自筆譜は挙げられていない。[（Beethoven-Haus Bonn）](https://www.beethoven.de/en/work/view/5820734521737216)

### 出版と献呈

原版は1823年4月、パリのモーリス・シュレージンガー（Maurice Schlesinger）から出た。1か月後の1823年5月にはベルリンのアドルフ・マルティン・シュレージンガーからも出版されたが、誤りが多く、ベートーヴェンはウィーンのアントン・ディアベッリ（Anton Diabelli）に訂正版を出させた。1823年6月3日頃には、ヴェンツェル・シュレンマー（Wenzel Schlemmer）とモーリス・シュレージンガーのそれぞれに誤りの一覧を送っている。[（Beethoven-Haus Bonn）](https://www.beethoven.de/en/work/view/5820734521737216)ヘンレ版の序文によれば、シュレージンガーは作品109〜111をまとめて出版し、国境を越えて権利を確保しようとした。[（Henle 序文）](https://www.henle.de/media/12/9a/ae/1781773221/HN_1118_Vorwort.pdf)

献呈先はルドルフ大公（Erzherzog Rudolph）である。[（Beethoven-Haus Bonn）](https://www.beethoven.de/en/work/view/5820734521737216)英国の版はアントーニエ・ブレンターノ（Antonie Brentano）に献呈された。[（LA Phil / Hollywood Bowl）](https://www.hollywoodbowl.com/musicdb/pieces/3553/piano-sonata-no-32-in-c-minor-op-111)

## 編成と演奏時間

ピアノ独奏。

ピティナ・ピアノ曲事典は、演奏時間を約26分30秒（第1楽章約8分30秒、第2楽章約18分）としている。[（ピティナ・ピアノ曲事典）](https://enc.piano.or.jp/en/musics/438)アルトゥル・シュナーベル（Artur Schnabel）の1932年の録音は26分2秒である。[（MusicWeb International）](https://www.musicweb-international.com/classrev/2006/Dec06/Beethoven_Schnabel_5628802.htm)

## 楽章ごとの聴きどころ

ヘンケンは、このソナタの2つの楽章が、ソナタ形式と変奏形式、速いと遅い、短調と長調の対をなすとしている。[（LA Phil / Hollywood Bowl）](https://www.hollywoodbowl.com/musicdb/pieces/3553/piano-sonata-no-32-in-c-minor-op-111)

### 第1楽章 Maestoso – Allegro con brio ed appassionato

ハ短調、4分の4拍子。Maestoso の序奏をもつソナタ形式。ピティナ・ピアノ曲事典による区分は次のとおりである。[（ピティナ・ピアノ曲事典）](https://enc.piano.or.jp/en/musics/438)

| 部分 | 小節 | 内容 |
|---|---|---|
| 序奏 | 1〜18 | Maestoso、付点リズム |
| 提示部 | 19〜 | 第1主題（19〜）、主題の確保（29〜）、推移（35〜）、変イ長調の第2主題（50〜）、終結への推移（56〜）、小結尾（67〜69） |
| 展開部 | 70〜 | |
| 再現部 | 92〜 | 第1主題（92〜）、ハ長調の第2主題（116〜）、ヘ短調の挿入（124〜）、推移（132〜） |
| コーダ | 145〜 | ピカルディの3度で終わる |

ヘンケンは、付点リズムの序奏、バッハのインヴェンションに似たポリフォニックな書法、フーガ風の展開部を挙げ、主部はハ長調の静かなコーダで閉じて第2楽章を導くと書いている。[（LA Phil / Hollywood Bowl）](https://www.hollywoodbowl.com/musicdb/pieces/3553/piano-sonata-no-32-in-c-minor-op-111)

### 第2楽章 Arietta. Adagio molto semplice e cantabile

ハ長調。主題《アリエッタ》と変奏。主題は16小節で、8小節ずつ反復される（反復を含めて32小節）。主題の後半はイ短調に向かう。[（ピティナ・ピアノ曲事典）](https://enc.piano.or.jp/en/musics/438)主題には「きわめて素朴に、歌うように」（molto semplice e cantabile）と書かれている。

変奏ごとに拍子が変わる。ピティナ・ピアノ曲事典の区分は次のとおりである。[（ピティナ・ピアノ曲事典）](https://enc.piano.or.jp/en/musics/438)

| 部分 | 小節 | 拍子 |
|---|---|---|
| 主題 | 1〜16 | |
| 第1変奏 | 17〜 | 9/16 |
| 第2変奏 | 33〜 | 6/16 |
| 第3変奏 | 48〜 | 12/32 |
| 第4変奏 | 65〜 | 9/16 |
| ハ短調への推移 | 120〜 | |
| 第5変奏 | 131〜 | |
| コーダ | 160〜 | 長いトリルを含む |

シャーロッツヴィル室内楽音楽祭のティモシー・サマーズ（Timothy Summers）の解説は、第2変奏に dolce、第3変奏に l'istesso tempo（同じ速さで）と12/32拍子が書かれていること、第4変奏の冒頭の音型がトリルに囲まれていることを示している。サマーズは変奏の数を5つとしている。[（Charlottesville Chamber Music Festival）](https://www.cvillechambermusic.org/op-111-analysis.html)

ヘンケンによれば、最初の3つの変奏で動きが増していき、その後、音楽はハ長調から遠い変ホ長調に上る。変ホ長調は、第1楽章のハ短調には近い調である。トリルを経てハ長調に戻り、冒頭の素朴な主題が戻ってくる。[（LA Phil / Hollywood Bowl）](https://www.hollywoodbowl.com/musicdb/pieces/3553/piano-sonata-no-32-in-c-minor-op-111)

## 演奏史と解釈

### 出版直後の訂正

ベートーヴェン・ハウスが整理する書簡からは、出版直後の1823年5〜6月に、ベートーヴェンが誤りの一覧をシュレンマーと出版者に送り、ディアベッリに訂正版を出させたことがわかる。1823年5月末か6月初めのディアベッリ宛の書簡は、ヘッツェンドルフから送られ、髪の房が添えられていた。題の訂正を書いた日付のない紙片も残っている。[（Beethoven-Haus Bonn）](https://www.beethoven.de/en/work/view/5820734521737216)

### 代表的な録音

- アルトゥル・シュナーベル。1932年、ロンドンのアビー・ロード第3スタジオで録音。シュナーベルのベートーヴェン録音の一部として、EMI Classics「Great Recordings of the Century」（5 62880 2）で出ている。[（MusicWeb International）](https://www.musicweb-international.com/classrev/2006/Dec06/Beethoven_Schnabel_5628802.htm)
- マウリツィオ・ポリーニ（Maurizio Pollini）。ドイツ・グラモフォンに作品109〜111のスタジオ録音があり、2020年には同じ3曲のライヴ録音が同社から出た（483 8250GH）。グラモフォン誌（2020年4月）のジェド・ディストラー（Jed Distler）は、新しい録音を以前のスタジオ録音と比べ、新録音のほうが対比がはっきりしているとした。[（Gramophone）](https://gramophone.co.uk/review/beethoven-piano-sonatas-nos-30-32-maurizio-pollini)

## もっと深く

- **2楽章の構成**：ヘンケンは、2楽章の構成を、ベートーヴェンが以前のソナタで用いた形に戻ったものとしている。[（LA Phil / Hollywood Bowl）](https://www.hollywoodbowl.com/musicdb/pieces/3553/piano-sonata-no-32-in-c-minor-op-111)
- **『ファウストゥス博士』**：トーマス・マン（Thomas Mann）の小説『ファウストゥス博士』（Doktor Faustus）第8章で、音楽教師クレッチュマーは「なぜベートーヴェンはピアノ・ソナタ作品111に第3楽章を書かなかったか」という題で講演し、「第3楽章？ この別れの後に、新たに始めるのか？」と語る。[（Projekt Gutenberg-DE）](https://projekt-gutenberg.org/authors/thomas-mann/books/doktor-faustus/chapter/9)
- **三部作としての作品109〜111**：ベートーヴェン・ハウスは3曲を計画された三部作としている。ヘンレ版の序文は、ベートーヴェンがまだ書き上げていない段階で3曲をまとめて提供したことを記している。[（Henle 序文）](https://www.henle.de/media/12/9a/ae/1781773221/HN_1118_Vorwort.pdf)
- **自筆譜の所在**：ベートーヴェン・ハウスには第1楽章の自筆譜（BH 71）と、作曲者が確認した筆写譜（HCB Mh 54）がある。[（Beethoven-Haus Bonn）](https://www.beethoven.de/en/work/view/5820734521737216)
- **版の系統**：パリ版（1823年4月）、ベルリン版（1823年5月）、ディアベッリによる訂正版があり、その後もライデスドルフ（版番号1277）などから再刊された。ベートーヴェン・ハウスのデータはパリのシュレージンガー版を原版としている。[（Beethoven-Haus Bonn）](https://www.beethoven.de/en/work/view/5820734521737216)
