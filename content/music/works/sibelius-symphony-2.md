## 成立

### カルペランとイタリア行き

1900年3月、シベリウスのもとに「X.」と署名された手紙が届いた。差出人は男爵アクセル・カルペラン（Axel Carpelan）で、シベリウスにイタリアへ行くよう勧めていた。[（Breitkopf 序文 / Kilpeläinen）](https://www.breitkopf.com/assets/pdf/6293_PDF_PB5376_NW.pdf)ストックホルム・フィルの解説を書いたイルッカ・オラモ（Ilkka Oramo）によれば、同じ手紙はパリでの演奏会のための序曲を求め、その題名として「フィンランディア」を提案していた。[（Konserthuset / Oramo）](https://integration.konserthuset.se/en/about-us/our-operation/festivals/grande-finale/liner-notes-and-curious-facts/the-symphonies/symphony-no.-2)カルペランは、シベリウスの音楽には地中海の明るさが必要だと考え、旅費を集めた。シベリウスは5000マルクを受け取ったが、まずその一部で借金を返した。[（sibelius.fi, 1900–1902）](https://sibelius.klubi.fi/english/elamankaari/sib_lapimurto.htm)旅費を出した後援者はアクセル・タム（Axel Tamm）である。[（Breitkopf 序文 / Kilpeläinen）](https://www.breitkopf.com/assets/pdf/6293_PDF_PB5376_NW.pdf)

この年の2月13日、シベリウス夫妻は娘キルスティをチフスで亡くしていた。妻アイノは深い抑うつに陥り、シベリウスの飲酒は危険なものになっていた。[（sibelius.fi, 1900–1902）](https://sibelius.klubi.fi/english/elamankaari/sib_lapimurto.htm)

### ベルリン、ラパッロ、ローマ、フィレンツェ

シベリウスは1900年10月27日にフィンランドを発ち、家族とともにベルリンで約2か月を過ごし、1901年1月末にイタリアのラパッロ（Rapallo）に着いた。[（Breitkopf 序文 / Kilpeläinen）](https://www.breitkopf.com/assets/pdf/6293_PDF_PB5376_NW.pdf)ベルリンでは夫妻でリストのオラトリオ《キリスト》を聴いている。ベルリン滞在で資金は1月までに尽き、シベリウスはフィンランドから追加の金を借りた。[（sibelius.fi, 1900–1902）](https://sibelius.klubi.fi/english/elamankaari/sib_lapimurto.htm)

ラパッロでシベリウスは山の上の別荘に仕事部屋を借り、多くの楽想を書き留めた。[（BIS-CD-862 / Barnett）](https://eclassical.textalk.se/shop/art33/BIS-862_booklet_x.pdf-15896d.pdf)ジャン・パウル（Jean Paul）の小説『生意気盛り』（Flegeljahre）の真昼の静けさの一節に触発され、シベリウスはドン・ジュアンと死の場面の筋書きを書いた。その紙の裏に、のちに第2楽章の主題になるニ短調のファゴットの旋律がスケッチされている。オラモはこの紙の日付を1901年2月19日としている。[（Konserthuset / Oramo）](https://integration.konserthuset.se/en/about-us/our-operation/festivals/grande-finale/liner-notes-and-curious-facts/the-symphonies/symphony-no.-2)アンドルー・バーネット（Andrew Barnett）は、2月11日にシベリウスが別荘をドン・ジュアンの館に見立て、ドン・ジュアンの主題を死と結びつけるメモを書いたとしている。この段階では、計画中の管弦楽のための4つの交響詩《祝祭》のための素材だった。[（BIS-CD-862 / Barnett）](https://eclassical.textalk.se/shop/art33/BIS-862_booklet_x.pdf-15896d.pdf)

イタリアでの生活は難しかった。資金は乏しく、娘ルートは重い病気にかかり、夫婦の仲も危うくなった。3月、シベリウスは予告なしにローマへ出た。[（BIS-CD-862 / Barnett）](https://eclassical.textalk.se/shop/art33/BIS-862_booklet_x.pdf-15896d.pdf)ローマでは《ポホヨラの娘》と《夜の騎行と日の出》の最初のスケッチが書かれている。[（sibelius.fi, 1900–1902）](https://sibelius.klubi.fi/english/elamankaari/sib_lapimurto.htm)約2か月後、フィレンツェで「Christus」と書かれたハ長調の主題が書かれ、これが第2楽章の第2主題（Andante sostenuto）になった。[（Konserthuset / Oramo）](https://integration.konserthuset.se/en/about-us/our-operation/festivals/grande-finale/liner-notes-and-curious-facts/the-symphonies/symphony-no.-2)シベリウスはダンテの『神曲』による作品も考えていた。[（BIS-CD-862 / Barnett）](https://eclassical.textalk.se/shop/art33/BIS-862_booklet_x.pdf-15896d.pdf)

イタリアでのスケッチは、はじめは交響曲のためではなく、《祝祭》や管弦楽の幻想曲のためのもので、ドン・ジュアン、キリスト、ダンテの『神曲』に関わっていた。エンマ・ヤルネフェルトの結核が、死と煉獄を主題とするスケッチに影響した可能性もある。[（Breitkopf 序文 / Kilpeläinen）](https://www.breitkopf.com/assets/pdf/6293_PDF_PB5376_NW.pdf)オラモは、ほかの楽章について標題的な構想を示す証拠は無いとしている。[（Konserthuset / Oramo）](https://integration.konserthuset.se/en/about-us/our-operation/festivals/grande-finale/liner-notes-and-curious-facts/the-symphonies/symphony-no.-2)

### フィンランドでの作曲（1901年）

1901年3月6日、シベリウスはイタリアから「仕事はうまくいっている」（Ich arbeite gut）と書き、交響曲はフィンランドで仕上げるつもりだと伝えた。5月に一家はフィンランドに戻った。[（Breitkopf 序文 / Kilpeläinen）](https://www.breitkopf.com/assets/pdf/6293_PDF_PB5376_NW.pdf)シベリウスはその後ベルリンとハイデルベルクへ行き、ハイデルベルクで《トゥオネラの白鳥》と《レンミンカイネンの帰郷》を指揮した。夏のロホヤ（Lohja）で、ダンテによる交響詩の計画はやめた。[（BIS-CD-862 / Barnett）](https://eclassical.textalk.se/shop/art33/BIS-862_booklet_x.pdf-15896d.pdf)

手紙からは、作曲の進み具合が次のようにたどれる。[（Breitkopf 序文 / Kilpeläinen）](https://www.breitkopf.com/assets/pdf/6293_PDF_PB5376_NW.pdf)

- 1901年8月27日（ロホヤから）：「わたしは芸術のために厳しい戦いをしなければならなかった」（Ich musste einen harten Kampf um meine Kunst bestehen）。作品をカルペランに献呈したいと書く。
- 9月12日：アドルフ・パウル（Adolf Paul）に、順調に進んでいると知らせる。
- 10月初め：カルペランがケラヴァのシベリウスを訪ねた。カルペランは従姉妹への手紙で、計画中の作品を5楽章の交響曲と書き、約20作品のスケッチがあると伝えた。
- 11月9日：書簡に初めて「symfoni II」の題が現れる。シベリウスはこの作品を「苦しみの子」（Smerzens Kind）と呼んだ。
- 12月2日：年末に予定していた初演を、多くの手直しのために1月に延ばす。
- 12月29日：午前11時から翌朝5時まで仕事をしていると報告。
- 1902年1月8日：写譜師がオーケストラ・パートを書いていると葉書で知らせる。

初演は結局3月にずれ込んだ。[（Fort Worth Symphony / Meltzer）](https://fwsymphony.org/program-notes/sibelius-jean-symphony-no-2-in-d-major-opus-43-1902)

### 初演（1902年3月8日）

初演は1902年3月8日、ヘルシンキ大学の大講堂で、作曲者の指揮による。[（Breitkopf 序文 / Kilpeläinen）](https://www.breitkopf.com/assets/pdf/6293_PDF_PB5376_NW.pdf)管弦楽はヘルシンキ・フィルハーモニー協会の楽団である。[（sibelius.fi, Symphony No. 2）](https://www.sibelius.klubi.fi/english/musiikki/ork_sinf_02.htm)同じ演奏会では、序曲イ短調（JS 144）と、女声合唱と管弦楽のための《即興曲》作品19の初稿も演奏された。シベリウスは初演で3つの月桂冠を受けた。[（Breitkopf 序文 / Kilpeläinen）](https://www.breitkopf.com/assets/pdf/6293_PDF_PB5376_NW.pdf)

演奏会は3月10日、14日、16日に繰り返され、いずれも満席だった。最後の回は消防団会館（Palokunnantalo）で行われた。[（Breitkopf 序文 / Kilpeläinen）](https://www.breitkopf.com/assets/pdf/6293_PDF_PB5376_NW.pdf)[（BIS-CD-862 / Barnett）](https://eclassical.textalk.se/shop/art33/BIS-862_booklet_x.pdf-15896d.pdf)批評家オスカル・メリカント（Oskar Merikanto）は、この交響曲が「最も大胆な期待さえ上回った」と書いた。[（sibelius.fi, 1900–1902）](https://sibelius.klubi.fi/english/elamankaari/sib_lapimurto.htm)

4月2日、カルペランは、イタリア旅行の後援者が満足していると書いた。同じ4月2日、ヘルシングフォシュ新音楽商会（Helsingfors Nya Musikhandel）との出版契約が結ばれ、写譜師エルンスト・レーリヒ（Ernst Röllig）は4月11日までに写しを仕上げた。[（Breitkopf 序文 / Kilpeläinen）](https://www.breitkopf.com/assets/pdf/6293_PDF_PB5376_NW.pdf)

### 改訂（1902〜1903年）

シベリウスは第2楽章に迷いがあった。1902年8月にはアイノに、第2楽章が「少し気がかりだ」（macht mir ein wenig Sorgen）と書いている。9月には出版社が、自筆の総譜がヘルシンキにあると知らせており、手直しのために戻されていたとみられる。1903年1月には総譜とパート譜がドイツのリヒャルト・シュトラウス（Richard Strauss）の手元にあった。シュトラウスは1903年2月16日にベルリンのクロル・オーパーでこの曲を指揮する予定だったが、演奏は実現しなかった。編者のカリ・キルペライネン（Kari Kilpeläinen）は、改訂の大半はシュトラウスが総譜を受け取る1903年1月より前に終わっていたと推定している。[（Breitkopf 序文 / Kilpeläinen）](https://www.breitkopf.com/assets/pdf/6293_PDF_PB5376_NW.pdf)

### ストックホルムと各地での演奏

改訂後の形での最初の演奏は、1903年11月10日、ストックホルムの王立音楽アカデミーの大ホールで、アルマス・ヤルネフェルト（Armas Järnefelt）の指揮による。ストックホルム・フィルハーモニー管弦楽団が演奏した最初のシベリウスの管弦楽作品であった。[（Konserthuset / Oramo）](https://integration.konserthuset.se/en/about-us/our-operation/festivals/grande-finale/liner-notes-and-curious-facts/the-symphonies/symphony-no.-2)それから約2か月のうちに、シカゴ（セオドア・トマス）、ハンブルク（マックス・フィードラー）、サンクトペテルブルク（ロベルト・カヤヌス）で演奏された。[（Breitkopf 序文 / Kilpeläinen）](https://www.breitkopf.com/assets/pdf/6293_PDF_PB5376_NW.pdf)

### 出版と献呈

1903年6月か7月に、ごく少部数の試し刷りが出た。7月8日、シベリウスはブライトコプフ＆ヘルテル社に、総譜2部を「できるだけ早く」求めている。[（Breitkopf 序文 / Kilpeläinen）](https://www.breitkopf.com/assets/pdf/6293_PDF_PB5376_NW.pdf)ニューヨークのモーガン図書館は、ブライトコプフ＆ヘルテル社の印刷による未校正の刷り（Bürstenabzug）を所蔵している。表紙には赤インクで、印刷された部と引き換えにライプツィヒのブライトコプフ＆ヘルテル社に返却すべきことが書かれ、1903年6月23日の日付と社印がある。[（Morgan Library 85444）](https://www.themorgan.org/music-manuscripts-and-printed-music/85444)

初版は1903年9月、ヘルシングフォシュ新音楽商会（K. G. ファツェル＆ヴェステルンド）から出た。総譜の版番号は Part. B. 1784、パート譜は Orch. B. 1610/12 である。1905年にブライトコプフ＆ヘルテル社が出版権を得た。[（Breitkopf 序文 / Kilpeläinen）](https://www.breitkopf.com/assets/pdf/6293_PDF_PB5376_NW.pdf)

作品はカルペランに献呈された。初刷りでは名前が「Carpelon」と誤植され、シベリウスは献辞の文言の「野暮ったいドイツ風」（dicke deutsche Art）を嫌って刷り直させた。シベリウスはのちに、訂正した部をカルペランに贈っている。[（Breitkopf 序文 / Kilpeläinen）](https://www.breitkopf.com/assets/pdf/6293_PDF_PB5376_NW.pdf)カルペランとシベリウスの交流は1900年に始まり、カルペランは1919年3月に亡くなった。[（BIS-CD-862 / Barnett）](https://eclassical.textalk.se/shop/art33/BIS-862_booklet_x.pdf-15896d.pdf)

## 編成と演奏時間

フルート2、オーボエ2、クラリネット2、ファゴット2、ホルン4、トランペット3、トロンボーン3、テューバ、ティンパニ、弦五部。[（IMSLP）](https://www.imslp.org/wiki/Symphony_No.2,_Op.43_(Sibelius,_Jean))

演奏時間は約43〜44分。[（Konserthuset / Oramo）](https://integration.konserthuset.se/en/about-us/our-operation/festivals/grande-finale/liner-notes-and-curious-facts/the-symphonies/symphony-no.-2)[（Fort Worth Symphony / Meltzer）](https://fwsymphony.org/program-notes/sibelius-jean-symphony-no-2-in-d-major-opus-43-1902)ヘルシンキ大学図書館（現フィンランド国立図書館）の印刷譜（HUL 1787）には、シベリウスが鉛筆で各楽章の所要時間を書き込んでおり、第1楽章9分、第2楽章14分、第4楽章20分となっている。[（Breitkopf 序文 / Kilpeläinen）](https://www.breitkopf.com/assets/pdf/6293_PDF_PB5376_NW.pdf)

## 楽章ごとの聴きどころ

### 第1楽章 Allegretto（ニ長調、6/4拍子）

弦の穏やかな歌で始まり、上行する3音の和音の動きが全曲の動機になる。[（sibelius.fi, Symphony No. 2）](https://www.sibelius.klubi.fi/english/musiikki/ork_sinf_02.htm)木管の音型が4本のホルンに受け継がれる。[（Aspen / Ledbetter）](https://www.aspenmusicfestival.com/program_notes/view/sibelius-symphony-no.-2-in-d-major-op.-43/25937)短い楽想が、間に沈黙をはさみながら次々に示される。[（TŌN / Brija）](https://ton.bard.edu/jean-sibelius-symphony-no-2)シベリウスは1907年、グスタフ・マーラーに、すべての動機の間に内的なつながりを生む「深い論理」について語っている。[（BIS-CD-862 / Barnett）](https://eclassical.textalk.se/shop/art33/BIS-862_booklet_x.pdf-15896d.pdf)

シベリウスはのちに、指揮者ユッシ・ヤラス（Jussi Jalas）やトール・マン（Tor Mann）に、この楽章の主題を遅く弾きすぎないこと、「カヤヌス流に遅く」はしないことを注意している。こうした発言は総譜には反映されていない。[（Breitkopf 序文 / Kilpeläinen）](https://www.breitkopf.com/assets/pdf/6293_PDF_PB5376_NW.pdf)

### 第2楽章 Tempo andante, ma rubato

チェロとコントラバスのピッツィカートで始まる。[（sibelius.fi, Symphony No. 2）](https://www.sibelius.klubi.fi/english/musiikki/ork_sinf_02.htm)その上にファゴットが、ラパッロで死と結びつけて書かれたニ短調の主題を吹く。これに、フィレンツェで「Christus」と書かれた主題が答える。[（Konserthuset / Oramo）](https://integration.konserthuset.se/en/about-us/our-operation/festivals/grande-finale/liner-notes-and-curious-facts/the-symphonies/symphony-no.-2)楽章は2つのピッツィカートの打撃で終わる。[（sibelius.fi, Symphony No. 2）](https://www.sibelius.klubi.fi/english/musiikki/ork_sinf_02.htm)

指揮者トーマス・ビーチャム（Thomas Beecham）は、この楽章の冒頭を、管弦楽の低音域を「愛想のよいサナダムシのように」さまよう、と評した。[（BIS-CD-862 / Barnett）](https://eclassical.textalk.se/shop/art33/BIS-862_booklet_x.pdf-15896d.pdf)第2楽章の手稿には「たそがれ時にわが城に座っていると、客が入ってくる」という書き込みがあると伝えられる。[（TŌN / Brija）](https://ton.bard.edu/jean-sibelius-symphony-no-2)改訂の過程でシベリウスが最も迷ったのはこの楽章であり、批評家アラリク・ウッグラ（Alarik Uggla）は新聞でこの楽章を短くすることを提案している。[（Breitkopf 序文 / Kilpeläinen）](https://www.breitkopf.com/assets/pdf/6293_PDF_PB5376_NW.pdf)

### 第3楽章 Vivacissimo

激しく始まり、フルートの穏やかな楽想を経て、オーボエが同じ音を9回繰り返すやさしいトリオになる。[（sibelius.fi, Symphony No. 2）](https://www.sibelius.klubi.fi/english/musiikki/ork_sinf_02.htm)繰り返される音は変ロである。[（TŌN / Brija）](https://ton.bard.edu/jean-sibelius-symphony-no-2)トリオは12/4拍子で書かれている。[（Aspen / Ledbetter）](https://www.aspenmusicfestival.com/program_notes/view/sibelius-symphony-no.-2-in-d-major-op.-43/25937)スケルツォが戻った後、上行する3音の音階が切れ目なく終楽章へ導く。[（TŌN / Brija）](https://ton.bard.edu/jean-sibelius-symphony-no-2)

### 第4楽章 Finale. Allegro moderato（ニ長調、3/2拍子）

英雄的な主要主題に、トランペットが上行する3音の動機で答える。[（sibelius.fi, Symphony No. 2）](https://www.sibelius.klubi.fi/english/musiikki/ork_sinf_02.htm)第3楽章から切れ目なく続くため、交響曲は前半2楽章と後半2楽章の2つの部分に分かれる形になる。[（Aspen / Ledbetter）](https://www.aspenmusicfestival.com/program_notes/view/sibelius-symphony-no.-2-in-d-major-op.-43/25937)

副主題は嘆きの歌で、アイノ・シベリウスは、これがアイノの姉妹エリ・ヤルネフェルトの思い出のために書かれたと語った。[（BIS-CD-862 / Barnett）](https://eclassical.textalk.se/shop/art33/BIS-862_booklet_x.pdf-15896d.pdf)コーダの主題は、1899年6月、ルオヴェシのアクセリ・ガッレン＝カッレラ（Akseli Gallen-Kallela）の家の印象として着想されたらしい。公式サイトは、同じ1899年夏、ガッレン＝カッレラの息子の洗礼式でシベリウスが終楽章の主題を即興で弾いたという話を伝えている。[（BIS-CD-862 / Barnett）](https://eclassical.textalk.se/shop/art33/BIS-862_booklet_x.pdf-15896d.pdf)[（sibelius.fi, Symphony No. 2）](https://www.sibelius.klubi.fi/english/musiikki/ork_sinf_02.htm)

同じくヤラスやマンへの発言でシベリウスは、終楽章のある箇所を「星空の下で」、「ちっぽけなもの」（Bagatelle）ではないと説明し、終わり近くを「とても遅く、Tempo I ではなく」と指示している。[（Breitkopf 序文 / Kilpeläinen）](https://www.breitkopf.com/assets/pdf/6293_PDF_PB5376_NW.pdf)

## 演奏史と解釈

### 「解放の交響曲」

ヘルシンキ・フィルハーモニー管弦楽団の創設者で指揮者のロベルト・カヤヌス（Robert Kajanus）は、1902年に『ヒューヴドスタッズブラーデット』紙に書いた文章で、アンダンテを「現在のあらゆる不正に対する、最も打ちのめされた抗議」と呼び、終楽章に慰めと楽観の明るい気分を聴いた。[（sibelius.fi, Symphony No. 2）](https://www.sibelius.klubi.fi/english/musiikki/ork_sinf_02.htm)[（BIS-CD-862 / Barnett）](https://eclassical.textalk.se/shop/art33/BIS-862_booklet_x.pdf-15896d.pdf)この読み方は、ニコライ2世によるロシア化政策（1899〜1905年）のもとで、交響曲を民族の独立の象徴とする受け取り方を広めた。[（Konserthuset / Oramo）](https://integration.konserthuset.se/en/about-us/our-operation/festivals/grande-finale/liner-notes-and-curious-facts/the-symphonies/symphony-no.-2)イルマリ・クローン（Ilmari Krohn）は1940年代半ばにこれを「解放の交響曲」と呼んだ。[（BIS-CD-862 / Barnett）](https://eclassical.textalk.se/shop/art33/BIS-862_booklet_x.pdf-15896d.pdf)

シベリウス自身はこうした標題的な読み方を一貫して退け、自分の交響曲を純粋な絶対音楽と呼んだ。[（Konserthuset / Oramo）](https://integration.konserthuset.se/en/about-us/our-operation/festivals/grande-finale/liner-notes-and-curious-facts/the-symphonies/symphony-no.-2)バーネットは、カヤヌスの文章を誤解を招くものとしている。[（BIS-CD-862 / Barnett）](https://eclassical.textalk.se/shop/art33/BIS-862_booklet_x.pdf-15896d.pdf)

### 評価の幅

公式サイトは、さまざまな評を並べている。[（sibelius.fi, Symphony No. 2）](https://www.sibelius.klubi.fi/english/musiikki/ork_sinf_02.htm)

- カール・フローディン（Karl Flodin、批評家、1903年）：「絶対的な傑作」
- エリク・フルイェルム（Erik Furuhjelm、研究者、1916年）：客観性の鎖からの人格の決定的な解放
- シモン・パルメット（Simon Parmet、指揮者、1955年）：夏と生の喜びへの賛歌
- ヴァージル・トムソン（Virgil Thomson、作曲家・批評家）：「俗っぽく、自己満足的で、田舎臭い」
- エルッキ・サルメンハーラ（Erkki Salmenhaara、研究者、1984年）：チャイコフスキーよりブラームスに近い、大きなロマン派の交響曲

### テンポの資料

キルペライネンの序文は、テンポに関わる資料として、シベリウスの交響曲のメトロノーム表示（フィンランド国立公文書館）、1943年（または1942年）のブライトコプフのメトロノーム表示、ヤラスがシベリウスとの対話を記したメモ（国立公文書館）、マンの総譜研究（ストックホルム、1977年）を挙げている。[（Breitkopf 序文 / Kilpeläinen）](https://www.breitkopf.com/assets/pdf/6293_PDF_PB5376_NW.pdf)

### 録音

- ロベルト・カヤヌス指揮（1930年5月27・28日、ロンドン、セントラル・ホール・ウェストミンスター）。1930年、シベリウスには国際的な関心を広めるためにロンドンで録音を行う助成が提示され、シベリウスは指揮者にカヤヌスを選んだ。Naxos の復刻盤は管弦楽を Royal Philharmonic Orchestra と表記している。[（MusicWeb / Rob Barnett）](https://musicweb-international.com/classrev/2013/Mar13/Sibelius_sy2_8111394p.htm)
- ジョン・バルビローリ（John Barbirolli）指揮 ハレ管弦楽団（EMI、1966年）。Gramophone は、同じ指揮者のケルン WDR 交響楽団とのライヴ（ICA Classics）より整った演奏としている。[（Gramophone）](https://gramophone.co.uk/review/sibelius-symphony-no-2)
- オスモ・ヴァンスカ（Osmo Vänskä）指揮 ラハティ交響楽団（BIS-CD-862）。[（BIS-CD-862 / Barnett）](https://eclassical.textalk.se/shop/art33/BIS-862_booklet_x.pdf-15896d.pdf)Gramophone は、デジタル録音ではヴァンスカと、コリン・デイヴィス（Colin Davis）のロンドン交響楽団との LSO Live 盤を上位に置いている。[（Gramophone）](https://gramophone.co.uk/review/sibelius-symphony-no-2)

### 自筆譜と印刷譜の違い

印刷された総譜は、初演に使われた自筆譜と多くの箇所で異なる。キルペライネンは、シベリウスが訂正の大半を、失われたレーリヒの写し（C-2）に書き込んだとみている。[（Breitkopf 序文 / Kilpeläinen）](https://www.breitkopf.com/assets/pdf/6293_PDF_PB5376_NW.pdf)

### イタリアの素材と交響曲

第2楽章の2つの主題は、ドン・ジュアンとキリストという、交響曲とは別の構想から来ている。それ以外の楽章に標題の証拠は無い。[（Konserthuset / Oramo）](https://integration.konserthuset.se/en/about-us/our-operation/festivals/grande-finale/liner-notes-and-curious-facts/the-symphonies/symphony-no.-2)公式サイトは、完成までに1年以上かかり、その間に元の標題的な着想は薄れていったとしている。[（sibelius.fi, Symphony No. 2）](https://www.sibelius.klubi.fi/english/musiikki/ork_sinf_02.htm)カルペランが1901年10月に従姉妹に伝えた「5楽章の交響曲」という計画は、最終的に4楽章になった。[（Breitkopf 序文 / Kilpeläinen）](https://www.breitkopf.com/assets/pdf/6293_PDF_PB5376_NW.pdf)
