## 要点

> 要点
>
> - 1525〜30年頃の生まれ。1551年にアントウェルペンの聖ルカ組合の親方になった
> - 版画出版社ヒエロニムス・コックのもとで40点を超える版画の下絵を描き、1557年頃から油彩に移った
> - 1565年の「月暦画」連作のうち5点が残り、《雪中の狩人》はその冬の一枚

ブリューゲル（父）は、16世紀のネーデルラント（いまのベルギーとオランダ）で、農民の暮らし、季節の風景、諺や寓意を描いた。==聖人や王侯ではなく、雪道を帰る猟師や麦を刈る農民を主役にした==。息子のピーテル（子）とヤン（父）も画家になった。

## 生涯

> 要点
>
> - 生年・生地ははっきりしない。ブレダ近辺とする記録が多い
> - 1552〜53年にイタリアを旅し、ローマで細密画家ジュリオ・クローヴィオと仕事をした
> - 1563年にブリュッセルで結婚し、1569年9月9日に同地で没した

| 年 | 出来事 |
|---|---|
| 1525〜30年頃 | ネーデルラントに生まれる。生地はブレダとする説、ブレダ近くの村とする説がある |
| 1550年頃 | メヘレンで聖ロンバウツ大聖堂の祭壇画の外翼を手伝う（現存しない） |
| 1551年 | アントウェルペンの聖ルカ組合に親方として登録 |
| 1552〜54年 | イタリアへ。南はカラブリアまで行き、1553年にはローマにいた |
| 1555年 | アントウェルペンに戻り、出版者ヒエロニムス・コック（「四方の風」）に版画の下絵を描き始める |
| 1557年 | 年記のある最初期の油彩 |
| 1559年 | 署名の綴りを Brueghel から Bruegel に改める。《ネーデルラントの諺》 |
| 1560年 | 《子供の遊戯》 |
| 1563年 | 師ピーテル・クック・ファン・アールストの娘マイケンとブリュッセルで結婚。《バベルの塔》 |
| 1564年 | 長男ピーテル（子）が生まれる |
| 1565年 | アントウェルペンの商人ニクラース・ヨンゲリンクのために「月暦画」連作 |
| 1568年 | 次男ヤン（父）が生まれる。《農民の婚宴》 |
| 1569年9月9日 | ブリュッセルで没し、ノートル＝ダム・ド・ラ・シャペル教会（カペレ教会）に葬られる |

生涯の伝記は、1604年に出たカレル・ファン・マンデルの『画家列伝』に多くを負うが、逸話が多く当てにならない部分もある。コックの版画では、ボスの作風を借りた《七つの大罪》の連作などを手がけた。==《大きな魚は小さな魚を食う》の版画は、コックがボスの作として売った==が、下絵にはブリューゲルの署名がある。1567年にはグイッチャルディーニが彼を「第二のヒエロニムス・ボス」と呼んだ。

## 作風

> 要点
>
> - 高い視点から広い風景を見下ろし、その中に多くの小さな人物を置く
> - 諺・遊び・祭りを一枚に集める「百科事典」のような画面
> - 1552〜53年のイタリア旅行で描いた約20点の風景素描が、風景画の出発点になった

ブリューゲルの画面は、高い所から谷や村を見渡す構図が多い。《雪中の狩人》では、丘の上の猟師と犬の背中越しに、凍った池で遊ぶ人々と遠くの岩山が一望できる。==人物は小さく描かれるが、一人ひとりが何をしているかまで読み取れる==。

《ネーデルラントの諺》には、もとは《青いマント》の題があり、多くの諺を一つの村の中に描き込んでいる。《子供の遊戯》も同じ考え方で、広場いっぱいに子どもの遊びを並べる。旧約聖書の《バベルの塔》では、天に届こうとして建設途中のまま終わる塔を描いた。

## 代表作

> 要点
>
> - 「月暦画」は6点とも12点ともいわれ、現存は5点
> - 現存する油彩はおよそ40点で、うち12点をウィーン美術史美術館が持つ
> - 夏の一枚《穀物の収穫》はメトロポリタン美術館にある

| 題 | 年 | 所蔵 |
|---|---|---|
| ネーデルラントの諺 | 1559年 | ベルリン国立美術館絵画館 |
| 子供の遊戯 | 1560年 | ウィーン美術史美術館 |
| バベルの塔（大） | 1563年 | ウィーン美術史美術館 |
| 雪中の狩人（12〜1月） | 1565年 | ウィーン美術史美術館 |
| 暗い日（2〜3月） | 1565年 | ウィーン美術史美術館 |
| 牛群の帰り（10〜11月） | 1565年 | ウィーン美術史美術館 |
| 干し草の収穫（6〜7月） | 1565年 | ロプコヴィツ宮殿（プラハ） |
| 穀物の収穫（8〜9月） | 1565年 | メトロポリタン美術館（ニューヨーク） |
| 農民の婚宴 | 1568年 | ウィーン美術史美術館 |

「月暦画」は、一年を2か月ずつに分けた連作と考えられている。1569年の財産目録には6点が載る。==5点が残り、ウィーンに3点、プラハとニューヨークに1点ずつ散った==。

## どこで見られるか

> 要点
>
> - まとまって見るならウィーン美術史美術館。現存作の約3割がここにある
> - 《穀物の収穫》はメトロポリタン美術館、《ネーデルラントの諺》はベルリン
> - 墓所はブリュッセルのカペレ教会

ウィーン美術史美術館には、《雪中の狩人》《バベルの塔》《農民の婚宴》《子供の遊戯》を含む12点がある。==現存するおよそ40点の油彩のうち、12点が一つの館に集まっている==ので、ブリューゲルを見る旅はまずウィーンになる。ニューヨークのメトロポリタン美術館では、8月から9月を表す《穀物の収穫》が見られる。ブリュッセルのカペレ教会には墓所があり、1676年にダフィット・テニールス（子）が記念碑を新しくした。

## よくある質問

> 要点
>
> - 「父」と呼ぶ理由、季節の連作、作品の多い美術館

### なぜ「父」と付けるのか

同じ名の長男ピーテル・ブリューゲル（子、1564/65–1638）も画家で、区別のためである。次男ヤン・ブリューゲル（父、1568–1625）も画家になった。

### 《雪中の狩人》はいつ、何のために描かれたか

1565年、アントウェルペンのニクラース・ヨンゲリンクのための「月暦画」の一枚で、12月から1月を表す。

### いちばん多く作品を持つ美術館はどこか

==ウィーン美術史美術館で、12点を持つ==。

### 綴りが Brueghel と Bruegel の二通りあるのはなぜか

本人が1559年から h を抜いた Bruegel と署名し、息子たちは Brueghel の綴りを使ったため。

### イタリアには行ったか

行った。1551年に親方になって間もなく旅立ち、1552年には南のレッジョ・カラブリアに達し、1553年にはローマで細密画家ジュリオ・クローヴィオと仕事をした。1555年までにアントウェルペンへ戻った。

### 版画の仕事は何をしたか

1555年から出版者ヒエロニムス・コックのために40点を超える版画の下絵を描いた。1555年に出た風景の大判の連作、ボスに倣った《七つの大罪》の連作などがある。
