## 要点

> 要点
>
> - 1841年、リモージュに生まれ、少年期は磁器の絵付けの見習いをした
> - グレールの画室でモネ、シスレー、バジールと出会い、1874年の第1回印象派展に出品した
> - 1881年のイタリア旅行でラファエロらを見て、印象派から離れた

ルノワールは、パリの人々が踊り、舟遊びをし、食卓を囲む場面を、明るい色で描いた。==風景より、人とその楽しみの場面を好んで描いた==。晩年は体の衰えに苦しみながら、南仏カーニュで描き続けた。

## 生涯

> 要点
>
> - 幼くして一家でパリへ移り、磁器の絵付けを学んだ
> - 長男ピエールは1885年、次男ジャンは1894年に生まれた
> - 1919年12月3日、カーニュ＝シュル＝メールで没した。78歳

| 年 | 出来事 |
|---|---|
| 1841年2月25日 | リモージュに生まれる |
| 幼少期 | 一家でパリへ移る |
| 少年期 | 磁器の絵付けの見習いをする。4年後に職を失い、家具や巻き上げ式の日よけに絵を描く |
| 1860年代 | シャルル・グレールの画室で、モネ、シスレー、バジールと知り合う |
| 1869年 | モネと並んでラ・グルヌイエールを描く |
| 1874年 | 第1回印象派展に出品 |
| 1877年 | 第3回印象派展に《ムーラン・ド・ラ・ギャレットの舞踏会》を出品 |
| 1878年 | 《シャルパンティエ夫人と子どもたち》（1879年の官展に出品） |
| 1881年 | アルジェとイタリアを旅し、ラファエロやポンペイの壁画に学ぶ |
| 1885年 | 長男ピエールが生まれる |
| 1890年代初め | 印象派から離れた晩年の作風に入る |
| 1894年 | 次男ジャンが生まれる |
| 1903年 | 南仏カーニュ＝シュル＝メールに移る |
| 1919年12月3日 | カーニュで没する。78歳 |

==磁器の絵付けの見習いは、4年で終わった==。その後は家具や日よけに絵を描いて暮らしを立て、絵の道に進んだ。

## 作風

> 要点
>
> - 1869年にモネと並んで戸外で描いた
> - イタリア旅行の後、線を硬く引く時期に入った
> - 1890年代初めからの晩年の作風は、ピカソやマティスに称えられた

1869年、ルノワールはモネと並んで戸外で描き、二人は同じラ・グルヌイエールの景色を描いた。1874年の第1回印象派展に出品し、1877年の第3回展には《ムーラン・ド・ラ・ギャレットの舞踏会》を出した。

1881年のイタリア旅行で、ラファエロらルネサンスの作品やポンペイの壁画を見たルノワールは、印象派から離れた。==その後の時期は、線を硬く引く描き方で、「酸っぱい時期」とも呼ばれる==。1890年代初めからの晩年の作品は、夢見るような官能的な画面で、ピカソやマティスに称えられた一方、多くの批評家には退けられた。

## 代表作

> 要点
>
> - 《シャルパンティエ夫人と子どもたち》はメトロポリタン美術館
> - 《ムーラン・ド・ラ・ギャレットの舞踏会》は1877年の第3回印象派展に出た
> - フィラデルフィアのバーンズ財団は181点を持つ

| 題 | 年 | 所蔵 |
|---|---|---|
| ムーラン・ド・ラ・ギャレットの舞踏会 | 1877年出品 | — |
| シャルパンティエ夫人と子どもたち | 1878年 | メトロポリタン美術館（ニューヨーク）07.122 |

《シャルパンティエ夫人と子どもたち》は、出版者ジョルジュ・シャルパンティエの妻マルグリットと、子のジョルジェットとポールを、パリの邸宅の日本風の居間に描いた。夫人はフロベール、ゴンクール兄弟、ゾラらの集う文学サロンを開き、その人脈で1879年の官展にこの絵の良い場所を得た。プルーストはこの絵に「優雅な家と、私たちの時代の美しい衣装の詩」を見た。1907年にメトロポリタン美術館が購入した。

==1877年の《ムーラン・ド・ラ・ギャレットの舞踏会》と1878年の《シャルパンティエ夫人と子どもたち》は、印象派展と官展という二つの場で作品を見せた時期の作==である。

## どこで見られるか

> 要点
>
> - フィラデルフィアのバーンズ財団（181点）
> - ニューヨークのメトロポリタン美術館
> - 晩年を過ごしたのは南仏カーニュ＝シュル＝メール

==一か所で最も多く見られるのは、181点を持つフィラデルフィアのバーンズ財団==で、ルノワールの作品の世界最大のまとまりである。メトロポリタン美術館では《シャルパンティエ夫人と子どもたち》が見られる。

## よくある質問

> 要点
>
> - 生地と出自、作風の変化、家族

### どこで生まれたか

リモージュ。1841年2月25日に生まれ、幼くして一家でパリへ移った。

### なぜ作風を変えたのか

1881年のイタリア旅行でラファエロらの作品やポンペイの壁画を見て、印象派から離れたため。

### 子どもはいたか

==長男ピエールが1885年に、次男ジャンが1894年に生まれた==。

### 晩年はどこで過ごしたか

1903年から南仏カーニュ＝シュル＝メールで過ごし、1919年にそこで亡くなった。

### 画家になる前は何をしていたか

磁器の絵付けの見習いをした。4年で職を失い、家具や巻き上げ式の日よけに絵を描いて暮らしを立てた。

### 作品を最も多く持つ館はどこか

フィラデルフィアのバーンズ財団で、181点を持つ。
