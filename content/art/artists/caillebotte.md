## 要点

> 要点
>
> - 1848年パリ生まれ。法律の学位を取ってから絵を学び、父の遺産で生活の心配なく描いた
> - 1875年の官展に落ちた《床削り》を、翌1876年の第2回印象派展に出した
> - 仲間の絵を買い集め、遺言で国に遺した。1897年にリュクサンブール美術館で公開された

カイユボットは印象派の画家であり、同時に印象派展の組織者、仲間の絵の買い手でもあった。==描いた絵と集めた絵の両方が、いまのパリとシカゴで印象派を見る体験の土台になっている==。代表作《パリの通り、雨の日》はシカゴ美術館の目玉の一つである。

## 生涯

> 要点
>
> - 裕福な家に生まれ、1874年に父、1878年に母を亡くして財産を受け継いだ
> - 1876年から印象派展に加わり、1877年の第3回展では会場探しから展示まで担った
> - 晩年はセーヌ河畔のプティ＝ジュヌヴィリエでヨットの設計と庭づくりに打ち込んだ

| 年 | 出来事 |
|---|---|
| 1848年8月19日 | パリのフォーブール＝サン＝ドニ通りに生まれる。父マルシャルは軍用織物の家業を継ぎ、商事裁判所の判事も務めた |
| 1868年 | 法律の学位を取る（1870年に弁護士資格） |
| 1870〜71年 | 普仏戦争でセーヌ県の遊動国民衛兵に従軍。この頃から絵を描き始める |
| 1873年 | レオン・ボナの画室を経て、国立美術学校に入る |
| 1874年 | 父が死去し、財産を受け継ぐ。第1回印象派展を見に行くが出品はしない |
| 1875年 | 《床削り》が官展で落選。初めてモネの絵を買う |
| 1876年 | 第2回印象派展に8点を出品 |
| 1877年 | 第3回印象派展を取り仕切り、《パリの通り、雨の日》を出品 |
| 1878年 | 母が死去。兄弟で財産を分け、イエールの屋敷を売ってオスマン大通りに移る |
| 1879年 | 第4回印象派展に油彩とパステル計35点 |
| 1881年 | プティ＝ジュヌヴィリエに土地を買う（1888年から定住） |
| 1890年 | モネと募金を集め、マネ《オランピア》を国に買い取らせる |
| 1894年2月21日 | ジュヌヴィリエで庭仕事中に肺うっ血で死去。45歳。ペール・ラシェーズ墓地に葬られる |

==作品を世に出したのは、1876年の第2回印象派展から34歳の頃までの、わずか数年だった==。1876年に弟ルネが若くして死んだあと、カイユボットは20代で遺言を書き、自分の集めた絵を国に遺すと決めていた。印象派展には8回のうち5回出品した。作品の発表をやめたのは34歳の頃で、その後はプティ＝ジュヌヴィリエに造船所を構えてヨットを設計し、「ローストビーフ」号などでレガッタに勝った。弟マルシャルとは切手を集め、その収集はいま大英図書館にある。

## 作風

> 要点
>
> - 印象派の題材（都市の日常・余暇）を、輪郭のはっきりした写実的な描き方で描いた
> - 強い遠近法と、写真を思わせる大胆な切り取りが特徴
> - 雨粒は描かず、傘と濡れた石畳で雨を表した

カイユボットは、モネやルノワールのように筆触を細かく分けて光を描くより、形と線を正確に描くほうを選んだ。題材は印象派と同じで、オスマンの改造で生まれた新しいパリの大通り、アパルトマンの窓から見下ろす街、セーヌでの舟遊びを描いた。==題材は印象派、描き方は写実——この組み合わせがカイユボットの位置を決めている==。

《床削り》は、パリのアパルトマンで床を削る上半身裸の職人たちを描く。1875年の官展は、労働者をそのまま描いた題材を「卑俗」とみて退けた。カイユボットは落選に傷ついたが、翌年の第2回印象派展でこの絵と《窓辺の若い男》を並べた。

《パリの通り、雨の日》は彼の最大の作品で、自宅近くの交差点を描く。手前の人物が画面の端で断ち切られる構図には写真の影響がうかがえる。雨は雨粒ではなく、並んだ傘と光る石畳で示されている。

## 代表作

> 要点
>
> - 《床削り》と《パリの通り、雨の日》は、いずれも印象派展で初めて公開された
> - 《床削り》は1894年に遺族が国に寄贈し、1986年からオルセー美術館にある
> - 《窓辺の若い男》は2021年にゲティ美術館が購入した

| 題 | 年 | 所蔵 |
|---|---|---|
| 床削り | 1875年 | オルセー美術館（パリ）。102×146.5cm |
| 窓辺の若い男 | 1876年 | J・ポール・ゲティ美術館（ロサンゼルス）。2021年購入 |
| パリの通り、雨の日 | 1877年 | シカゴ美術館（201室）。212.2×276.2cm、1964年購入 |
| 舟遊び | 1879年出品 | 第4回印象派展に出品 |

《床削り》は遺族から国に贈られ、リュクサンブール美術館、1929年にルーヴル、1947年にジュ・ド・ポームを経て、1986年にオルセー美術館に移った。1876年の第2回展には、構図の違う2枚目の《床削り》（1876年）も出ている。

《パリの通り、雨の日》は1877年の第3回印象派展に「パリの通り、雨天」の題で出た。画家の死後は弟マルシャルの家に残り、1954年にウォルター・P・クライスラー・ジュニアの手に渡ったのち、1964年に画商ウィルデンスタインを経てシカゴ美術館が購入した。1894年の回顧展、1951年のパリの回顧展にも出ている。==シカゴに入って以来、来館者に親しまれてきた一枚である==。

## どこで見られるか

> 要点
>
> - パリならオルセー美術館、シカゴならシカゴ美術館
> - 遺贈の受け入れは1896年、公開は1897年のリュクサンブール美術館
> - 残りの作品は1904年と1908年に申し出られたが、国は断った

カイユボットは68点の絵を国に遺し、展示はまずリュクサンブール美術館、のちにルーヴルで、と条件を付けた。国は受け入れに難色を示し、1896年2月に遺言執行人のルノワールと交渉した結果、38点が受け入れられた。1897年2月、リュクサンブール美術館に「カイユボットの部屋」が開いた。残りの作品は1904年と1908年に改めて申し出られたが断られている。ルノワールは執行の謝礼として、遺品からドガの1点を受け取った。

==遺贈を一度は渋った国の美術館が、いまはその遺贈を核に印象派を見せている==。オルセー美術館で《床削り》を見るときは、同じ画家が仲間の絵を買い、国に遺そうとした人でもあったことを思い出すとよい。シカゴ美術館では《パリの通り、雨の日》が常設の201室にある。

## よくある質問

> 要点
>
> - 生年と没年、落選作、遺贈の数字、代表作の所蔵

### カイユボットはいつの人か

1848年8月19日にパリで生まれ、1894年2月21日にジュヌヴィリエで亡くなった。45歳だった。

### 官展に落ちた作品は何か

《床削り》（1875年）。労働者を描いた題材が卑俗とされた。翌年の第2回印象派展に出品された。

### 遺贈した作品は何点で、何点が受け入れられたか

==68点を遺し、1896年の交渉で38点が受け入れられた==。1897年にリュクサンブール美術館で公開された。

### 《パリの通り、雨の日》はどこにあるか

シカゴ美術館。1964年に購入された。
