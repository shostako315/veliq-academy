## 要点

- ==<span lang="it">c</span>・<span lang="it">g</span> は後ろが <span lang="it">e</span>・<span lang="it">i</span> なら「チ・ジ」、<span lang="it">a</span>・<span lang="it">o</span>・<span lang="it">u</span> なら「カ・ガ」。<span lang="it">ch</span>・<span lang="it">gh</span> は「キ・ギ」（<span lang="it">che</span>＝ケ、<span lang="it">spaghetti</span>＝スパゲッティ）==
- <span lang="it">gli</span> は「リ」に近い音（<span lang="it">famiglia</span>＝ファミーリア）、<span lang="it">gn</span> は「ニャ・ニョ」（<span lang="it">gnocchi</span>＝ニョッキ）
- 最後にアクセント記号がある語はそこを強く読む（<span lang="it">caffè</span>、<span lang="it">città</span>、<span lang="it">perché</span>）。ほかの多くは後ろから2つ目を強く読む

## キーフレーズ

> 要点
>
> - ==「<span lang="it">Un caffè, per favore.</span>」<span lang="it">caffè</span> は <span lang="it">f</span> が2つで、最後の <span lang="it">è</span> を強く読みます。記号の向きは <span lang="it">è</span> です。==
> - 「<span lang="it">Vorrei gli gnocchi.</span>」<span lang="it">gn</span> は「ニョ」、<span lang="it">cch</span> は「ッキ」と読みます。
> - 「<span lang="it">Com'è la città?</span>」<span lang="it">città</span> は <span lang="it">tt</span> を詰め、最後の <span lang="it">à</span> を強く読みます。

| イタリア語 | 読み | 日本語 | 使う場面 |
|---|---|---|---|
| <span lang="it">Ciao.</span> | チャオ | やあ・じゃあね。 | 親しい人へのあいさつ |
| <span lang="it">Buongiorno.</span> | ブォンジョルノ | こんにちは（おはようございます）。 | 朝から午後のあいさつ |
| <span lang="it">Grazie mille.</span> | グラツィエ・ミッレ | どうもありがとうございます。 | お礼を言うとき |
| <span lang="it">Un caffè, per favore.</span> | ウン・カッフェ・ペル・ファヴォーレ | コーヒーを1杯ください。 | バールで |
| <span lang="it">Che cos'è?</span> | ケ・コゼ | これは何ですか。 | ものを尋ねるとき |
| <span lang="it">Vorrei gli gnocchi.</span> | ヴォッレイ・リ・ニョッキ | ニョッキをお願いします。 | 料理を頼むとき |
| <span lang="it">Gli spaghetti sono buonissimi.</span> | リ・スパゲッティ・ソーノ・ブォニッスィミ | スパゲッティがとてもおいしいです。 | 感想を言うとき |
| <span lang="it">La mia famiglia è a Tokyo.</span> | ラ・ミーア・ファミーリア・エ・ア・トーキョー | 家族は東京にいます。 | 家族のことを話すとき |

### 解説

- **<span lang="it">Ciao.</span>**：<span lang="it">ci</span> は「チ」と読みます。親しい相手にだけ使います。
- **<span lang="it">Buongiorno.</span>**：<span lang="it">gi</span> は「ジ」と読みます。
- **<span lang="it">Grazie mille.</span>**：<span lang="it">ll</span> は小さな「ッ」を入れて「ミッレ」と読みます。
- **<span lang="it">Che cos'è?</span>**：<span lang="it">che</span> は「ケ」と読みます（<span lang="it">ch</span> はカ行）。
- **<span lang="it">Gli spaghetti sono buonissimi.</span>**：<span lang="it">ghe</span> は「ゲ」、<span lang="it">gli</span> は「リ」に近い音です。
- **<span lang="it">La mia famiglia è a Tokyo.</span>**：<span lang="it">famiglia</span> の <span lang="it">gli</span> は「リ」に近く、ファミーリアと読みます。
- **<span lang="it">Perché?</span>**：最後の <span lang="it">é</span> を強く「ペルケ」と読みます。
- **<span lang="it">Come si scrive?</span>**：<span lang="it">scrivere</span> は「書く」。<span lang="it">Come si scrive?</span> で綴りを尋ねられます。

## 文法ポイント

> 要点
>
> - ==アクセント記号と強く読む位置==
> - 「<span lang="it">Un caffè, per favore.</span>」アクセント記号まで書いて <span lang="it">caffè</span> です。

イタリア語の単語は、多くが後ろから2つ目の音節を強く読みます（<span lang="it">a-MI-co</span>、<span lang="it">ri-sto-RAN-te</span>）。最後を強く読む語にはアクセント記号を付けます（<span lang="it">caffè</span>、<span lang="it">città</span>）。記号の向き（<span lang="it">è</span> と <span lang="it">é</span>）は母音の開き方の違いで、書くときは語ごとに決まった形を覚えます。

| 例文 | 日本語 | ポイント |
|---|---|---|
| <span lang="it">Un caffè, per favore.</span> | コーヒーを1杯ください。 | アクセント記号まで書いて <span lang="it">caffè</span> です。 |
| <span lang="it">Lunedì vado a Roma.</span> | 月曜日にローマに行きます。 |  |
| <span lang="it">La città è molto bella.</span> | 街はとても美しいです。 |  |

## 文化メモ

> 要点
>
> - ==イタリア語は綴りと読みがほぼ一対一なので、決まりを覚えると知らない単語も読めます。==

<span lang="it">h</span> は発音しない文字で、<span lang="it">ch</span>・<span lang="it">gh</span> のように <span lang="it">c</span> と <span lang="it">g</span> をカ行・ガ行にするために使われます。<span lang="it">ho</span>（持っている）は「オ」と読みます。

## よくある間違い

> 要点
>
> - ==「<span lang="it">Una brusketta, per favore.</span>」ではなく「<span lang="it">Una bruschetta, per favore.</span>」==
> - 「<span lang="it">Un cafè, per favore.</span>」ではなく「<span lang="it">Un caffè, per favore.</span>」
> - 「<span lang="it">Grazie mile.</span>」ではなく「<span lang="it">Grazie mille.</span>」

| 誤 | 正 | 理由 |
|---|---|---|
| <span lang="it">Una brusketta, per favore.</span> | <span lang="it">Una bruschetta, per favore.</span> | 「スケ」の音は <span lang="it">sche</span> と書きます（<span lang="it">ch</span> はカ行）。ブルスケッタと読みます。 |
| <span lang="it">Un cafè, per favore.</span> | <span lang="it">Un caffè, per favore.</span> | <span lang="it">caffè</span> は <span lang="it">f</span> が2つで、最後に <span lang="it">è</span> を付けます。 |
| <span lang="it">Grazie mile.</span> | <span lang="it">Grazie mille.</span> | <span lang="it">mille</span> は <span lang="it">l</span> が2つで「ミッレ」と詰めて読みます。 |

## よくある質問

### 「やあ・じゃあね」はイタリア語で何と言いますか

==「<span lang="it">Ciao.</span>」（チャオ）==。<span lang="it">ci</span> は「チ」と読みます。親しい相手にだけ使います。

### 綴りを聞くときは、何と言いますか

「<span lang="it">Come si scrive?</span>」（コメ・スィ・スクリーヴェ）。意味は「どう書きますか」です。<span lang="it">scrivere</span> は「書く」。<span lang="it">Come si scrive?</span> で綴りを尋ねられます。

### 「アクセント記号と強く読む位置」では、何を押さえればよいですか

イタリア語の単語は、多くが後ろから2つ目の音節を強く読みます（<span lang="it">a-MI-co</span>、<span lang="it">ri-sto-RAN-te</span>）。最後を強く読む語にはアクセント記号を付けます（<span lang="it">caffè</span>、<span lang="it">città</span>）。

### 「<span lang="it">Una brusketta, per favore.</span>」はなぜ間違いですか

正しくは「<span lang="it">Una bruschetta, per favore.</span>」です。「スケ」の音は <span lang="it">sche</span> と書きます（<span lang="it">ch</span> はカ行）。ブルスケッタと読みます。
