## 要点

- ==天気は <span lang="it">Fa caldo</span> / <span lang="it">Fa freddo</span>（<span lang="it">fare</span> を使う）、<span lang="it">Che bella giornata.</span>==
- 好みは <span lang="it">Le piace</span> 〜?（〜はお好きですか）。答えは <span lang="it">Sì, mi piace molto.</span>
- 答えたあと <span lang="it">E a Lei?</span> で相手に返す

## キーフレーズ

> 要点
>
> - ==「<span lang="it">Oggi fa freddo, vero?</span>」暑さ寒さは <span lang="it">fare</span> で言います。<span lang="it">vero?</span> で同意を求めます。==
> - 「<span lang="it">Mi piacciono le opere di Verdi.</span>」好きなものが複数なので <span lang="it">piacciono</span> です。
> - 「<span lang="it">È mai stato all'Arena di Verona?</span>」相手が男性なら <span lang="it">stato</span>、女性なら <span lang="it">stata</span> です。

### 解説

- **<span lang="it">Che bella giornata.</span>**：<span lang="it">che</span> ＋形容詞＋名詞で「なんと〜な」です。
- **<span lang="it">Sta per piovere.</span>**：<span lang="it">stare per</span> ＋動詞で「いまにも〜しそう」です。
- **<span lang="it">Le è piaciuto il concerto?</span>**：<span lang="it">Lei</span> に対して「あなたの気に入ったか」の形で聞きます。
- **<span lang="it">Mi piace molto Puccini.</span>**：好きなもの（<span lang="it">Puccini</span>）が主語になります。
- **<span lang="it">Suono il violino in un'orchestra.</span>**：<span lang="it">orchestra</span> は母音で始まる女性名詞なので <span lang="it">un'</span> です。
- **<span lang="it">E a Lei?</span>**：好みを答えたあとに、相手に返す言い方です。
- **<span lang="it">È stato un piacere parlare con Lei.</span>**：<span lang="it">un piacere</span> で「喜び」です。

## 文法ポイント

> 要点
>
> - ==<span lang="it">piacere</span>「〜が好き」==

「私は〜が好き」は <span lang="it">mi piace</span> 〜 で、好きなもののほうが主語になります。好きなものが単数なら <span lang="it">piace</span>、複数なら <span lang="it">piacciono</span> です。相手（<span lang="it">Lei</span>）に聞くときは <span lang="it">Le piace</span> 〜? と言います。

| 例文 | 日本語 |
|---|---|
| <span lang="it">Mi piace la musica classica.</span> | クラシック音楽が好きです。 |
| <span lang="it">Le piacciono i tortellini?</span> | トルテッリーニはお好きですか。 |
| <span lang="it">Non mi piace il caldo.</span> | 暑いのは苦手です。 |

## よくある間違い

> 要点
>
> - ==「<span lang="it">Io piaccio Puccini.</span>」ではなく「<span lang="it">Mi piace Puccini.</span>」==
> - 「<span lang="it">Mi piace le opere di Verdi.</span>」ではなく「<span lang="it">Mi piacciono le opere di Verdi.</span>」
> - 「<span lang="it">Oggi è freddo.</span>」ではなく「<span lang="it">Oggi fa freddo.</span>」

| 誤 | 正 | 理由 |
|---|---|---|
| <span lang="it">Io piaccio Puccini.</span> | <span lang="it">Mi piace Puccini.</span> | 好きなもの（<span lang="it">Puccini</span>）を主語にして <span lang="it">mi piace</span> と言います。 |
| <span lang="it">Mi piace le opere di Verdi.</span> | <span lang="it">Mi piacciono le opere di Verdi.</span> | 好きなものが複数なら <span lang="it">piacciono</span> です。 |
| <span lang="it">Oggi è freddo.</span> | <span lang="it">Oggi fa freddo.</span> | 天気の暑さ寒さは、ふつう <span lang="it">fare</span> で言います。 |

## よくある質問

### 「いいお天気ですね」はイタリア語で何と言いますか

==「<span lang="it">Che bella giornata.</span>」（ケ・ベッラ・ジョルナータ）==。<span lang="it">che</span> ＋形容詞＋名詞で「なんと〜な」です。

### 別れるときは、何と言いますか

「<span lang="it">È stato un piacere parlare con Lei.</span>」（エ・スタート・ウン・ピアチェーレ・パルラーレ・コン・レイ）。意味は「お話しできてうれしかったです」です。<span lang="it">un piacere</span> で「喜び」です。

### 「<span lang="it">piacere</span>「〜が好き」」では、何を押さえればよいですか

「私は〜が好き」は <span lang="it">mi piace</span> 〜 で、好きなもののほうが主語になります。好きなものが単数なら <span lang="it">piace</span>、複数なら <span lang="it">piacciono</span> です。

### 「<span lang="it">Io piaccio Puccini.</span>」はなぜ間違いですか

正しくは「<span lang="it">Mi piace Puccini.</span>」です。好きなもの（<span lang="it">Puccini</span>）を主語にして <span lang="it">mi piace</span> と言います。
