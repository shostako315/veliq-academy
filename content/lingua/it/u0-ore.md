## 要点

- ==時刻は <span lang="it">Che ore sono?</span> → <span lang="it">Sono le tre.</span>（1時だけ <span lang="it">È l'una.</span>）==
- 「〜時に」は <span lang="it">alle tre</span>、1時は <span lang="it">all'una</span>
- 曜日は小文字で書く。<span lang="it">lunedì</span>〜<span lang="it">venerdì</span> は最後にアクセント記号が付く

## キーフレーズ

> 要点
>
> - ==「<span lang="it">Sono le tre.</span>」時刻は <span lang="it">le</span> ＋数字で言います。==
> - 「<span lang="it">A che ora apre?</span>」主語（店・美術館）が1つなので <span lang="it">apre</span> です。
> - 「<span lang="it">È aperto la domenica?</span>」<span lang="it">la domenica</span> で「（毎週）日曜日に」。<span lang="it">domenica</span> は女性名詞です。

### 解説

- **<span lang="it">Che ore sono?</span>**：<span lang="it">ore</span> は複数形です。<span lang="it">Che ora è?</span> とも言います。
- **<span lang="it">È l'una e mezza.</span>**：1時だけは単数の <span lang="it">È l'una</span> です。<span lang="it">e mezza</span> で「半」です。
- **<span lang="it">Apre alle nove.</span>**：<span lang="it">alle</span> ＝ <span lang="it">a</span> ＋ <span lang="it">le</span> で「〜時に」です。
- **<span lang="it">Chiude a pranzo?</span>**：<span lang="it">a pranzo</span> で「昼食どきに」です。
- **<span lang="it">Ci vediamo venerdì.</span>**：曜日は小文字で、<span lang="it">venerdì</span> は最後にアクセント記号を付けます。
- **<span lang="it">Il concerto comincia alle otto e mezza.</span>**：<span lang="it">cominciare</span>（始まる）の3人称は <span lang="it">comincia</span> です。
- **<span lang="it">Sono libero nel pomeriggio.</span>**：女性なら <span lang="it">libera</span> です。<span lang="it">nel pomeriggio</span> で「午後に」です。

## 文法ポイント

> 要点
>
> - ==時刻の言い方と <span lang="it">alle</span>==

「何時です」は <span lang="it">Sono le</span> ＋数（<span lang="it">Sono le cinque</span>）、1時だけは <span lang="it">È l'una</span> です。「〜時に」は <span lang="it">a</span> と <span lang="it">le</span> を合わせた <span lang="it">alle</span> を使い（<span lang="it">alle cinque</span>）、1時は <span lang="it">all'una</span> です。正午は <span lang="it">a mezzogiorno</span> と冠詞を付けません。

| 例文 | 日本語 |
|---|---|
| <span lang="it">Il treno parte alle sei.</span> | 列車は6時に出ます。 |
| <span lang="it">Pranziamo all'una.</span> | 1時に昼食をとります。 |
| <span lang="it">Sono le dieci e un quarto.</span> | 10時15分です。 |

## 文化メモ

> 要点
>
> - ==イタリアの小さな町の店は、昼に数時間閉まり、夕方に開け直すことがあります。==

国立の美術館は月曜日を休館日にしているところが多いので、行く前に確かめておくと安心です。駅の時刻表示は24時間制です。

## よくある間違い

> 要点
>
> - ==「<span lang="it">Sono la una.</span>」ではなく「<span lang="it">È l'una.</span>」==
> - 「<span lang="it">Apre a le nove.</span>」ではなく「<span lang="it">Apre alle nove.</span>」
> - 「<span lang="it">Ci vediamo Lunedì.</span>」ではなく「<span lang="it">Ci vediamo lunedì.</span>」

| 誤 | 正 | 理由 |
|---|---|---|
| <span lang="it">Sono la una.</span> | <span lang="it">È l'una.</span> | 1時だけは単数の <span lang="it">È l'una</span> です。 |
| <span lang="it">Apre a le nove.</span> | <span lang="it">Apre alle nove.</span> | <span lang="it">a</span> と <span lang="it">le</span> は <span lang="it">alle</span> と1語にします。 |
| <span lang="it">Ci vediamo Lunedì.</span> | <span lang="it">Ci vediamo lunedì.</span> | 曜日は小文字で書きます。 |

## よくある質問

### 「何時ですか」はイタリア語で何と言いますか

==「<span lang="it">Che ore sono?</span>」（ケ・オーレ・ソーノ）==。<span lang="it">ore</span> は複数形です。<span lang="it">Che ora è?</span> とも言います。

### 予定を伝えるときは、何と言いますか

「<span lang="it">Sono libero nel pomeriggio.</span>」（ソーノ・リーベロ・ネル・ポメリッジョ）。意味は「午後は空いています」です。女性なら <span lang="it">libera</span> です。<span lang="it">nel pomeriggio</span> で「午後に」です。

### 「時刻の言い方と <span lang="it">alle</span>」では、何を押さえればよいですか

「何時です」は <span lang="it">Sono le</span> ＋数（<span lang="it">Sono le cinque</span>）、1時だけは <span lang="it">È l'una</span> です。「〜時に」は <span lang="it">a</span> と <span lang="it">le</span> を合わせた <span lang="it">alle</span> を使い（<span lang="it">alle cinque</span>）、1時は <span lang="it">all'una</span> です。

### 「<span lang="it">Sono la una.</span>」はなぜ間違いですか

正しくは「<span lang="it">È l'una.</span>」です。1時だけは単数の <span lang="it">È l'una</span> です。
