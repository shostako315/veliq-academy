## 要点

- ==店に入るときは <span lang="it">Buongiorno.</span>、午後遅くからは <span lang="it">Buonasera.</span> と言ってから用件に入る==
- 初対面は <span lang="it">Piacere.</span>（はじめまして）。親しくない相手には <span lang="it">Lei</span> を使い、動詞は3人称の形（<span lang="it">Come sta?</span>）
- お礼は <span lang="it">Grazie.</span>、答えは <span lang="it">Prego.</span>。人に声をかけるときは <span lang="it">Scusi.</span>

## キーフレーズ

> 要点
>
> - ==「<span lang="it">Come sta?</span>」<span lang="it">Lei</span> に対しては <span lang="it">sta</span> です。親しい相手なら <span lang="it">Come stai?</span> です。==
> - 「<span lang="it">Mi chiamo Kenta.</span>」「私は〜という名前です」は <span lang="it">mi chiamo</span> です。
> - 「<span lang="it">Buona giornata.</span>」別れ際は <span lang="it">buona giornata</span>、夜なら <span lang="it">buona serata</span> です。

### 解説

- **<span lang="it">Buonasera.</span>**：午後のある時間から <span lang="it">Buonasera</span> に変わります。店に入るときにも使います。
- **<span lang="it">Bene, grazie. E Lei?</span>**：答えたあと <span lang="it">E Lei?</span> と尋ね返します。
- **<span lang="it">Piacere.</span>**：名乗ったあとに言う決まった言葉です。
- **<span lang="it">Scusi.</span>**：<span lang="it">Lei</span> に対する言い方です。親しい相手には <span lang="it">Scusa.</span> です。
- **<span lang="it">Grazie mille.</span>**：<span lang="it">mille</span> は「千」。強いお礼になります。
- **<span lang="it">Prego.</span>**：<span lang="it">prego</span> は「どうぞ」の意味でも使います。
- **<span lang="it">Arrivederci.</span>**：店を出るときにも言います。
- **<span lang="it">A domani.</span>**：<span lang="it">a</span> ＋時を表す語で「また〜に」です。

## 文法ポイント

> 要点
>
> - ==<span lang="it">Lei</span> と <span lang="it">tu</span>==
> - 「<span lang="it">Come sta, signora?</span>」<span lang="it">signora</span> と呼ぶ相手には <span lang="it">Lei</span> の形 <span lang="it">sta</span> です。

イタリア語には「あなた」が二つあります。知らない人・店の人・目上の人には <span lang="it">Lei</span>（丁寧）、家族や友人には <span lang="it">tu</span>（親しい）。<span lang="it">Lei</span> を使うときは、動詞を3人称（彼・彼女と同じ形）にします。迷ったら <span lang="it">Lei</span> を使い、相手が <span lang="it">tu</span> で話そうと言ってくれたら切り替えます。

| 例文 | 日本語 | ポイント |
|---|---|---|
| <span lang="it">Come sta, signora?</span> | お元気ですか（丁寧）。 | <span lang="it">signora</span> と呼ぶ相手には <span lang="it">Lei</span> の形 <span lang="it">sta</span> です。 |
| <span lang="it">Come stai, Marco?</span> | 元気？マルコ（親しい）。 |  |
| <span lang="it">Scusi, Lei è italiano?</span> | すみません、イタリアの方ですか。 |  |

## 文化メモ

> 要点
>
> - ==イタリアでは、店に入るときに <span lang="it">Buongiorno</span> / <span lang="it">Buonasera</span> と声をかけ、出るときに <span lang="it">Arrivederci</span> と言うのが礼儀です。==

親しい間柄では頬を寄せるあいさつを交わすことがありますが、初対面や仕事の場では握手がふつうです。

## よくある間違い

> 要点
>
> - ==「<span lang="it">Ciao, signore.</span>」ではなく「<span lang="it">Buongiorno, signore.</span>」==
> - 「<span lang="it">Come stai, signora?</span>」ではなく「<span lang="it">Come sta, signora?</span>」
> - 「<span lang="it">Mi chiamo è Kenta.</span>」ではなく「<span lang="it">Mi chiamo Kenta.</span>」

| 誤 | 正 | 理由 |
|---|---|---|
| <span lang="it">Ciao, signore.</span> | <span lang="it">Buongiorno, signore.</span> | <span lang="it">ciao</span> は親しい相手向けです。 |
| <span lang="it">Come stai, signora?</span> | <span lang="it">Come sta, signora?</span> | <span lang="it">signora</span> と呼ぶ相手には <span lang="it">Lei</span> の形 <span lang="it">sta</span> を使います。 |
| <span lang="it">Mi chiamo è Kenta.</span> | <span lang="it">Mi chiamo Kenta.</span> | <span lang="it">mi chiamo</span> だけで「〜という名前です」になるので、<span lang="it">è</span> は付けません。 |

## よくある質問

### 「こんばんは」はイタリア語で何と言いますか

==「<span lang="it">Buonasera.</span>」（ブォナセーラ）==。午後のある時間から <span lang="it">Buonasera</span> に変わります。店に入るときにも使います。

### 別れるときは、何と言いますか

「<span lang="it">A domani.</span>」（ア・ドマーニ）。意味は「また明日」です。<span lang="it">a</span> ＋時を表す語で「また〜に」です。

### 「<span lang="it">Lei</span> と <span lang="it">tu</span>」では、何を押さえればよいですか

イタリア語には「あなた」が二つあります。知らない人・店の人・目上の人には <span lang="it">Lei</span>（丁寧）、家族や友人には <span lang="it">tu</span>（親しい）。

### 「<span lang="it">Ciao, signore.</span>」はなぜ間違いですか

正しくは「<span lang="it">Buongiorno, signore.</span>」です。<span lang="it">ciao</span> は親しい相手向けです。
