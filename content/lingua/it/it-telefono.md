## 要点

- ==電話は <span lang="it">Pronto?</span> で始まる==
- 予約は <span lang="it">Vorrei prenotare un tavolo per due per sabato alle otto.</span>
- 聞き取れないときは <span lang="it">Può ripetere, per favore?</span>

### 解説

- **<span lang="it">Pronto, buonasera.</span>**：電話では <span lang="it">pronto</span>（もしもし）と言います。
- **<span lang="it">Vorrei prenotare un tavolo.</span>**：<span lang="it">prenotare</span> は「予約する」です。
- **<span lang="it">Per sabato sera.</span>**：予約の日は <span lang="it">per</span> ＋曜日で言います。
- **<span lang="it">A nome Tanaka. Ti, a, enne, a, cappa, a.</span>**：アルファベットはイタリア語の読み方で一文字ずつ伝えます。
- **<span lang="it">Può ripetere, per favore?</span>**：<span lang="it">ripetere</span> は「繰り返す」です。
- **<span lang="it">Può parlare più lentamente?</span>**：<span lang="it">più lentamente</span> で「もっとゆっくり」です。
- **<span lang="it">Il mio numero è tre tre tre, uno due tre, quattro cinque sei sette.</span>**：番号は一桁ずつ区切って読みます。

## 文法ポイント

> 要点
>
> - ==予約の <span lang="it">per</span>・<span lang="it">alle</span>・<span lang="it">a nome</span>==

予約では、人数を <span lang="it">per</span>（<span lang="it">per due persone</span>）、日にちも <span lang="it">per</span>（<span lang="it">per sabato</span>）、時刻を <span lang="it">alle</span>（<span lang="it">alle otto</span>）、名前を <span lang="it">a nome</span>（<span lang="it">a nome Tanaka</span>）で伝えます。<span lang="it">Vorrei prenotare un tavolo per quattro per domani alle nove.</span> のように並べれば一文で伝わります。

| 例文 | 日本語 |
|---|---|
| <span lang="it">Un tavolo per quattro.</span> | 4名の席を。 |
| <span lang="it">Per domani alle nove.</span> | 明日の9時に。 |
| <span lang="it">A nome Rossi.</span> | ロッシの名前で。 |

## 文化メモ

> 要点
>
> - ==イタリアでは電話に出るとき <span lang="it">Pronto?</span> と言います。==

人気のトラットリアは週末の夜にすぐ埋まるので、電話で予約しておくと安心です。夕食は8時ごろからが一般的で、日本より遅めに始まります。

## よくある間違い

> 要点
>
> - ==「<span lang="it">Vorrei prenoto un tavolo.</span>」ではなく「<span lang="it">Vorrei prenotare un tavolo.</span>」==
> - 「<span lang="it">Per due persone a le otto.</span>」ではなく「<span lang="it">Per due persone alle otto.</span>」
> - 「<span lang="it">Può ripete?</span>」ではなく「<span lang="it">Può ripetere?</span>」

| 誤 | 正 | 理由 |
|---|---|---|
| <span lang="it">Vorrei prenoto un tavolo.</span> | <span lang="it">Vorrei prenotare un tavolo.</span> | <span lang="it">vorrei</span> のあとは原形です。 |
| <span lang="it">Per due persone a le otto.</span> | <span lang="it">Per due persone alle otto.</span> | <span lang="it">a</span> と <span lang="it">le</span> は <span lang="it">alle</span> と1語にします。 |
| <span lang="it">Può ripete?</span> | <span lang="it">Può ripetere?</span> | <span lang="it">può</span> のあとは原形です。 |

## よくある質問

### 「もしもし、こんばんは」はイタリア語で何と言いますか

==「<span lang="it">Pronto, buonasera.</span>」（プロント・ブォナセーラ）==。電話では <span lang="it">pronto</span>（もしもし）と言います。

### キャンセルするときは、何と言いますか

「<span lang="it">Vorrei disdire la prenotazione.</span>」（ヴォッレイ・ディズディーレ・ラ・プレノタツィオーネ）。意味は「予約を取り消したいのですが」です。<span lang="it">vorrei</span> のあとは原形です。<span lang="it">disdire</span> は「取り消す」です。

### 「予約の <span lang="it">per</span>・<span lang="it">alle</span>・<span lang="it">a nome</span>」では、何を押さえればよいですか

予約では、人数を <span lang="it">per</span>（<span lang="it">per due persone</span>）、日にちも <span lang="it">per</span>（<span lang="it">per sabato</span>）、時刻を <span lang="it">alle</span>（<span lang="it">alle otto</span>）、名前を <span lang="it">a nome</span>（<span lang="it">a nome Tanaka</span>）で伝えます。<span lang="it">Vorrei prenotare un tavolo per quattro per domani alle nove.</span> のように並べれば一文で伝わります。

### 「<span lang="it">Vorrei prenoto un tavolo.</span>」はなぜ間違いですか

正しくは「<span lang="it">Vorrei prenotare un tavolo.</span>」です。<span lang="it">vorrei</span> のあとは原形です。
