## 要点

- ==声をかけて <span lang="it">Scusi, dov'è</span> 〜? / <span lang="it">Come arrivo a</span> 〜?==
- 案内は <span lang="it">Vada sempre dritto.</span> / <span lang="it">Giri a destra.</span>（<span lang="it">Lei</span> への命令形）
- 距離は <span lang="it">È a cinque minuti a piedi.</span> のように歩く時間で返ってくることが多い

### 解説

- **<span lang="it">Scusi, dov'è Piazza Maggiore?</span>**：<span lang="it">dov'è</span> で場所を尋ねます。
- **<span lang="it">È lontano da qui?</span>**：<span lang="it">lontano</span> は「遠い」、<span lang="it">vicino</span> は「近い」です。
- **<span lang="it">È a cinque minuti a piedi.</span>**：<span lang="it">a piedi</span> で「歩いて」です。
- **<span lang="it">Giri a destra al semaforo.</span>**：<span lang="it">giri</span> は <span lang="it">Lei</span> に対する「曲がって」です。
- **<span lang="it">Prenda la seconda a sinistra.</span>**：<span lang="it">la seconda</span> で「2つ目の道」です。
- **<span lang="it">È di fronte alla chiesa.</span>**：<span lang="it">di fronte a</span> 〜 で「〜の向かい」です。
- **<span lang="it">Me lo può indicare sulla mappa?</span>**：<span lang="it">indicare</span> は「指し示す」です。

## 文法ポイント

> 要点
>
> - ==道案内の命令形（<span lang="it">Lei</span>）==
> - 「<span lang="it">Giri a sinistra.</span>」<span lang="it">Lei</span> に対する形は <span lang="it">giri</span> です。

道案内は <span lang="it">Lei</span> に対する命令形で返ってきます。<span lang="it">-are</span> の動詞は <span lang="it">-i</span>（<span lang="it">girare</span> → <span lang="it">giri</span>）、<span lang="it">-ere</span>・<span lang="it">-ire</span> の動詞は <span lang="it">-a</span>（<span lang="it">prendere</span> → <span lang="it">prenda</span>）になり、<span lang="it">andare</span> は <span lang="it">vada</span> です。丁寧な依頼の形なので、失礼には聞こえません。

| 例文 | 日本語 | ポイント |
|---|---|---|
| <span lang="it">Giri a sinistra.</span> | 左に曲がってください。 | <span lang="it">Lei</span> に対する形は <span lang="it">giri</span> です。 |
| <span lang="it">Prenda via Rizzoli.</span> | リッツォーリ通りを行ってください。 |  |
| <span lang="it">Attraversi la piazza.</span> | 広場を渡ってください。 |  |

## 文化メモ

> 要点
>
> - ==ボローニャの旧市街は、歩道を覆う柱廊（ポルティコ）が長く続き、雨の日も傘なしで歩けます。==

ボローニャのポルティコは2021年にユネスコの世界遺産に登録されました。マッジョーレ広場は旧市街の中心で、サン・ペトロニオ聖堂に面しています。

## よくある間違い

> 要点
>
> - ==「<span lang="it">Come arrivo a la stazione?</span>」ではなく「<span lang="it">Come arrivo alla stazione?</span>」==
> - 「<span lang="it">Vada sempre dritta.</span>」ではなく「<span lang="it">Vada sempre dritto.</span>」
> - 「<span lang="it">È cinque minuti a piedi.</span>」ではなく「<span lang="it">È a cinque minuti a piedi.</span>」

| 誤 | 正 | 理由 |
|---|---|---|
| <span lang="it">Come arrivo a la stazione?</span> | <span lang="it">Come arrivo alla stazione?</span> | <span lang="it">a</span> と <span lang="it">la</span> は <span lang="it">alla</span> と1語にします。 |
| <span lang="it">Vada sempre dritta.</span> | <span lang="it">Vada sempre dritto.</span> | 「まっすぐ」は副詞なので <span lang="it">dritto</span> のままです。 |
| <span lang="it">È cinque minuti a piedi.</span> | <span lang="it">È a cinque minuti a piedi.</span> | 距離は <span lang="it">a</span> ＋時間で言います。 |

## よくある質問

### 「すみません、マッジョーレ広場はどこですか」はイタリア語で何と言いますか

==「<span lang="it">Scusi, dov'è Piazza Maggiore?</span>」（スクーズィ・ドヴェ・ピアッツァ・マッジョーレ）==。<span lang="it">dov'è</span> で場所を尋ねます。

### 迷ったときは、何と言いますか

「<span lang="it">Mi sono perso.</span>」（ミ・ソーノ・ペルソ）。意味は「道に迷いました」です。男性は <span lang="it">perso</span>、女性は <span lang="it">persa</span> です。

### 「道案内の命令形（<span lang="it">Lei</span>）」では、何を押さえればよいですか

道案内は <span lang="it">Lei</span> に対する命令形で返ってきます。<span lang="it">-are</span> の動詞は <span lang="it">-i</span>（<span lang="it">girare</span> → <span lang="it">giri</span>）、<span lang="it">-ere</span>・<span lang="it">-ire</span> の動詞は <span lang="it">-a</span>（<span lang="it">prendere</span> → <span lang="it">prenda</span>）になり、<span lang="it">andare</span> は <span lang="it">vada</span> です。

### 「<span lang="it">Come arrivo a la stazione?</span>」はなぜ間違いですか

正しくは「<span lang="it">Come arrivo alla stazione?</span>」です。<span lang="it">a</span> と <span lang="it">la</span> は <span lang="it">alla</span> と1語にします。
