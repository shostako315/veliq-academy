## 要点

- ==値段は <span lang="it">Quanto costa?</span>（1つ）/ <span lang="it">Quanto costano?</span>（複数）で聞く==
- <span lang="it">euro</span> は複数でも形が変わらない（<span lang="it">un euro</span>、<span lang="it">due euro</span>）。セントは <span lang="it">centesimi</span>
- €4,50 は <span lang="it">quattro euro e cinquanta</span> と読む。小数点はコンマで書く

## キーフレーズ

> 要点
>
> - ==「<span lang="it">Quanto costa?</span>」1つのものには <span lang="it">costa</span>、複数なら <span lang="it">costano</span> です。==
> - 「<span lang="it">Due caffè, per favore.</span>」2は <span lang="it">due</span> です。<span lang="it">caffè</span> は複数でも形が変わりません。
> - 「<span lang="it">Posso pagare con la carta?</span>」支払いの手段は <span lang="it">con</span> で表します。

| イタリア語 | 読み | 日本語 | 使う場面 |
|---|---|---|---|
| <span lang="it">Quanto costa?</span> | クアント・コスタ | いくらですか。 | 値段を聞くとき（1つ） |
| <span lang="it">Quanto costano queste pesche?</span> | クアント・コスターノ・クエステ・ペスケ | この桃はいくらですか。 | 複数のものの値段を聞くとき |
| <span lang="it">Sono quattro euro e cinquanta.</span> | ソーノ・クアットロ・エウロ・エ・チンクアンタ | 4ユーロ50セントです。 | 値段を言うとき |
| <span lang="it">Due caffè, per favore.</span> | ドゥエ・カッフェ・ペル・ファヴォーレ | コーヒーを2つください。 | 数を伝えて注文するとき |
| <span lang="it">Posso pagare con la carta?</span> | ポッソ・パガーレ・コン・ラ・カルタ | カードで払えますか。 | 会計のとき |
| <span lang="it">Accettate carte di credito?</span> | アッチェッターテ・カルテ・ディ・クレーディト | クレジットカードは使えますか。 | 店で確かめるとき |
| <span lang="it">Pago in contanti.</span> | パーゴ・イン・コンタンティ | 現金で払います。 | 現金で払うとき |
| <span lang="it">Mi può fare lo scontrino?</span> | ミ・プオ・ファーレ・ロ・スコントリーノ | レシートをいただけますか。 | レシートがほしいとき |
| <span lang="it">È troppo caro.</span> | エ・トロッポ・カーロ | 高すぎます。 | 値段の感想 |
| <span lang="it">Tenga il resto.</span> | テンガ・イル・レスト | おつりは取っておいてください。 | おつりを断るとき |

### 解説

- **<span lang="it">Quanto costano queste pesche?</span>**：<span lang="it">pesche</span> は複数なので <span lang="it">costano</span> です。
- **<span lang="it">Sono quattro euro e cinquanta.</span>**：<span lang="it">euro</span> は複数でも <span lang="it">euro</span> のままです。
- **<span lang="it">Accettate carte di credito?</span>**：<span lang="it">carta</span> の複数形は <span lang="it">carte</span> です。
- **<span lang="it">Pago in contanti.</span>**：現金は <span lang="it">in contanti</span> です。
- **<span lang="it">Mi può fare lo scontrino?</span>**：<span lang="it">scontrino</span> はレシートです。
- **<span lang="it">È troppo caro.</span>**：<span lang="it">caro</span> は「高い」。女性名詞を指すなら <span lang="it">cara</span> です。
- **<span lang="it">Tenga il resto.</span>**：<span lang="it">tenga</span> は <span lang="it">Lei</span> に対する「取っておいて」です。

## 文法ポイント

> 要点
>
> - ==名詞の複数形==

イタリア語の名詞は、語尾を変えて複数にします。<span lang="it">-o</span> は <span lang="it">-i</span>（<span lang="it">biglietto</span> → <span lang="it">biglietti</span>）、<span lang="it">-a</span> は <span lang="it">-e</span>（<span lang="it">pesca</span> → <span lang="it">pesche</span>）、<span lang="it">-e</span> は <span lang="it">-i</span>（<span lang="it">bicchiere</span> → <span lang="it">bicchieri</span>）。<span lang="it">caffè</span> のように最後にアクセントがある語や、<span lang="it">euro</span> は複数でも形が変わりません。

| 例文 | 日本語 |
|---|---|
| <span lang="it">Due biglietti, per favore.</span> | 切符を2枚ください。 |
| <span lang="it">Tre bicchieri d'acqua.</span> | お水を3杯。 |
| <span lang="it">Sono dieci euro.</span> | 10ユーロです。 |

## 文化メモ

> 要点
>
> - ==イタリアのバールや店では、会計のあとにレシート（<span lang="it">scontrino</span>）が渡されます。==

値段は €4,50 のように小数点をコンマで書きます。カードはほとんどの店で使えますが、市場の小さな店などでは現金のほうが確実です。

## よくある間違い

> 要点
>
> - ==「<span lang="it">Due euros.</span>」ではなく「<span lang="it">Due euro.</span>」==
> - 「<span lang="it">Quanto costa questi?</span>」ではなく「<span lang="it">Quanto costano questi?</span>」
> - 「<span lang="it">Posso pagare per carta?</span>」ではなく「<span lang="it">Posso pagare con la carta?</span>」

| 誤 | 正 | 理由 |
|---|---|---|
| <span lang="it">Due euros.</span> | <span lang="it">Due euro.</span> | <span lang="it">euro</span> は複数でも形が変わりません。 |
| <span lang="it">Quanto costa questi?</span> | <span lang="it">Quanto costano questi?</span> | 複数のものには <span lang="it">costano</span> です。 |
| <span lang="it">Posso pagare per carta?</span> | <span lang="it">Posso pagare con la carta?</span> | 手段は <span lang="it">con</span> で表します。 |

## よくある質問

### 「いくらですか」はイタリア語で何と言いますか

==「<span lang="it">Quanto costa?</span>」（クアント・コスタ）==。1つのものには <span lang="it">costa</span>、複数なら <span lang="it">costano</span> です。

### おつりを断るときは、何と言いますか

「<span lang="it">Tenga il resto.</span>」（テンガ・イル・レスト）。意味は「おつりは取っておいてください」です。<span lang="it">tenga</span> は <span lang="it">Lei</span> に対する「取っておいて」です。

### 「名詞の複数形」では、何を押さえればよいですか

イタリア語の名詞は、語尾を変えて複数にします。<span lang="it">-o</span> は <span lang="it">-i</span>（<span lang="it">biglietto</span> → <span lang="it">biglietti</span>）、<span lang="it">-a</span> は <span lang="it">-e</span>（<span lang="it">pesca</span> → <span lang="it">pesche</span>）、<span lang="it">-e</span> は <span lang="it">-i</span>（<span lang="it">bicchiere</span> → <span lang="it">bicchieri</span>）。

### 「<span lang="it">Due euros.</span>」はなぜ間違いですか

正しくは「<span lang="it">Due euro.</span>」です。<span lang="it">euro</span> は複数でも形が変わりません。
