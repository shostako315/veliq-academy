## 要点

- ==名前は <span lang="it">Mi chiamo</span> 〜.、出身は <span lang="it">Sono giapponese.</span> / <span lang="it">Sono di Tokyo.</span>==
- 仕事は <span lang="it">Faccio il consulente.</span> / <span lang="it">Lavoro in banca.</span>
- 楽器は <span lang="it">suonare</span> を使う：<span lang="it">Suono il violino.</span>

## キーフレーズ

> 要点
>
> - ==「<span lang="it">Sono giapponese.</span>」国籍の形容詞は小文字で書きます。==
> - 「<span lang="it">Abito a Musashino, vicino a Tokyo.</span>」町の名前の前は <span lang="it">a</span> です（国なら <span lang="it">in</span>）。
> - 「<span lang="it">Lavoro in banca.</span>」<span lang="it">in banca</span> は冠詞なしで「銀行で」です。

| イタリア語 | 読み | 日本語 | 使う場面 |
|---|---|---|---|
| <span lang="it">Mi chiamo Kenta Tanaka.</span> | ミ・キアーモ・ケンタ・タナカ | 田中健太と申します。 | 名乗るとき |
| <span lang="it">Sono giapponese.</span> | ソーノ・ジャッポネーゼ | 日本人です。 | 国籍を言うとき |
| <span lang="it">Sono di Tokyo.</span> | ソーノ・ディ・トーキョー | 東京の出身です。 | 出身地を言うとき |
| <span lang="it">Abito a Musashino, vicino a Tokyo.</span> | アービト・ア・ムサシノ・ヴィチーノ・ア・トーキョー | 東京の近くの武蔵野に住んでいます。 | 住まいを言うとき |
| <span lang="it">Faccio il consulente.</span> | ファッチョ・イル・コンスレンテ | コンサルタントをしています。 | 仕事を言うとき |

| <span lang="it">E Lei, di dov'è?</span> | エ・レイ・ディ・ドヴェ | あなたはどちらのご出身ですか。 | 相手の出身を聞くとき |
| <span lang="it">Che lavoro fa?</span> | ケ・ラヴォーロ・ファ | お仕事は何ですか。 | 相手の仕事を聞くとき |

### 解説

- **<span lang="it">Mi chiamo Kenta Tanaka.</span>**：<span lang="it">chiamarsi</span>（〜という名前だ）を使います。
- **<span lang="it">Sono di Tokyo.</span>**：出身の町は <span lang="it">di</span> で言います。
- **<span lang="it">Faccio il consulente.</span>**：<span lang="it">fare</span> ＋定冠詞＋職業で「〜をしている」です。
- **<span lang="it">Suono il violino.</span>**：楽器を演奏するのは <span lang="it">suonare</span> です（スポーツは <span lang="it">giocare</span>）。
- **<span lang="it">Sono qui in vacanza.</span>**：<span lang="it">in vacanza</span> で「休暇で」です。
- **<span lang="it">Parlo un po' d'italiano.</span>**：<span lang="it">un po'</span> は <span lang="it">un poco</span> を短くした形です。
- **<span lang="it">E Lei, di dov'è?</span>**：<span lang="it">Lei</span> に対しては <span lang="it">è</span> を使います。
- **<span lang="it">Che lavoro fa?</span>**：<span lang="it">Lei</span> に対する <span lang="it">fa</span>（する）です。

## 文法ポイント

> 要点
>
> - ==動詞の「私」の形（<span lang="it">-o</span>）==

イタリア語の動詞は、主語によって語尾が変わります。「私は〜する」は多くが <span lang="it">-o</span> で終わる形です（<span lang="it">abitare</span> → <span lang="it">abito</span>、<span lang="it">lavorare</span> → <span lang="it">lavoro</span>、<span lang="it">parlare</span> → <span lang="it">parlo</span>）。主語の <span lang="it">io</span> は動詞の形で分かるので、ふつうは省きます。

| 例文 | 日本語 |
|---|---|
| <span lang="it">Lavoro a Tokyo.</span> | 東京で働いています。 |
| <span lang="it">Parlo inglese.</span> | 英語を話します。 |
| <span lang="it">Abito vicino alla stazione.</span> | 駅の近くに住んでいます。 |

## 文化メモ

> 要点
>
> - ==イタリアでは自己紹介のあとに <span lang="it">Piacere.</span> と言って握手をするのがふつうです。==

仕事を言うときは <span lang="it">Faccio il medico.</span>（医者をしています）のように <span lang="it">fare</span> を使う言い方がよく聞かれます。国籍や言語の名前は、英語と違って小文字で書き始めます。

## よくある間違い

> 要点
>
> - ==「<span lang="it">Sono Giapponese.</span>」ではなく「<span lang="it">Sono giapponese.</span>」==
> - 「<span lang="it">Gioco il violino.</span>」ではなく「<span lang="it">Suono il violino.</span>」
> - 「<span lang="it">Abito in Tokyo.</span>」ではなく「<span lang="it">Abito a Tokyo.</span>」

| 誤 | 正 | 理由 |
|---|---|---|
| <span lang="it">Sono Giapponese.</span> | <span lang="it">Sono giapponese.</span> | 国籍は小文字で書き始めます。 |
| <span lang="it">Gioco il violino.</span> | <span lang="it">Suono il violino.</span> | 楽器の演奏は <span lang="it">suonare</span> です。<span lang="it">giocare</span> はスポーツやゲームです。 |
| <span lang="it">Abito in Tokyo.</span> | <span lang="it">Abito a Tokyo.</span> | 町の名前の前は <span lang="it">a</span> です。 |

## よくある質問

### 「田中健太と申します」はイタリア語で何と言いますか

==「<span lang="it">Mi chiamo Kenta Tanaka.</span>」（ミ・キアーモ・ケンタ・タナカ）==。<span lang="it">chiamarsi</span>（〜という名前だ）を使います。

### 相手の仕事を聞くときは、何と言いますか

「<span lang="it">Che lavoro fa?</span>」（ケ・ラヴォーロ・ファ）。意味は「お仕事は何ですか」です。<span lang="it">Lei</span> に対する <span lang="it">fa</span>（する）です。

### 「動詞の「私」の形（<span lang="it">-o</span>）」では、何を押さえればよいですか

イタリア語の動詞は、主語によって語尾が変わります。「私は〜する」は多くが <span lang="it">-o</span> で終わる形です（<span lang="it">abitare</span> → <span lang="it">abito</span>、<span lang="it">lavorare</span> → <span lang="it">lavoro</span>、<span lang="it">parlare</span> → <span lang="it">parlo</span>）。

### 「<span lang="it">Sono Giapponese.</span>」はなぜ間違いですか

正しくは「<span lang="it">Sono giapponese.</span>」です。国籍は小文字で書き始めます。
