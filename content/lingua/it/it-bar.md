## 要点

- ==注文は <span lang="it">Un caffè, per favore.</span> / <span lang="it">Vorrei un cappuccino.</span>。<span lang="it">un caffè</span> はエスプレッソのこと==
- 店によっては先にレジ（<span lang="it">cassa</span>）で払い、レシート（<span lang="it">scontrino</span>）をカウンターで見せて注文する
- カウンター（<span lang="it">al banco</span>）と席（<span lang="it">al tavolo</span>）で値段が違う店がある

## キーフレーズ

> 要点
>
> - ==「<span lang="it">Vorrei un cappuccino.</span>」<span lang="it">cappuccino</span> は男性名詞なので <span lang="it">un</span> です。==
> - 「<span lang="it">E una brioche, per favore.</span>」<span lang="it">brioche</span> は女性名詞なので <span lang="it">una</span> です。
> - 「<span lang="it">Quanto Le devo?</span>」「私があなたにいくら払うべきか」の形で、<span lang="it">devo</span>（私が）です。

### 解説

- **<span lang="it">Un caffè, per favore.</span>**：イタリアで <span lang="it">caffè</span> と言えばエスプレッソです。
- **<span lang="it">Un caffè macchiato, per favore.</span>**：<span lang="it">macchiato</span> は「しみの付いた」。少量のミルクを落としたエスプレッソです。
- **<span lang="it">Un bicchiere d'acqua, per favore.</span>**：<span lang="it">d'acqua</span> は <span lang="it">di acqua</span> の短い形です。
- **<span lang="it">Pago alla cassa?</span>**：<span lang="it">cassa</span> はレジです。
- **<span lang="it">Al banco o al tavolo?</span>**：<span lang="it">al banco</span> はカウンターで立って飲むことです。
- **<span lang="it">Al banco, grazie.</span>**：短く答えれば十分です。
- **<span lang="it">Un cornetto alla crema, per favore.</span>**：<span lang="it">alla crema</span> で「クリーム入りの」です（<span lang="it">crema</span> は女性名詞）。

## 文法ポイント

> 要点
>
> - ==不定冠詞 <span lang="it">un</span>・<span lang="it">una</span>・<span lang="it">uno</span>・<span lang="it">un'</span>==
> - 「<span lang="it">Uno spritz, per favore.</span>」<span lang="it">s</span> ＋子音で始まる男性名詞なので <span lang="it">uno</span> です。

「1つの」にあたる不定冠詞は、名詞の性と最初の音で変わります。男性名詞はふつう <span lang="it">un</span>（<span lang="it">un caffè</span>）、<span lang="it">s</span> ＋子音や <span lang="it">z</span> で始まる男性名詞は <span lang="it">uno</span>（<span lang="it">uno spritz</span>）、女性名詞は <span lang="it">una</span>（<span lang="it">una brioche</span>）、母音で始まる女性名詞は <span lang="it">un'</span>（<span lang="it">un'aranciata</span>）です。

| 例文 | 日本語 | ポイント |
|---|---|---|
| <span lang="it">Uno spritz, per favore.</span> | スプリッツを1杯。 | <span lang="it">s</span> ＋子音で始まる男性名詞なので <span lang="it">uno</span> です。 |
| <span lang="it">Un'aranciata, per favore.</span> | オレンジソーダを1つ。 |  |

## 文化メモ

> 要点
>
> - ==イタリアのバールでは、エスプレッソをカウンターで立ったまま短い時間で飲むのが日常の風景です。==

カウンターと席で料金が違う店があり、席に座ると高くなります。カプチーノは朝に飲むものと考える人が多く、食後にはエスプレッソを頼むのがふつうです。

## よくある間違い

> 要点
>
> - ==「<span lang="it">Un latte, per favore.（コーヒーのつもりで）</span>」ではなく「<span lang="it">Un caffellatte, per favore.</span>」==
> - 「<span lang="it">Una cappuccino.</span>」ではなく「<span lang="it">Un cappuccino.</span>」
> - 「<span lang="it">Voglio un caffè.</span>」ではなく「<span lang="it">Vorrei un caffè.</span>」

| 誤 | 正 | 理由 |
|---|---|---|
| <span lang="it">Un latte, per favore.（コーヒーのつもりで）</span> | <span lang="it">Un caffellatte, per favore.</span> | <span lang="it">latte</span> は「牛乳」です。コーヒー入りは <span lang="it">caffellatte</span> です。 |
| <span lang="it">Una cappuccino.</span> | <span lang="it">Un cappuccino.</span> | <span lang="it">cappuccino</span> は男性名詞なので <span lang="it">un</span> です。 |
| <span lang="it">Voglio un caffè.</span> | <span lang="it">Vorrei un caffè.</span> | <span lang="it">voglio</span> は強く聞こえます。<span lang="it">vorrei</span> が丁寧です。 |

## よくある質問

### 「エスプレッソを1杯ください」はイタリア語で何と言いますか

==「<span lang="it">Un caffè, per favore.</span>」（ウン・カッフェ・ペル・ファヴォーレ）==。イタリアで <span lang="it">caffè</span> と言えばエスプレッソです。

### パンの中身を選ぶときは、何と言いますか

「<span lang="it">Un cornetto alla crema, per favore.</span>」（ウン・コルネット・アッラ・クレーマ）。意味は「カスタードのコルネットを1つ」です。<span lang="it">alla crema</span> で「クリーム入りの」です（<span lang="it">crema</span> は女性名詞）。

### 「不定冠詞 <span lang="it">un</span>・<span lang="it">una</span>・<span lang="it">uno</span>・<span lang="it">un'</span>」では、何を押さえればよいですか

「1つの」にあたる不定冠詞は、名詞の性と最初の音で変わります。男性名詞はふつう <span lang="it">un</span>（<span lang="it">un caffè</span>）、<span lang="it">s</span> ＋子音や <span lang="it">z</span> で始まる男性名詞は <span lang="it">uno</span>（<span lang="it">uno spritz</span>）、女性名詞は <span lang="it">una</span>（<span lang="it">una brioche</span>）、母音で始まる女性名詞は <span lang="it">un'</span>（<span lang="it">un'aranciata</span>）です。

### 「<span lang="it">Un latte, per favore.（コーヒーのつもりで）</span>」はなぜ間違いですか

正しくは「<span lang="it">Un caffellatte, per favore.</span>」です。<span lang="it">latte</span> は「牛乳」です。コーヒー入りは <span lang="it">caffellatte</span> です。
