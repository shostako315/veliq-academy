## 要点

- ==予約は <span lang="it">Ho una prenotazione a nome Tanaka.</span>==
- 設備は <span lang="it">C'è</span> 〜? / <span lang="it">Ci sono</span> 〜? で聞く
- チェックインでは身分証を求められ、多くの町で滞在税がかかる

## キーフレーズ

> 要点
>
> - ==「<span lang="it">Ho una prenotazione a nome Tanaka.</span>」予約名は <span lang="it">a nome</span> 〜 です。==
> - 「<span lang="it">C'è l'ascensore?</span>」1つのものには <span lang="it">c'è</span> です。
> - 「<span lang="it">L'aria condizionata non funziona.</span>」主語が1つなので <span lang="it">funziona</span> です。

### 解説

- **<span lang="it">Per tre notti.</span>**：<span lang="it">notte</span> の複数は <span lang="it">notti</span> です。
- **<span lang="it">A che ora è la colazione?</span>**：<span lang="it">colazione</span> は朝食です。
- **<span lang="it">Posso lasciare i bagagli qui?</span>**：<span lang="it">lasciare</span> は「置いていく」です。
- **<span lang="it">Qual è la password del Wi-Fi?</span>**：<span lang="it">qual è</span> はアポストロフィを付けずに書きます。
- **<span lang="it">La colazione è inclusa?</span>**：<span lang="it">colazione</span> は女性名詞なので <span lang="it">inclusa</span> です。
- **<span lang="it">Posso pagare la tassa di soggiorno con la carta?</span>**：<span lang="it">tassa di soggiorno</span> は1泊ごとにかかる税です。
- **<span lang="it">A che ora devo lasciare la camera?</span>**：<span lang="it">devo</span> ＋動詞で「〜しなければならない」です。

## 文法ポイント

> 要点
>
> - ==<span lang="it">c'è</span> と <span lang="it">ci sono</span>==

「〜がある」は、1つのものなら <span lang="it">c'è</span>（<span lang="it">ci è</span>）、複数なら <span lang="it">ci sono</span> です。疑問文も同じ形で、語尾を上げて言います。<span lang="it">C'è un ristorante qui vicino?</span>（近くにレストランはありますか）

| 例文 | 日本語 |
|---|---|
| <span lang="it">C'è una farmacia qui vicino?</span> | 近くに薬局はありますか。 |
| <span lang="it">Ci sono asciugamani in camera?</span> | 部屋にタオルはありますか。 |
| <span lang="it">C'è il Wi-Fi in camera?</span> | 部屋に Wi-Fi はありますか。 |

## 文化メモ

> 要点
>
> - ==イタリアのホテルでは、チェックインのときにパスポートなどの身分証を見せる決まりがあります。==

フィレンツェやボローニャなど多くの町では、1泊ごとに滞在税（<span lang="it">tassa di soggiorno</span>）がかかり、宿泊料とは別にホテルで払います。地上階は <span lang="it">pianterreno</span> で、その上が <span lang="it">primo piano</span>（日本の2階）です。

## よくある間違い

> 要点
>
> - ==「<span lang="it">Ho prenotato per tre notte.</span>」ではなく「<span lang="it">Ho prenotato per tre notti.</span>」==
> - 「<span lang="it">Qual'è la password?</span>」ではなく「<span lang="it">Qual è la password?</span>」
> - 「<span lang="it">Ci sono l'ascensore?</span>」ではなく「<span lang="it">C'è l'ascensore?</span>」

| 誤 | 正 | 理由 |
|---|---|---|
| <span lang="it">Ho prenotato per tre notte.</span> | <span lang="it">Ho prenotato per tre notti.</span> | 3泊は複数なので <span lang="it">notti</span> です。 |
| <span lang="it">Qual'è la password?</span> | <span lang="it">Qual è la password?</span> | <span lang="it">qual è</span> にはアポストロフィを付けません。 |
| <span lang="it">Ci sono l'ascensore?</span> | <span lang="it">C'è l'ascensore?</span> | 1つのものには <span lang="it">c'è</span> です。 |

## よくある質問

### 「田中の名前で予約しています」はイタリア語で何と言いますか

==「<span lang="it">Ho una prenotazione a nome Tanaka.</span>」（オ・ウナ・プレノタツィオーネ・ア・ノーメ・タナカ）==。予約名は <span lang="it">a nome</span> 〜 です。

### チェックアウトの時間を聞くときは、何と言いますか

「<span lang="it">A che ora devo lasciare la camera?</span>」（ア・ケ・オーラ・デーヴォ・ラッシャーレ・ラ・カーメラ）。意味は「何時までに部屋を出ればいいですか」です。<span lang="it">devo</span> ＋動詞で「〜しなければならない」です。

### 「<span lang="it">c'è</span> と <span lang="it">ci sono</span>」では、何を押さえればよいですか

「〜がある」は、1つのものなら <span lang="it">c'è</span>（<span lang="it">ci è</span>）、複数なら <span lang="it">ci sono</span> です。疑問文も同じ形で、語尾を上げて言います。

### 「<span lang="it">Ho prenotato per tre notte.</span>」はなぜ間違いですか

正しくは「<span lang="it">Ho prenotato per tre notti.</span>」です。3泊は複数なので <span lang="it">notti</span> です。
