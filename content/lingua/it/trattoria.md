## 要点

- ==予約は <span lang="it">un tavolo per due a nome Tanaka</span>==
- 料理は <span lang="it">Vorrei</span> 〜 / <span lang="it">Prendo</span> 〜。コースは <span lang="it">antipasto</span>・<span lang="it">primo</span>・<span lang="it">secondo</span>・<span lang="it">contorno</span>・<span lang="it">dolce</span>
- 会計は <span lang="it">Il conto, per favore.</span>。<span lang="it">coperto</span>（席料）が付くことがある

## キーフレーズ

> 要点
>
> - ==「<span lang="it">Avete un tavolo per due?</span>」人数は <span lang="it">per</span> ＋数で言います。==
> - 「<span lang="it">Vorrei le tagliatelle al ragù, per favore.</span>」<span lang="it">tagliatelle</span> は女性の複数形なので <span lang="it">le</span> です。
> - 「<span lang="it">Un'acqua naturale, per favore.</span>」炭酸なしは <span lang="it">naturale</span>、炭酸入りは <span lang="it">frizzante</span> です。

### 解説

- **<span lang="it">Sì, un tavolo per due a nome Tanaka.</span>**：予約名は <span lang="it">a nome</span> 〜 で伝えます。
- **<span lang="it">Possiamo vedere il menù?</span>**：<span lang="it">menù</span> は最後にアクセントがあります。
- **<span lang="it">Cosa ci consiglia?</span>**：<span lang="it">ci</span> は「私たちに」です。
- **<span lang="it">Come secondo, prendo la cotoletta.</span>**：<span lang="it">prendo</span> は「〜にします」と決めるときの言い方です。
- **<span lang="it">Un bicchiere di vino rosso, per favore.</span>**：グラス1杯は <span lang="it">un bicchiere di</span> 〜 です。
- **<span lang="it">Sono allergico alle noci.</span>**：女性なら <span lang="it">allergica</span> です。
- **<span lang="it">Sì, era buonissimo.</span>**：<span lang="it">buonissimo</span> だけで「とてもおいしい」です。<span lang="it">molto</span> は付けません。
- **<span lang="it">Il conto, per favore.</span>**：<span lang="it">conto</span> は会計（勘定）です。

## 文法ポイント

> 要点
>
> - ==定冠詞と <span lang="it">vorrei</span>==
> - 「<span lang="it">Vorrei le lasagne.</span>」<span lang="it">lasagne</span> は女性の複数形なので <span lang="it">le</span> です。

注文では「その料理」を指すので定冠詞を付けます。男性単数 <span lang="it">il</span>（<span lang="it">il ragù</span>）、女性単数 <span lang="it">la</span>（<span lang="it">la cotoletta</span>）、男性複数 <span lang="it">i</span>（<span lang="it">i tortellini</span>）、女性複数 <span lang="it">le</span>（<span lang="it">le tagliatelle</span>）。<span lang="it">tagliatelle</span> や <span lang="it">lasagne</span> は複数形の名詞です。「〜をいただきたい」は <span lang="it">vorrei</span> で、<span lang="it">voglio</span> より柔らかく聞こえます。

| 例文 | 日本語 | ポイント |
|---|---|---|
| <span lang="it">Vorrei le lasagne.</span> | ラザニアをお願いします。 | <span lang="it">lasagne</span> は女性の複数形なので <span lang="it">le</span> です。 |
| <span lang="it">Prendo il risotto.</span> | リゾットにします。 |  |
| <span lang="it">Vorrei i tortellini in brodo.</span> | ブロードのトルテッリーニをお願いします。 |  |

## 文化メモ

> 要点
>
> - ==イタリアのレストランでは、会計に <span lang="it">coperto</span>（席料。パンなどの代金として1人いくら）が加わることがあり、金額はメニューに書かれています。==

チップは義務ではなく、よかったときに小銭を置く程度です。ボローニャでは「スパゲッティ・ボロネーゼ」とは言わず、ラグーは平たい生パスタのタリアテッレで食べます。

## よくある間違い

> 要点
>
> - ==「<span lang="it">Io voglio tagliatelle.</span>」ではなく「<span lang="it">Vorrei le tagliatelle.</span>」==
> - 「<span lang="it">Era molto buonissimo.</span>」ではなく「<span lang="it">Era buonissimo.</span>」
> - 「<span lang="it">Il bill, per favore.</span>」ではなく「<span lang="it">Il conto, per favore.</span>」

| 誤 | 正 | 理由 |
|---|---|---|
| <span lang="it">Io voglio tagliatelle.</span> | <span lang="it">Vorrei le tagliatelle.</span> | <span lang="it">voglio</span> は強く聞こえます。定冠詞も付けます。 |
| <span lang="it">Era molto buonissimo.</span> | <span lang="it">Era buonissimo.</span> | <span lang="it">-issimo</span> だけで「とても」の意味です。 |
| <span lang="it">Il bill, per favore.</span> | <span lang="it">Il conto, per favore.</span> | 会計は <span lang="it">il conto</span> です。 |

## よくある質問

### 「はい、田中の名前で2名です」はイタリア語で何と言いますか

==「<span lang="it">Sì, un tavolo per due a nome Tanaka.</span>」（スィ・ウン・ターヴォロ・ペル・ドゥエ・ア・ノーメ・タナカ）==。予約名は <span lang="it">a nome</span> 〜 で伝えます。

### 会計のときは、何と言いますか

「<span lang="it">Il conto, per favore.</span>」（イル・コント・ペル・ファヴォーレ）。意味は「お会計をお願いします」です。<span lang="it">conto</span> は会計（勘定）です。

### 「定冠詞と <span lang="it">vorrei</span>」では、何を押さえればよいですか

注文では「その料理」を指すので定冠詞を付けます。男性単数 <span lang="it">il</span>（<span lang="it">il ragù</span>）、女性単数 <span lang="it">la</span>（<span lang="it">la cotoletta</span>）、男性複数 <span lang="it">i</span>（<span lang="it">i tortellini</span>）、女性複数 <span lang="it">le</span>（<span lang="it">le tagliatelle</span>）。

### 「<span lang="it">Io voglio tagliatelle.</span>」はなぜ間違いですか

正しくは「<span lang="it">Vorrei le tagliatelle.</span>」です。<span lang="it">voglio</span> は強く聞こえます。定冠詞も付けます。
