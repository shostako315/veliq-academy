## 要点

- ==予約した人は <span lang="it">Ho prenotato online.</span>、当日なら <span lang="it">Un biglietto intero, per favore.</span>==
- 許可は <span lang="it">Si può</span> 〜? で聞く（<span lang="it">Si può fotografare?</span>）
- 大きな荷物は <span lang="it">guardaroba</span>（クローク）に預ける

### 解説

- **<span lang="it">Un biglietto intero, per favore.</span>**：<span lang="it">intero</span> は「割引なしの」です。割引は <span lang="it">ridotto</span> です。
- **<span lang="it">Ho prenotato online.</span>**：<span lang="it">prenotare</span> の過去の形です。
- **<span lang="it">Senza flash, per favore.</span>**：<span lang="it">senza</span> は「〜なしで」です。
- **<span lang="it">Dov'è il guardaroba?</span>**：<span lang="it">dov'è</span> は <span lang="it">dove è</span> の短い形です。
- **<span lang="it">Dove si trova la Primavera di Botticelli?</span>**：<span lang="it">si trova</span> で「〜がある」です。
- **<span lang="it">Qual è l'uscita?</span>**：<span lang="it">uscita</span> は「出口」です。
- **<span lang="it">A che ora chiude il museo?</span>**：<span lang="it">chiudere</span> の3人称 <span lang="it">chiude</span> です。

## 文法ポイント

> 要点
>
> - ==<span lang="it">si può</span> ＋動詞「〜してよいか」==

<span lang="it">si può</span> ＋動詞の原形は「（誰でも）〜してよい」という一般的な許可を表します。自分のことを聞くなら <span lang="it">posso</span> ＋原形（<span lang="it">Posso entrare?</span>）。禁止の表示は <span lang="it">Vietato fotografare</span>（撮影禁止）のように書かれています。

| 例文 | 日本語 |
|---|---|
| <span lang="it">Si può entrare con lo zaino?</span> | リュックを持って入れますか。 |
| <span lang="it">Posso sedermi qui?</span> | ここに座ってもいいですか。 |
| <span lang="it">Non si può mangiare in sala.</span> | 展示室では飲食できません。 |

## 文化メモ

> 要点
>
> - ==ウフィツィ美術館のような人気の美術館は、日時指定の予約をしておくと長い列に並ばずに入れます。==

入口では手荷物の検査があり、大きなリュックはクロークに預けるよう求められます。ウフィツィを含め、国立の美術館の多くは月曜日が休館日です。

## よくある間違い

> 要点
>
> - ==「<span lang="it">Si possono fotografare?</span>」ではなく「<span lang="it">Si può fotografare?</span>」==
> - 「<span lang="it">C'è un audioguida?</span>」ではなく「<span lang="it">C'è un'audioguida?</span>」
> - 「<span lang="it">Posso lascio lo zaino?</span>」ではなく「<span lang="it">Posso lasciare lo zaino?</span>」

| 誤 | 正 | 理由 |
|---|---|---|
| <span lang="it">Si possono fotografare?</span> | <span lang="it">Si può fotografare?</span> | 「〜してよいか」は <span lang="it">si può</span> ＋原形です。 |
| <span lang="it">C'è un audioguida?</span> | <span lang="it">C'è un'audioguida?</span> | <span lang="it">audioguida</span> は女性名詞なので <span lang="it">un'</span> と書きます。 |
| <span lang="it">Posso lascio lo zaino?</span> | <span lang="it">Posso lasciare lo zaino?</span> | <span lang="it">posso</span> のあとは原形です。 |

## よくある質問

### 「一般のチケットを1枚お願いします」はイタリア語で何と言いますか

==「<span lang="it">Un biglietto intero, per favore.</span>」（ウン・ビリエット・インテーロ）==。<span lang="it">intero</span> は「割引なしの」です。割引は <span lang="it">ridotto</span> です。

### 荷物を預けるときは、何と言いますか

「<span lang="it">Posso lasciare lo zaino qui?</span>」（ポッソ・ラッシャーレ・ロ・ザイノ・クイ）。意味は「ここにリュックを置いてもいいですか」です。<span lang="it">posso</span> のあとは原形です。

### 「<span lang="it">si può</span> ＋動詞「〜してよいか」」では、何を押さえればよいですか

<span lang="it">si può</span> ＋動詞の原形は「（誰でも）〜してよい」という一般的な許可を表します。自分のことを聞くなら <span lang="it">posso</span> ＋原形（<span lang="it">Posso entrare?</span>）。

### 「<span lang="it">Si possono fotografare?</span>」はなぜ間違いですか

正しくは「<span lang="it">Si può fotografare?</span>」です。「〜してよいか」は <span lang="it">si può</span> ＋原形です。
