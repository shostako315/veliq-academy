## 要点

- ==声をかけられたら <span lang="en">I'm just looking, thanks.</span> で十分==
- 試着は <span lang="en">Could I try this on?</span>
- 別のサイズは <span lang="en">Do you have this in a smaller size?</span>

## キーフレーズ

> 要点
>
> - ==「<span lang="en">Could I try this on?</span>」<span lang="en">try on</span> で「試着する」です。==
> - 「<span lang="en">Do you have this in a smaller size?</span>」比べるときは <span lang="en">smaller</span> です。
> - 「<span lang="en">Where can I find the food hall?</span>」<span lang="en">Where can I find</span> 〜? で場所を聞けます。

| 英語 | 日本語 | 使う場面 |
|---|---|---|
| <span lang="en">I'm just looking, thanks.</span> | 見ているだけです。ありがとうございます。 | 声をかけられたとき |
| <span lang="en">Could I try this on?</span> | 試着してもいいですか。 | 試着するとき |
| <span lang="en">Where are the fitting rooms?</span> | 試着室はどこですか。 | 試着室を探すとき |
| <span lang="en">Do you have this in a smaller size?</span> | これの小さいサイズはありますか。 | サイズを聞くとき |
| <span lang="en">Do you have it in black?</span> | 黒はありますか。 | 色を聞くとき |
| <span lang="en">It's a bit too big.</span> | 少し大きすぎます。 | 合わないとき |
| <span lang="en">I'll take it.</span> | これをいただきます。 | 買うと決めたとき |
| <span lang="en">Could you gift-wrap it?</span> | 贈り物用に包んでいただけますか。 | 贈り物のとき |
| <span lang="en">Where can I find the food hall?</span> | 食料品売り場はどこですか。 | 売り場を探すとき |
| <span lang="en">Can I return it if it doesn't fit?</span> | 合わなかったら返品できますか。 | 返品を確かめるとき |

### 解説

- **<span lang="en">I'm just looking, thanks.</span>**：断るときも <span lang="en">thanks</span> を添えると感じがよいです。
- **<span lang="en">Where are the fitting rooms?</span>**：イギリスでは <span lang="en">changing rooms</span> とも言います。
- **<span lang="en">Do you have it in black?</span>**：<span lang="en">in</span> ＋色で「〜色の」です。
- **<span lang="en">It's a bit too big.</span>**：<span lang="en">a bit too</span> 〜 で「少し〜すぎる」です。
- **<span lang="en">I'll take it.</span>**：<span lang="en">I'll take it.</span> は買うときの決まった言い方です。
- **<span lang="en">Could you gift-wrap it?</span>**：<span lang="en">gift-wrap</span> は「贈り物用に包む」です。
- **<span lang="en">Can I return it if it doesn't fit?</span>**：<span lang="en">fit</span> は「（サイズが）合う」です。

## 文法ポイント

> 要点
>
> - ==比べる言い方（比較級）==

短い形容詞は <span lang="en">-er</span> を付けて「もっと〜」にします（<span lang="en">small</span> → <span lang="en">smaller</span>、<span lang="en">big</span> → <span lang="en">bigger</span>）。長い形容詞は <span lang="en">more</span> を前に置きます（<span lang="en">more expensive</span>）。比べる相手は <span lang="en">than</span> で示します。

| 例文 | 日本語 |
|---|---|
| <span lang="en">Do you have a bigger one?</span> | もっと大きいものはありますか。 |
| <span lang="en">This one is cheaper.</span> | こちらのほうが安いです。 |
| <span lang="en">It's more expensive than the black one.</span> | 黒いものより高いです。 |

## 文化メモ

> 要点
>
> - ==イギリスの服のサイズは日本と表記が違い、女性服は 8・10・12 のような数字、靴は <span lang="en">UK</span> サイズで表されます。==

試着室の前で、持ち込む枚数を数えて札を渡されることがあります。

## よくある間違い

> 要点
>
> - ==「<span lang="en">Can I try?</span>」ではなく「<span lang="en">Could I try this on?</span>」==
> - 「<span lang="en">Do you have more small size?</span>」ではなく「<span lang="en">Do you have this in a smaller size?</span>」
> - 「<span lang="en">I take this.</span>」ではなく「<span lang="en">I'll take it.</span>」

| 誤 | 正 | 理由 |
|---|---|---|
| <span lang="en">Can I try?</span> | <span lang="en">Could I try this on?</span> | 服を試すときは <span lang="en">try on</span> です。 |
| <span lang="en">Do you have more small size?</span> | <span lang="en">Do you have this in a smaller size?</span> | <span lang="en">small</span> は <span lang="en">smaller</span> にします。 |
| <span lang="en">I take this.</span> | <span lang="en">I'll take it.</span> | 買うと決めたときは <span lang="en">I'll take it.</span> です。 |

## よくある質問

### 「見ているだけです。ありがとうございます」は英語で何と言いますか

==「<span lang="en">I'm just looking, thanks.</span>」==。断るときも <span lang="en">thanks</span> を添えると感じがよいです。

### 返品を確かめるときは、何と言いますか

「<span lang="en">Can I return it if it doesn't fit?</span>」。意味は「合わなかったら返品できますか」です。<span lang="en">fit</span> は「（サイズが）合う」です。

### 「比べる言い方（比較級）」では、何を押さえればよいですか

短い形容詞は <span lang="en">-er</span> を付けて「もっと〜」にします（<span lang="en">small</span> → <span lang="en">smaller</span>、<span lang="en">big</span> → <span lang="en">bigger</span>）。長い形容詞は <span lang="en">more</span> を前に置きます（<span lang="en">more expensive</span>）。

### 「<span lang="en">Can I try?</span>」はなぜ間違いですか

正しくは「<span lang="en">Could I try this on?</span>」です。服を試すときは <span lang="en">try on</span> です。
