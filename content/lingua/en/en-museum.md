## 要点

- ==許可は <span lang="en">Can I take photos?</span> / <span lang="en">Is it OK to</span> 〜? で聞く==
- 常設展は <span lang="en">free</span>、特別展は有料、という館が多い
- 大きな荷物は <span lang="en">cloakroom</span> に預ける

## キーフレーズ

> 要点
>
> - ==「<span lang="en">Can I take photos here?</span>」写真を撮るは <span lang="en">take photos</span> です。==
> - 「<span lang="en">Which room is it in?</span>」部屋の中なので <span lang="en">in</span> です。
> - 「<span lang="en">Is it OK to sit here?</span>」<span lang="en">Is it OK to</span> のあとは原形です。

| 英語 | 日本語 | 使う場面 |
|---|---|---|
| <span lang="en">Is it free to get in?</span> | 入館は無料ですか。 | 入口で |
| <span lang="en">One ticket for the exhibition, please.</span> | 特別展のチケットを1枚お願いします。 | 特別展に入るとき |
| <span lang="en">Can I take photos here?</span> | ここで写真を撮ってもいいですか。 | 撮影を確かめるとき |
| <span lang="en">Is there a cloakroom?</span> | クロークはありますか。 | 荷物を預けたいとき |
| <span lang="en">Where can I find the Vermeer?</span> | フェルメールの作品はどこにありますか。 | 作品を探すとき |
| <span lang="en">Is there an audio guide in Japanese?</span> | 日本語の音声ガイドはありますか。 | 音声ガイドを聞くとき |
| <span lang="en">Which room is it in?</span> | 何番の部屋ですか。 | 展示室を聞くとき |
| <span lang="en">What time does the museum close?</span> | 美術館は何時に閉まりますか。 | 閉館時間を聞くとき |
| <span lang="en">Is there a student discount?</span> | 学生割引はありますか。 | 料金を確かめるとき |
| <span lang="en">Is it OK to sit here?</span> | ここに座ってもいいですか。 | 許可を求めるとき |

### 解説

- **<span lang="en">Is it free to get in?</span>**：<span lang="en">get in</span> は「入る」です。
- **<span lang="en">One ticket for the exhibition, please.</span>**：<span lang="en">exhibition</span> は「展覧会」です。
- **<span lang="en">Is there a cloakroom?</span>**：イギリスでは <span lang="en">cloakroom</span> と言います。
- **<span lang="en">Where can I find the Vermeer?</span>**：画家の名前で作品を指すことがよくあります。
- **<span lang="en">Is there an audio guide in Japanese?</span>**：<span lang="en">an audio guide</span> と <span lang="en">an</span> を付けます。
- **<span lang="en">What time does the museum close?</span>**：<span lang="en">does</span> のあとは原形の <span lang="en">close</span> です。
- **<span lang="en">Is there a student discount?</span>**：<span lang="en">discount</span> は「割引」です。

## 文法ポイント

> 要点
>
> - ==許可を求める <span lang="en">Can I</span> 〜? / <span lang="en">Is it OK to</span> 〜?==

「〜してもいいですか」は <span lang="en">Can I</span> 〜? が基本で、<span lang="en">Is it OK to</span> 〜? も同じ意味で使えます。どちらも後ろは動詞の原形です。<span lang="en">May I</span> 〜? はより改まった言い方です。

| 例文 | 日本語 |
|---|---|
| <span lang="en">Can I take photos?</span> | 写真を撮ってもいいですか。 |
| <span lang="en">Is it OK to use flash?</span> | フラッシュを使ってもいいですか。 |
| <span lang="en">May I leave my coat here?</span> | ここにコートを置いてもよろしいですか。 |

## 文化メモ

> 要点
>
> - ==ロンドンのナショナル・ギャラリーや大英博物館は常設展の入館が無料で、入口に寄付（<span lang="en">donation</span>）の箱が置かれています。==

特別展は有料で、日時指定の予約が必要なことがあります。

## よくある間違い

> 要点
>
> - ==「<span lang="en">Can I take a picture here?</span>」ではなく「<span lang="en">Can I take photos here?</span>」==
> - 「<span lang="en">Is it OK to sitting here?</span>」ではなく「<span lang="en">Is it OK to sit here?</span>」
> - 「<span lang="en">Where is cloakroom?</span>」ではなく「<span lang="en">Where is the cloakroom?</span>」

| 誤 | 正 | 理由 |
|---|---|---|
| <span lang="en">Can I take a picture here?</span> | <span lang="en">Can I take photos here?</span> | どちらも通じますが、複数枚撮るなら <span lang="en">photos</span> が自然です。 |
| <span lang="en">Is it OK to sitting here?</span> | <span lang="en">Is it OK to sit here?</span> | <span lang="en">to</span> のあとは原形です。 |
| <span lang="en">Where is cloakroom?</span> | <span lang="en">Where is the cloakroom?</span> | 場所を聞くときは <span lang="en">the</span> を付けます。 |

## よくある質問

### 「入館は無料ですか」は英語で何と言いますか

==「<span lang="en">Is it free to get in?</span>」==。<span lang="en">get in</span> は「入る」です。

### 許可を求めるときは、何と言いますか

「<span lang="en">Is it OK to sit here?</span>」。意味は「ここに座ってもいいですか」です。<span lang="en">Is it OK to</span> のあとは原形です。

### 「許可を求める <span lang="en">Can I</span> 〜? / <span lang="en">Is it OK to</span> 〜?」では、何を押さえればよいですか

「〜してもいいですか」は <span lang="en">Can I</span> 〜? が基本で、<span lang="en">Is it OK to</span> 〜? も同じ意味で使えます。どちらも後ろは動詞の原形です。

### 「<span lang="en">Can I take a picture here?</span>」はなぜ間違いですか

正しくは「<span lang="en">Can I take photos here?</span>」です。どちらも通じますが、複数枚撮るなら <span lang="en">photos</span> が自然です。
