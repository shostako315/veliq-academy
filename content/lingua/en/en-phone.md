## 要点

- ==予約は <span lang="en">I'd like to book a table for two at eight tonight.</span>==
- 日時は <span lang="en">on Saturday</span>、時刻は <span lang="en">at eight</span>
- 名前の綴りを聞かれたら一文字ずつ伝える

## キーフレーズ

> 要点
>
> - ==「<span lang="en">For two people, at eight o'clock.</span>」時刻の前は <span lang="en">at</span> です。==
> - 「<span lang="en">Do you have anything earlier?</span>」<span lang="en">early</span> の比較級は <span lang="en">earlier</span> です。
> - 「<span lang="en">I'd like to cancel my booking.</span>」<span lang="en">I'd like to</span> のあとは原形です。

| 英語 | 日本語 | 使う場面 |
|---|---|---|
| <span lang="en">Hello, I'd like to book a table.</span> | もしもし、席を予約したいのですが。 | 電話の最初に |
| <span lang="en">For two people, at eight o'clock.</span> | 2名で、8時にお願いします。 | 人数と時刻を伝えるとき |
| <span lang="en">On Saturday, the fourteenth.</span> | 14日の土曜日です。 | 日付を伝えるとき |
| <span lang="en">Do you have anything earlier?</span> | もっと早い時間は空いていますか。 | 時間を変えたいとき |
| <span lang="en">The name is Tanaka. T-A-N-A-K-A.</span> | 名前は田中です。T・A・N・A・K・A。 | 名前を伝えるとき |
| <span lang="en">Could you say that again, please?</span> | もう一度言っていただけますか。 | 聞き取れなかったとき |
| <span lang="en">Could you speak a little more slowly?</span> | もう少しゆっくり話していただけますか。 | 速すぎるとき |
| <span lang="en">My number is 07700 900123.</span> | 電話番号は 07700 900123 です。 | 連絡先を伝えるとき |
| <span lang="en">Could we have a table by the window?</span> | 窓際の席にできますか。 | 席の希望を伝えるとき |
| <span lang="en">I'd like to cancel my booking.</span> | 予約を取り消したいのですが。 | キャンセルするとき |

### 解説

- **<span lang="en">Hello, I'd like to book a table.</span>**：<span lang="en">book</span> は「予約する」です。
- **<span lang="en">On Saturday, the fourteenth.</span>**：日付は序数（<span lang="en">fourteenth</span>）で読みます。
- **<span lang="en">The name is Tanaka. T-A-N-A-K-A.</span>**：綴りを続けて伝えると確実です。
- **<span lang="en">Could you say that again, please?</span>**：電話では遠慮なく聞き返します。
- **<span lang="en">Could you speak a little more slowly?</span>**：<span lang="en">more slowly</span> で「もっとゆっくり」です。
- **<span lang="en">My number is 07700 900123.</span>**：番号は一桁ずつ読み、0 は <span lang="en">oh</span> と読むことが多いです。
- **<span lang="en">Could we have a table by the window?</span>**：<span lang="en">by the window</span> で「窓際に」です。

## 文法ポイント

> 要点
>
> - ==予約の <span lang="en">for</span>・<span lang="en">at</span>・<span lang="en">on</span>==

予約は、人数を <span lang="en">for</span>、時刻を <span lang="en">at</span>、曜日や日付を <span lang="en">on</span> で伝えます。<span lang="en">I'd like to book a table for four at seven on Friday.</span> のように並べると、一文で伝わります。

| 例文 | 日本語 |
|---|---|
| <span lang="en">A table for four, please.</span> | 4名でお願いします。 |
| <span lang="en">At half past seven.</span> | 7時半に。 |
| <span lang="en">On Friday the twentieth.</span> | 20日の金曜日に。 |

## 文化メモ

> 要点
>
> - ==イギリスでは予約を <span lang="en">booking</span> と言うことが多く、<span lang="en">reservation</span> も通じます。==

電話番号は 0 を <span lang="en">oh</span> と読むのがふつうで、同じ数字が続くと <span lang="en">double seven</span> のように言います。

## よくある間違い

> 要点
>
> - ==「<span lang="en">I want reserve a table.</span>」ではなく「<span lang="en">I'd like to book a table.</span>」==
> - 「<span lang="en">For two people on eight o'clock.</span>」ではなく「<span lang="en">For two people at eight o'clock.</span>」
> - 「<span lang="en">More early, please.</span>」ではなく「<span lang="en">Do you have anything earlier?</span>」

| 誤 | 正 | 理由 |
|---|---|---|
| <span lang="en">I want reserve a table.</span> | <span lang="en">I'd like to book a table.</span> | <span lang="en">want</span> のあとには <span lang="en">to</span> が必要です。丁寧には <span lang="en">I'd like to</span> です。 |
| <span lang="en">For two people on eight o'clock.</span> | <span lang="en">For two people at eight o'clock.</span> | 時刻の前は <span lang="en">at</span> です。 |
| <span lang="en">More early, please.</span> | <span lang="en">Do you have anything earlier?</span> | <span lang="en">early</span> の比較級は <span lang="en">earlier</span> です。 |

## よくある質問

### 「もしもし、席を予約したいのですが」は英語で何と言いますか

==「<span lang="en">Hello, I'd like to book a table.</span>」==。<span lang="en">book</span> は「予約する」です。

### キャンセルするときは、何と言いますか

「<span lang="en">I'd like to cancel my booking.</span>」。意味は「予約を取り消したいのですが」です。<span lang="en">I'd like to</span> のあとは原形です。

### 「予約の <span lang="en">for</span>・<span lang="en">at</span>・<span lang="en">on</span>」では、何を押さえればよいですか

予約は、人数を <span lang="en">for</span>、時刻を <span lang="en">at</span>、曜日や日付を <span lang="en">on</span> で伝えます。<span lang="en">I'd like to book a table for four at seven on Friday.</span> のように並べると、一文で伝わります。

### 「<span lang="en">I want reserve a table.</span>」はなぜ間違いですか

正しくは「<span lang="en">I'd like to book a table.</span>」です。<span lang="en">want</span> のあとには <span lang="en">to</span> が必要です。丁寧には <span lang="en">I'd like to</span> です。
