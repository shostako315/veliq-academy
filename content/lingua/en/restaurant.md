## 要点

- ==予約は <span lang="en">a table for two under Tanaka</span>（田中の名前で2名）==
- おすすめは <span lang="en">What do you recommend?</span> で聞ける
- 会計はイギリスでは <span lang="en">the bill</span>、アメリカでは <span lang="en">the check</span>

## キーフレーズ

> 要点
>
> - ==「<span lang="en">We have a reservation under Tanaka.</span>」予約の名前は <span lang="en">under</span> 〜 で伝えます。==
> - 「<span lang="en">What do you recommend?</span>」<span lang="en">recommend</span> は動詞です。
> - 「<span lang="en">It was delicious.</span>」食べ終わったので過去形 <span lang="en">was</span> です。

| 英語 | 日本語 | 使う場面 |
|---|---|---|
| <span lang="en">We have a reservation under Tanaka.</span> | 田中の名前で予約しています。 | 店に着いたとき |
| <span lang="en">A table for two, please.</span> | 2名です。 | 予約なしで入るとき |
| <span lang="en">Could we see the menu, please?</span> | メニューを見せていただけますか。 | 席に着いたとき |
| <span lang="en">What do you recommend?</span> | おすすめは何ですか。 | 迷ったとき |
| <span lang="en">I'll have the lamb, please.</span> | 子羊をお願いします。 | 料理を決めたとき |
| <span lang="en">Could I have a glass of red wine, please?</span> | 赤ワインをグラスでいただけますか。 | 飲み物を頼むとき |
| <span lang="en">Does this contain nuts?</span> | これにナッツは入っていますか。 | アレルギーを確かめるとき |
| <span lang="en">It was delicious.</span> | とてもおいしかったです。 | 感想を言うとき |
| <span lang="en">Could we have the bill, please?</span> | お会計をお願いします。 | 会計のとき（イギリス） |
| <span lang="en">Is service included?</span> | サービス料は含まれていますか。 | 会計を確かめるとき |
| <span lang="en">Could we split the bill?</span> | 別々に払えますか。 | 割り勘にしたいとき |

### 解説

- **<span lang="en">A table for two, please.</span>**：人数は <span lang="en">a table for</span> 〜 で言います。
- **<span lang="en">Could we see the menu, please?</span>**：<span lang="en">we</span> を主語にすると連れの分も含みます。
- **<span lang="en">I'll have the lamb, please.</span>**：<span lang="en">I'll have</span> 〜 は注文の決まった言い方です。
- **<span lang="en">Could I have a glass of red wine, please?</span>**：グラスでは <span lang="en">a glass of</span> 〜 です。
- **<span lang="en">Does this contain nuts?</span>**：<span lang="en">contain</span> は「含む」です。
- **<span lang="en">Could we have the bill, please?</span>**：アメリカでは <span lang="en">the check</span> と言います。
- **<span lang="en">Is service included?</span>**：<span lang="en">service</span> は「サービス料」の意味でも使います。
- **<span lang="en">Could we split the bill?</span>**：<span lang="en">split</span> は「分ける」です。

## 文法ポイント

> 要点
>
> - ==<span lang="en">I'll have</span> 〜 と <span lang="en">Could we</span> 〜?==
> - 「<span lang="en">Could we have some water?</span>」主語は <span lang="en">we</span> です。

注文は <span lang="en">I'll have</span> 〜. がいちばん簡単です。連れと一緒に頼むときは主語を <span lang="en">we</span> にして <span lang="en">Could we have</span> 〜? とします。<span lang="en">I will have</span> を短くした <span lang="en">I'll</span> を使うのが自然です。

| 例文 | 日本語 | ポイント |
|---|---|---|
| <span lang="en">I'll have the fish, please.</span> | 魚をお願いします。 |  |
| <span lang="en">Could we have some water?</span> | お水をいただけますか。 | 主語は <span lang="en">we</span> です。 |
| <span lang="en">We'll share a starter.</span> | 前菜を一皿、二人で分けます。 |  |

## 文化メモ

> 要点
>
> - ==ロンドンのレストランでは、会計に <span lang="en">service charge</span>（12.5% のことが多い）が最初から含まれていることがあり、その場合は追加でチップを置く必要はありません。==

含まれていないときは、10〜15% ほどを添える人が多いです。

## よくある間違い

> 要点
>
> - ==「<span lang="en">What is your recommend?</span>」ではなく「<span lang="en">What do you recommend?</span>」==
> - 「<span lang="en">It is delicious.</span>」ではなく「<span lang="en">It was delicious.</span>」
> - 「<span lang="en">Check out, please.</span>」ではなく「<span lang="en">Could we have the bill, please?</span>」

| 誤 | 正 | 理由 |
|---|---|---|
| <span lang="en">What is your recommend?</span> | <span lang="en">What do you recommend?</span> | <span lang="en">recommend</span> は動詞です。 |
| <span lang="en">It is delicious.</span> | <span lang="en">It was delicious.</span> | 食べ終わったあとは過去形です。 |
| <span lang="en">Check out, please.</span> | <span lang="en">Could we have the bill, please?</span> | <span lang="en">check out</span> はホテルの手続きです。 |

## よくある質問

### 「田中の名前で予約しています」は英語で何と言いますか

==「<span lang="en">We have a reservation under Tanaka.</span>」==。予約の名前は <span lang="en">under</span> 〜 で伝えます。

### 割り勘にしたいときは、何と言いますか

「<span lang="en">Could we split the bill?</span>」。意味は「別々に払えますか」です。<span lang="en">split</span> は「分ける」です。

### 「<span lang="en">I'll have</span> 〜 と <span lang="en">Could we</span> 〜?」では、何を押さえればよいですか

注文は <span lang="en">I'll have</span> 〜. がいちばん簡単です。連れと一緒に頼むときは主語を <span lang="en">we</span> にして <span lang="en">Could we have</span> 〜? とします。

### 「<span lang="en">What is your recommend?</span>」はなぜ間違いですか

正しくは「<span lang="en">What do you recommend?</span>」です。<span lang="en">recommend</span> は動詞です。
