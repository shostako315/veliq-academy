## 要点

- ==症状は <span lang="en">I have a headache.</span> / <span lang="en">I have a sore throat.</span> のように <span lang="en">I have</span> で言う==
- いつからは <span lang="en">since yesterday</span> / <span lang="en">for two days</span>
- 緊急のときはイギリスでは 999（112 もつながる）

## キーフレーズ

> 要点
>
> - ==「<span lang="en">I have a headache.</span>」頭痛は <span lang="en">headache</span> の1語です。==
> - 「<span lang="en">I've had a fever since yesterday.</span>」「〜から（ずっと）」は <span lang="en">since</span> です。
> - 「<span lang="en">I'm allergic to penicillin.</span>」<span lang="en">allergic to</span> 〜 で「〜にアレルギーがある」です。

| 英語 | 日本語 | 使う場面 |
|---|---|---|
| <span lang="en">I have a headache.</span> | 頭が痛いです。 | 症状を伝えるとき |
| <span lang="en">I have a sore throat.</span> | のどが痛いです。 | 症状を伝えるとき |
| <span lang="en">I've had a fever since yesterday.</span> | 昨日から熱があります。 | いつからかを伝えるとき |
| <span lang="en">I feel sick.</span> | 吐き気がします。 | 気分が悪いとき |
| <span lang="en">Do you have something for a cold?</span> | 風邪に効くものはありますか。 | 薬を求めるとき |
| <span lang="en">How many should I take?</span> | 何錠飲めばいいですか。 | 飲み方を聞くとき |
| <span lang="en">I'm allergic to penicillin.</span> | ペニシリンにアレルギーがあります。 | アレルギーを伝えるとき |
| <span lang="en">Is there a doctor nearby?</span> | 近くに医者はいますか。 | 医者に診てもらいたいとき |
| <span lang="en">Could you call an ambulance?</span> | 救急車を呼んでいただけますか。 | 緊急のとき |
| <span lang="en">Does it make you sleepy?</span> | 眠くなりますか。 | 副作用を確かめるとき |

### 解説

- **<span lang="en">I have a sore throat.</span>**：<span lang="en">sore</span> は「ひりひり痛む」です。
- **<span lang="en">I feel sick.</span>**：イギリスでは <span lang="en">feel sick</span> は「吐き気がする」の意味でよく使います。
- **<span lang="en">Do you have something for a cold?</span>**：<span lang="en">something for</span> 〜 で「〜に効くもの」です。
- **<span lang="en">How many should I take?</span>**：薬を飲むは <span lang="en">take</span> です。
- **<span lang="en">Is there a doctor nearby?</span>**：<span lang="en">nearby</span> は「近くに」です。
- **<span lang="en">Could you call an ambulance?</span>**：<span lang="en">an ambulance</span> と <span lang="en">an</span> を付けます。
- **<span lang="en">Does it make you sleepy?</span>**：<span lang="en">make you</span> ＋形容詞で「〜にさせる」です。

## 文法ポイント

> 要点
>
> - ==症状は <span lang="en">I have a</span> 〜.==
> - 「<span lang="en">I've had a cold for three days.</span>」<span lang="en">for</span> ＋期間で「〜のあいだ」です。

体の症状は <span lang="en">I have a headache.</span> のように <span lang="en">have</span> を使います。<span lang="en">I'm headache</span> とは言いません。痛む場所を言うときは <span lang="en">My back hurts.</span>（背中が痛い）と <span lang="en">hurt</span> も使えます。

| 例文 | 日本語 | ポイント |
|---|---|---|
| <span lang="en">I have a cough.</span> | 咳が出ます。 |  |
| <span lang="en">My stomach hurts.</span> | お腹が痛いです。 |  |
| <span lang="en">I've had a cold for three days.</span> | 3日前から風邪をひいています。 | <span lang="en">for</span> ＋期間で「〜のあいだ」です。 |

## 文化メモ

> 要点
>
> - ==イギリスでは街の薬局（<span lang="en">pharmacy</span>、<span lang="en">chemist</span> とも言う）で、薬剤師が症状を聞いて市販薬を選んでくれます。==

救急は 999、急ぎではない医療相談は <span lang="en">NHS 111</span> につながります。日本の解熱鎮痛薬アセトアミノフェンは、イギリスでは <span lang="en">paracetamol</span> と呼ばれます。

## よくある間違い

> 要点
>
> - ==「<span lang="en">I'm headache.</span>」ではなく「<span lang="en">I have a headache.</span>」==
> - 「<span lang="en">I've had a fever from yesterday.</span>」ではなく「<span lang="en">I've had a fever since yesterday.</span>」
> - 「<span lang="en">I'm allergic for nuts.</span>」ではなく「<span lang="en">I'm allergic to nuts.</span>」

| 誤 | 正 | 理由 |
|---|---|---|
| <span lang="en">I'm headache.</span> | <span lang="en">I have a headache.</span> | 症状は <span lang="en">have</span> で言います。 |
| <span lang="en">I've had a fever from yesterday.</span> | <span lang="en">I've had a fever since yesterday.</span> | 「〜からずっと」は <span lang="en">since</span> です。 |
| <span lang="en">I'm allergic for nuts.</span> | <span lang="en">I'm allergic to nuts.</span> | <span lang="en">allergic</span> のあとは <span lang="en">to</span> です。 |

体の症状は <span lang="en">I have a headache.</span> のように <span lang="en">have</span> を使います。<span lang="en">I'm headache</span> とは言いません。
