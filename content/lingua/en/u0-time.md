## 要点

- ==時刻は <span lang="en">at ten</span>、曜日は <span lang="en">on Monday</span>、月や年は <span lang="en">in May</span> と前置詞が変わる==
- 3:30 は <span lang="en">three thirty</span>、イギリスでは <span lang="en">half past three</span> とも言う
- 曜日と月は大文字で書き始める（<span lang="en">Monday</span>、<span lang="en">May</span>）

## キーフレーズ

> 要点
>
> - ==「<span lang="en">What time does it open?</span>」<span lang="en">does</span> を使う疑問文では、動詞は原形の <span lang="en">open</span> に戻ります。==
> - 「<span lang="en">Is it open on Sunday?</span>」曜日の前は <span lang="en">on</span> です。
> - 「<span lang="en">See you on Friday.</span>」曜日には <span lang="en">on</span> を付けます。

| 英語 | 日本語 | 使う場面 |
|---|---|---|
| <span lang="en">What time is it?</span> | 何時ですか。 | 時刻を聞くとき |
| <span lang="en">It's half past three.</span> | 3時半です。 | 時刻を言うとき（イギリス） |
| <span lang="en">What time does it open?</span> | 何時に開きますか。 | 開く時間を聞くとき |
| <span lang="en">It opens at ten.</span> | 10時に開きます。 | 時刻を答えるとき |
| <span lang="en">Is it open on Sunday?</span> | 日曜日は開いていますか。 | 曜日を確かめるとき |
| <span lang="en">The concert starts at half past seven.</span> | 演奏会は7時半に始まります。 | 開演時間を言うとき |
| <span lang="en">It closes at six on weekdays.</span> | 平日は6時に閉まります。 | 閉まる時間を言うとき |
| <span lang="en">See you on Friday.</span> | 金曜日に会いましょう。 | 約束するとき |
| <span lang="en">I'm free in the afternoon.</span> | 午後は空いています。 | 予定を伝えるとき |
| <span lang="en">It's a quarter to eight.</span> | 8時15分前です。 | 時刻を言うとき（イギリス） |

### 解説

- **<span lang="en">What time is it?</span>**：<span lang="en">What time is it?</span> で今の時刻を聞けます。
- **<span lang="en">It's half past three.</span>**：<span lang="en">half past</span> 〜 で「〜時半」。<span lang="en">three thirty</span> とも言えます。
- **<span lang="en">It opens at ten.</span>**：時刻の前は <span lang="en">at</span> です。
- **<span lang="en">The concert starts at half past seven.</span>**：<span lang="en">start</span>（始まる）も主語が3人称単数なので <span lang="en">starts</span> です。
- **<span lang="en">It closes at six on weekdays.</span>**：<span lang="en">weekdays</span> は月曜から金曜です。
- **<span lang="en">I'm free in the afternoon.</span>**：午前・午後・晩は <span lang="en">in the morning</span> / <span lang="en">afternoon</span> / <span lang="en">evening</span> です。
- **<span lang="en">It's a quarter to eight.</span>**：<span lang="en">a quarter to</span> 〜 で「〜時15分前」です。

## 文法ポイント

> 要点
>
> - ==時の前置詞 <span lang="en">at</span>・<span lang="en">on</span>・<span lang="en">in</span>==

時刻のような一点には <span lang="en">at</span>、曜日や日付には <span lang="en">on</span>、月・年・季節や「午前・午後」には <span lang="en">in</span> を使います。小さい単位ほど <span lang="en">at</span>、大きい単位ほど <span lang="en">in</span> と覚えると迷いません。

| 例文 | 日本語 |
|---|---|
| <span lang="en">The shop opens at nine.</span> | 店は9時に開きます。 |
| <span lang="en">I'm leaving on Tuesday.</span> | 火曜日に発ちます。 |
| <span lang="en">We're going in May.</span> | 5月に行きます。 |

## 文化メモ

> 要点
>
> - ==イギリスでは日曜日は営業時間が短い店が多く、大きな店でも夕方には閉まることがあります。==

駅や空港の時刻表示は 24時間制（19:30）がふつうで、口頭では <span lang="en">seven thirty</span> や <span lang="en">half past seven</span> と言います。

## よくある間違い

> 要点
>
> - ==「<span lang="en">What time does it opens?</span>」ではなく「<span lang="en">What time does it open?</span>」==
> - 「<span lang="en">See you in Friday.</span>」ではなく「<span lang="en">See you on Friday.</span>」
> - 「<span lang="en">It's three and half.</span>」ではなく「<span lang="en">It's half past three.</span>」

| 誤 | 正 | 理由 |
|---|---|---|
| <span lang="en">What time does it opens?</span> | <span lang="en">What time does it open?</span> | <span lang="en">does</span> のあとの動詞は原形です。 |
| <span lang="en">See you in Friday.</span> | <span lang="en">See you on Friday.</span> | 曜日には <span lang="en">on</span> を使います。 |
| <span lang="en">It's three and half.</span> | <span lang="en">It's half past three.</span> | 3時半は <span lang="en">half past three</span> か <span lang="en">three thirty</span> です。 |

## よくある質問

### 「何時ですか」は英語で何と言いますか

==「<span lang="en">What time is it?</span>」==。<span lang="en">What time is it?</span> で今の時刻を聞けます。

### 時刻を言うとき（イギリス）は、何と言いますか

「<span lang="en">It's a quarter to eight.</span>」。意味は「8時15分前です」です。<span lang="en">a quarter to</span> 〜 で「〜時15分前」です。

### 「時の前置詞 <span lang="en">at</span>・<span lang="en">on</span>・<span lang="en">in</span>」では、何を押さえればよいですか

時刻のような一点には <span lang="en">at</span>、曜日や日付には <span lang="en">on</span>、月・年・季節や「午前・午後」には <span lang="en">in</span> を使います。小さい単位ほど <span lang="en">at</span>、大きい単位ほど <span lang="en">in</span> と覚えると迷いません。

### 「<span lang="en">What time does it opens?</span>」はなぜ間違いですか

正しくは「<span lang="en">What time does it open?</span>」です。<span lang="en">does</span> のあとの動詞は原形です。
