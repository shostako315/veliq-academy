## 要点

- ==予約したチケットの受け取りは <span lang="en">I'd like to pick up my tickets.</span>==
- 1階席はイギリスでは <span lang="en">stalls</span>、休憩は <span lang="en">interval</span>（アメリカでは <span lang="en">intermission</span>）
- 休憩中の感想は <span lang="en">It was wonderful.</span> と過去形で

## キーフレーズ

> 要点
>
> - ==「<span lang="en">I'd like to pick up my tickets.</span>」予約したチケットを受け取るは <span lang="en">pick up</span> です。==
> - 「<span lang="en">What time does it end?</span>」<span lang="en">does</span> のあとは原形です。
> - 「<span lang="en">Yes, it was wonderful.</span>」終わった前半なので過去形 <span lang="en">was</span> です。

| 英語 | 日本語 | 使う場面 |
|---|---|---|
| <span lang="en">I'd like to pick up my tickets.</span> | チケットを受け取りたいです。 | 窓口で |
| <span lang="en">The name is Tanaka.</span> | 名前は田中です。 | 予約名を伝えるとき |
| <span lang="en">Where is the cloakroom?</span> | クロークはどこですか。 | コートを預けるとき |
| <span lang="en">Could you show me my seat?</span> | 席を教えていただけますか。 | 座席を探すとき |
| <span lang="en">We're in row twelve.</span> | 12列目です。 | 席を伝えるとき |
| <span lang="en">Is there an interval?</span> | 休憩はありますか。 | 開演前に |

### 解説

- **<span lang="en">The name is Tanaka.</span>**：<span lang="en">The name is</span> 〜 で予約の名前を伝えられます。
- **<span lang="en">Where is the cloakroom?</span>**：ヨーロッパの劇場では <span lang="en">cloakroom</span> とよく言います。
- **<span lang="en">Could you show me my seat?</span>**：<span lang="en">show me</span> で「案内して」です。
- **<span lang="en">We're in row twelve.</span>**：列は <span lang="en">row</span> です。
- **<span lang="en">Is there an interval?</span>**：イギリスでは <span lang="en">interval</span>、アメリカでは <span lang="en">intermission</span> です。
- **<span lang="en">Could I have a programme, please?</span>**：イギリスでは <span lang="en">programme</span> と綴ります。
- **<span lang="en">Yes, it's my first time. I'm from Japan.</span>**：「初めて」は <span lang="en">it's my first time</span> です。

## 文法ポイント

> 要点
>
> - ==<span lang="en">I'd like to</span> ＋動詞==

「〜したい」は <span lang="en">I'd like to</span> ＋動詞の原形で丁寧に言えます。<span lang="en">I want to</span> も通じますが、窓口では <span lang="en">I'd like to</span> が自然です。名詞だけなら <span lang="en">I'd like</span> 〜（<span lang="en">I'd like two tickets</span>）です。

| 例文 | 日本語 |
|---|---|
| <span lang="en">I'd like to pick up my tickets.</span> | チケットを受け取りたいです。 |
| <span lang="en">I'd like to sit near the aisle.</span> | 通路側に座りたいです。 |
| <span lang="en">I'd like two tickets for tonight.</span> | 今夜のチケットを2枚お願いします。 |

## 文化メモ

> 要点
>
> - ==ウィーン楽友協会の大ホールは、平土間の席を <span lang="en">Parterre</span> と呼び、立ち見の席もあります。==

ヨーロッパの劇場では、開演前にコートをクロークに預けるのがふつうで、休憩のベルが鳴ると席に戻ります。

## よくある間違い

> 要点
>
> - ==「<span lang="en">I want to receive my ticket.</span>」ではなく「<span lang="en">I'd like to pick up my tickets.</span>」==
> - 「<span lang="en">It is wonderful.</span>」ではなく「<span lang="en">It was wonderful.</span>」
> - 「<span lang="en">I'm first time.</span>」ではなく「<span lang="en">It's my first time.</span>」

| 誤 | 正 | 理由 |
|---|---|---|
| <span lang="en">I want to receive my ticket.</span> | <span lang="en">I'd like to pick up my tickets.</span> | チケットを受け取るは <span lang="en">pick up</span> です。 |
| <span lang="en">It is wonderful.</span> | <span lang="en">It was wonderful.</span> | 終わった演奏のことは過去形です。 |
| <span lang="en">I'm first time.</span> | <span lang="en">It's my first time.</span> | 「初めて」は <span lang="en">it</span> を主語にします。 |

## よくある質問

### 「チケットを受け取りたいです」は英語で何と言いますか

==「<span lang="en">I'd like to pick up my tickets.</span>」==。予約したチケットを受け取るは <span lang="en">pick up</span> です。

### 初めてかと聞かれたときは、何と言いますか

「<span lang="en">Yes, it's my first time. I'm from Japan.</span>」。意味は「はい、初めてです。日本から来ました」です。「初めて」は <span lang="en">it's my first time</span> です。

### 「<span lang="en">I'd like to</span> ＋動詞」では、何を押さえればよいですか

「〜したい」は <span lang="en">I'd like to</span> ＋動詞の原形で丁寧に言えます。<span lang="en">I want to</span> も通じますが、窓口では <span lang="en">I'd like to</span> が自然です。

### 「<span lang="en">I want to receive my ticket.</span>」はなぜ間違いですか

正しくは「<span lang="en">I'd like to pick up my tickets.</span>」です。チケットを受け取るは <span lang="en">pick up</span> です。
