## 要点

- ==好みは <span lang="en">something dry</span> / <span lang="en">something light</span> のように <span lang="en">something</span> ＋形容詞で伝える==
- グラスの大きさ（125<span lang="en">ml</span>・175<span lang="en">ml</span>・250<span lang="en">ml</span>）を聞かれることがある
- 試飲したいときは <span lang="en">Could I try a little first?</span>

## キーフレーズ

> 要点
>
> - ==「<span lang="en">I'd like something dry.</span>」<span lang="en">something</span> のあとに形容詞を置きます。==
> - 「<span lang="en">Is it by the glass?</span>」<span lang="en">by the glass</span> で「グラス売りで」です。
> - 「<span lang="en">It's a bit too sweet for me.</span>」<span lang="en">too</span> ＋形容詞で「〜すぎる」です。

| 英語 | 日本語 | 使う場面 |
|---|---|---|
| <span lang="en">Could I see the wine list, please?</span> | ワインリストを見せていただけますか。 | 席に着いたとき |
| <span lang="en">I'd like something dry.</span> | 辛口のものがいいです。 | 好みを伝えるとき |
| <span lang="en">Something light and fruity, please.</span> | 軽くて果実味のあるものをお願いします。 | 赤の好みを伝えるとき |
| <span lang="en">What would you recommend with the fish?</span> | 魚に合わせるなら何がおすすめですか。 | 料理に合わせて選ぶとき |

### 解説

- **<span lang="en">Could I see the wine list, please?</span>**：<span lang="en">wine list</span> でワインのメニューです。
- **<span lang="en">Something light and fruity, please.</span>**：<span lang="en">light</span> は「軽い」、<span lang="en">fruity</span> は「果実味のある」です。
- **<span lang="en">What would you recommend with the fish?</span>**：<span lang="en">with</span> 〜 で「〜に合わせて」です。
- **<span lang="en">Could I try a little first?</span>**：<span lang="en">try</span> は「試す」です。
- **<span lang="en">A large glass of the Rioja, please.</span>**：銘柄には <span lang="en">the</span> を付けます。
- **<span lang="en">Just a small one, please.</span>**：<span lang="en">one</span> は <span lang="en">glass</span> の繰り返しを避ける語です。
- **<span lang="en">Could we have a bottle of this?</span>**：<span lang="en">a bottle of</span> 〜 で「〜を1本」です。

## 文法ポイント

> 要点
>
> - ==<span lang="en">something</span> ＋形容詞==
> - 「<span lang="en">Something to go with the lamb, please.</span>」<span lang="en">to go with</span> 〜 で「〜に合う」です。

<span lang="en">something</span>、<span lang="en">anything</span> のあとに形容詞を置くと「何か〜なもの」になります。英語では形容詞はふつう名詞の前ですが、<span lang="en">something</span> のときは後ろに置きます。

| 例文 | 日本語 | ポイント |
|---|---|---|
| <span lang="en">I'd like something dry.</span> | 辛口のものがいいです。 |  |
| <span lang="en">Do you have anything lighter?</span> | もっと軽いものはありますか。 |  |
| <span lang="en">Something to go with the lamb, please.</span> | 子羊に合うものをお願いします。 | <span lang="en">to go with</span> 〜 で「〜に合う」です。 |

## 文化メモ

> 要点
>
> - ==イギリスでは、グラスワインに 125<span lang="en">ml</span> の小さいサイズを用意することが決められていて、ほかに 175<span lang="en">ml</span>・250<span lang="en">ml</span> がよく使われます。==

何も言わないと 175<span lang="en">ml</span> や 250<span lang="en">ml</span> が出てくることもあるので、量を伝えておくと安心です。

## よくある間違い

> 要点
>
> - ==「<span lang="en">I'd like dry something.</span>」ではなく「<span lang="en">I'd like something dry.</span>」==
> - 「<span lang="en">Is it on glass?</span>」ではなく「<span lang="en">Is it by the glass?</span>」
> - 「<span lang="en">It's too much sweet.</span>」ではなく「<span lang="en">It's too sweet.</span>」

| 誤 | 正 | 理由 |
|---|---|---|
| <span lang="en">I'd like dry something.</span> | <span lang="en">I'd like something dry.</span> | 形容詞は <span lang="en">something</span> の後ろに置きます。 |
| <span lang="en">Is it on glass?</span> | <span lang="en">Is it by the glass?</span> | グラス売りは <span lang="en">by the glass</span> です。 |
| <span lang="en">It's too much sweet.</span> | <span lang="en">It's too sweet.</span> | <span lang="en">too</span> ＋形容詞で「〜すぎる」です。 |

## よくある質問

### 「ワインリストを見せていただけますか」は英語で何と言いますか

==「<span lang="en">Could I see the wine list, please?</span>」==。<span lang="en">wine list</span> でワインのメニューです。

### 感想を言うときは、何と言いますか

「<span lang="en">It's a bit too sweet for me.</span>」。意味は「私には少し甘すぎます」です。<span lang="en">too</span> ＋形容詞で「〜すぎる」です。

### 「<span lang="en">something</span> ＋形容詞」では、何を押さえればよいですか

<span lang="en">something</span>、<span lang="en">anything</span> のあとに形容詞を置くと「何か〜なもの」になります。英語では形容詞はふつう名詞の前ですが、<span lang="en">something</span> のときは後ろに置きます。

### 「<span lang="en">I'd like dry something.</span>」はなぜ間違いですか

正しくは「<span lang="en">I'd like something dry.</span>」です。形容詞は <span lang="en">something</span> の後ろに置きます。
