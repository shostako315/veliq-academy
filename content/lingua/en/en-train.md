## 要点

- ==切符は <span lang="en">A return to Oxford, please.</span>（片道は <span lang="en">single</span>）==
- 時刻は <span lang="en">When's the next train to</span> 〜? で聞ける
- ホームは <span lang="en">Which platform does it leave from?</span>

## キーフレーズ

> 要点
>
> - ==「<span lang="en">A single to Oxford, please.</span>」行き先は <span lang="en">to</span> で言います。==
> - 「<span lang="en">Which platform does it leave from?</span>」<span lang="en">does</span> のあとは原形の <span lang="en">leave</span> です。
> - 「<span lang="en">How long does it take?</span>」<span lang="en">does</span> のあとは原形です。

| 英語 | 日本語 | 使う場面 |
|---|---|---|
| <span lang="en">A return to Oxford, please.</span> | オックスフォードまで往復1枚お願いします。 | 切符を買うとき |
| <span lang="en">A single to Oxford, please.</span> | オックスフォードまで片道1枚お願いします。 | 片道を買うとき |
| <span lang="en">When's the next train to Oxford?</span> | オックスフォード行きの次の列車は何時ですか。 | 時刻を聞くとき |
| <span lang="en">Which platform does it leave from?</span> | 何番線から出ますか。 | ホームを聞くとき |
| <span lang="en">Do I need to change trains?</span> | 乗り換えは必要ですか。 | 乗り換えを確かめるとき |
| <span lang="en">Is this seat taken?</span> | この席は空いていますか。 | 座るとき |
| <span lang="en">Does this train stop at Reading?</span> | この列車はレディングに止まりますか。 | 停車駅を確かめるとき |
| <span lang="en">How long does it take?</span> | どのくらいかかりますか。 | 所要時間を聞くとき |
| <span lang="en">Is it cheaper off-peak?</span> | 混雑時間外だと安くなりますか。 | 料金を確かめるとき |
| <span lang="en">Excuse me, this is my seat.</span> | すみません、そこは私の席です。 | 予約席にほかの人がいたとき |

### 解説

- **<span lang="en">A return to Oxford, please.</span>**：イギリスでは往復を <span lang="en">return</span>、片道を <span lang="en">single</span> と言います。
- **<span lang="en">When's the next train to Oxford?</span>**：<span lang="en">When's</span> は <span lang="en">When is</span> を短くした形です。
- **<span lang="en">Do I need to change trains?</span>**：乗り換えは <span lang="en">change trains</span> と複数形です。
- **<span lang="en">Is this seat taken?</span>**：<span lang="en">taken</span> は「ふさがっている」です。
- **<span lang="en">Does this train stop at Reading?</span>**：<span lang="en">stop at</span> 〜 で「〜に止まる」です。
- **<span lang="en">Is it cheaper off-peak?</span>**：<span lang="en">off-peak</span> は混雑時間外の料金です。
- **<span lang="en">Excuse me, this is my seat.</span>**：<span lang="en">Excuse me</span> で丁寧に切り出します。

## 文法ポイント

> 要点
>
> - ==<span lang="en">How long does it take?</span>==

所要時間は <span lang="en">How long does it take?</span> で聞きます。答えは <span lang="en">It takes about an hour.</span> です。疑問文で <span lang="en">does</span> を使ったら、動詞は <span lang="en">take</span> のまま（<span lang="en">-s</span> を付けない）にします。

| 例文 | 日本語 |
|---|---|
| <span lang="en">How long does it take?</span> | どのくらいかかりますか。 |
| <span lang="en">It takes about an hour.</span> | 1時間ほどかかります。 |
| <span lang="en">How long does it take to Oxford?</span> | オックスフォードまでどのくらいかかりますか。 |

## 文化メモ

> 要点
>
> - ==イギリスの鉄道では、同じ区間でも時間帯（<span lang="en">peak</span> / <span lang="en">off-peak</span>）や買う時期で料金が大きく変わります。==

ロンドン市内の地下鉄やバスは、改札でクレジットカードやスマートフォンをかざすだけで乗れます。

## よくある間違い

> 要点
>
> - ==「<span lang="en">One ticket go and back.</span>」ではなく「<span lang="en">A return, please.</span>」==
> - 「<span lang="en">Which platform it leaves?</span>」ではなく「<span lang="en">Which platform does it leave from?</span>」
> - 「<span lang="en">Do I need to change train?</span>」ではなく「<span lang="en">Do I need to change trains?</span>」

| 誤 | 正 | 理由 |
|---|---|---|
| <span lang="en">One ticket go and back.</span> | <span lang="en">A return, please.</span> | 往復は <span lang="en">return</span> です。 |
| <span lang="en">Which platform it leaves?</span> | <span lang="en">Which platform does it leave from?</span> | 疑問文は <span lang="en">does</span> を使い、最後に <span lang="en">from</span> を置きます。 |
| <span lang="en">Do I need to change train?</span> | <span lang="en">Do I need to change trains?</span> | 乗り換えは <span lang="en">trains</span> と複数形です。 |

## よくある質問

### 「オックスフォードまで往復1枚お願いします」は英語で何と言いますか

==「<span lang="en">A return to Oxford, please.</span>」==。イギリスでは往復を <span lang="en">return</span>、片道を <span lang="en">single</span> と言います。

### 予約席にほかの人がいたときは、何と言いますか

「<span lang="en">Excuse me, this is my seat.</span>」。意味は「すみません、そこは私の席です」です。<span lang="en">Excuse me</span> で丁寧に切り出します。

### 「<span lang="en">How long does it take?</span>」では、何を押さえればよいですか

所要時間は <span lang="en">How long does it take?</span> で聞きます。答えは <span lang="en">It takes about an hour.</span> です。

### 「<span lang="en">One ticket go and back.</span>」はなぜ間違いですか

正しくは「<span lang="en">A return, please.</span>」です。往復は <span lang="en">return</span> です。
