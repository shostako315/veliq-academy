## 確かめきれず書かなかった点
- ロッシーニ・オペラ・フェスティバルの創設年（1980年とされるが、資料は「1980年から財団と協力」とだけ書く）。
- 《ギヨーム・テル》の幕数、《スターバト・マーテル》初稿の委嘱者（ヴァレラ）と共作者（タドリーニ）。
- 「イタリアの白鳥／ペーザロの白鳥」の呼び名は [EC] にあるが、記事には入れなかった。
- 晩年の病気、土曜の夜会（samedi soir）の詳細。資料を開けなかった。
- 師弟関係：データの teachers は既存 id に該当者がいないため空。
