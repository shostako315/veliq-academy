## 確かめきれず書かなかった点
- ヘンレ版の序文PDF（エックハルト）は許可が得られず開けなかった（https://www.henle.de/media/70/4b/65/1697725774/1586-1697725774-sync.pdf）。
- 楽譜上の速度表示（Lento a capriccio、Andante mesto、Vivace など）と小節番号。確かめられる一次資料が開けなかった。movements JSON は書かなかった。
- 導入主題がルーマニアの旋律でヴァイマルのスケッチ帳にあるという説、ハインリヒ・エールリヒ（Heinrich Ehrlich）の盗用の訴えと1864年のリストの書簡（Wikipedia が Henle 序文を典拠とするが、序文を開けなかった）。
- 管弦楽版の成立年（1857〜60年）と出版（シューベルト、1874〜75年）、連弾版1874年、ミュラー＝ベルクハウス版、シュレーカーの1933年編曲。
- アムラン（Marc-André Hamelin）のカデンツァと録音、《ネコの協奏曲》《ラプソディー・ラビット》などアニメーションの個別の題（Wikipedia 由来のブログにしか出ていなかった）。
