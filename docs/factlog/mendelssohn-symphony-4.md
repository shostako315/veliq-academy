## 確かめきれず書かなかった点
- 第3楽章・第4楽章の調（イ長調・トリオの調、終楽章がイ短調であること）は [CSO] の「同主短調で終わる」以外に明記した資料がなく、データの key は第3楽章を空欄にした。
- 自筆譜の所在、MWV 番号（MWV N 16 は販売頁の題と IMSLP のファイル名にしか見えず、書かなかった）。
- 代表的な録音。Gramophone の頁が上限で開けず、録音は書かなかった（作曲家記事にあるガーディナー／ウィーン・フィルの件は自分で確認できていない）。
- 第3楽章のトリオの楽器（[SPCO] の記述が断片的で、構成を特定できなかった）。
- 「ローマのサルタレッロ、ナポリのタランテラ」の対応は学生の解説（Sacramento State）にしかなく書かなかった。
