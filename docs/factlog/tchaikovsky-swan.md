## 確かめきれず書かなかった点
- データの musicalAnalysis にある「オーボエが奏でる情景の主題」（第10番の楽器・調）。開いた資料に楽器と調の記載がなかった。
- 委嘱料の総額。
- 初演の装置・美術担当（[CBR] は1895年の美術担当4名を挙げるが、本文には入れなかった）。
- レニャーニの32回転（[MPS] は1893年《シンデレラ》での披露として記述しており、《白鳥の湖》との関係は書かなかった）。
- マリインスキー劇場の公演頁は JavaScript の確認画面で読めなかった。
