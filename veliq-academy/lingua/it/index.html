イタリア語

イタリア語のユニット17本（はじめの一歩 5本・場面 12本）。各ユニットは要点・キーフレーズ・単語・文法・文化メモ・よくある間違い。

はじめの一歩

  • 発音と文字イタリア語は、ほぼ書いてあるとおりに読める言語です。母音はア・エ・イ・オ・ウの5つで日本人に発音しやすく、c と g の読み分けと、gli・gn の音にだけ決まりがあります。
  • あいさつイタリア語のあいさつは、相手との距離で使い分けます。知らない人や店の人には Buongiorno と Lei（あなた）、親しい人には Ciao と tu（きみ）。最初はすべて丁寧な形で話せば間違いありません。
  • 数字と値段値段を聞き取れると、買い物と会計がぐっと楽になります。数の言い方と、ユーロの値段の読み方、支払いのやりとりを覚えます。
  • 自己紹介自己紹介は、名前・出身・仕事・好きなことの四つを短く言えれば十分です。動詞の「私」の形（-o）を押さえると、ほとんどの文が作れます。
  • 時間と曜日開館時間、開演時間、列車の時刻。時間のやりとりは旅のあらゆる場面に出てきます。時刻の言い方と「〜時に」の alle を押さえます。

場面

  • カフェ（バール）で注文イタリアのバールでは、カウンターで立ったまま飲むのが日常です。何を頼むかに加えて、先に払うのか、カウンターか席か、という流れを知っておくと迷いません。
  • トラットリアで食事トラットリアでは、予約の確認、飲み物、料理、会計の順にやりとりが進みます。イタリアのコースの組み立て（primo・secondo）を知っておくと、メニューが読めるようになります。
  • ワインを選ぶエノテカ（ワインの店・バー）では、色と味わいの好みを伝えれば、店の人が土地のワインを選んでくれます。形容詞の語尾の変化に気をつけます。
  • ホテルにチェックインチェックインでは、予約の名前と泊数を伝え、身分証を見せたあと、朝食や部屋のことを尋ねます。c'è（〜がある）が使えれば、たいていのことは聞けます。
  • 駅・切符切符売り場では、行き先・片道か往復か・何時の列車かを伝えます。番線と乗り換え、刻印の決まりを知っていれば、一人で移動できます。
  • 美術館で美術館では、予約の確認、荷物、撮影の可否、作品の場所を尋ねます。si può（〜してよいか）が使えると、たいていの確認ができます。
  • 演奏会のチケットと座席イタリアの劇場では、窓口でのチケットの受け取り、座席の種類、休憩中の会話までが一続きです。劇場ならではの言葉（platea、palco、intervallo）を覚えます。
  • 道をたずねる道を聞くときは、声をかける・行き先を言う・案内を聞き取る・お礼、の四つです。案内は Lei に対する命令形で返ってくるので、その形を聞き取れるようにします。
  • 買い物（市場）市場や食料品店では、量り売りの単位と、店の人に選んでもらう作法を知っておくと気持ちよく買えます。un etto（100グラム）は毎日のように使う言葉です。
  • 体調が悪いとき旅先で体調を崩したら、まず薬局で症状を伝えます。Ho mal di 〜（〜が痛い）の形と、いつからかを言えれば、薬剤師が適した薬を選んでくれます。
  • 予約の電話電話は顔が見えないぶん、決まった言い方に頼るのがいちばん確実です。人数・日にち・時刻・名前の順に伝え、聞き取れないときは遠慮なく聞き返します。
  • 雑談（天気・音楽）雑談は天気から始まり、相手の好きなものへ広がります。暑さ寒さの fare と、「〜が好き」の piacere の形を覚えると、話が続きます。
