発音と文字（イタリア語）——母音、c・g の読み分け、gli・gn、アクセント

イタリア語は、ほぼ書いてあるとおりに読める言語です。母音はア・エ・イ・オ・ウの5つで日本人に発音しやすく、c と g の読み分けと、gli・gn の音にだけ決まりがあります。

1要点

  • c・g は後ろが e・i なら「チ・ジ」、a・o・u なら「カ・ガ」。ch・gh は「キ・ギ」（che＝ケ、spaghetti＝スパゲッティ）
  • gli は「リ」に近い音（famiglia＝ファミーリア）、gn は「ニャ・ニョ」（gnocchi＝ニョッキ）
  • 最後にアクセント記号がある語はそこを強く読む（caffè、città、perché）。ほかの多くは後ろから2つ目を強く読む

2キーフレーズ

要点

  • 「Un caffè, per favore.」caffè は f が2つで、最後の è を強く読みます。記号の向きは è です。
  • 「Vorrei gli gnocchi.」gn は「ニョ」、cch は「ッキ」と読みます。
  • 「Com'è la città?」città は tt を詰め、最後の à を強く読みます。

2-1解説

  • Ciao.：ci は「チ」と読みます。親しい相手にだけ使います。
  • Buongiorno.：gi は「ジ」と読みます。
  • Grazie mille.：ll は小さな「ッ」を入れて「ミッレ」と読みます。
  • Che cos'è?：che は「ケ」と読みます（ch はカ行）。
  • Gli spaghetti sono buonissimi.：ghe は「ゲ」、gli は「リ」に近い音です。
  • La mia famiglia è a Tokyo.：famiglia の gli は「リ」に近く、ファミーリアと読みます。
  • Perché?：最後の é を強く「ペルケ」と読みます。
  • Come si scrive?：scrivere は「書く」。Come si scrive? で綴りを尋ねられます。

3単語

要点

  • cena（夕食）：ce は「チェ」。チェーナと読みます。
  • casa（家）：ca は「カ」。カーザと読みます。
  • gelato（ジェラート）：ge は「ジェ」です。

4文法ポイント

要点

  • アクセント記号と強く読む位置
  • 「Un caffè, per favore.」アクセント記号まで書いて caffè です。

イタリア語の単語は、多くが後ろから2つ目の音節を強く読みます（a-MI-co、ri-sto-RAN-te）。最後を強く読む語にはアクセント記号を付けます（caffè、città）。記号の向き（è と é）は母音の開き方の違いで、書くときは語ごとに決まった形を覚えます。

例文 日本語 ポイント
Un caffè, per favore. コーヒーを1杯ください。 アクセント記号まで書いて caffè です。
Lunedì vado a Roma. 月曜日にローマに行きます。
La città è molto bella. 街はとても美しいです。

5文化メモ

要点

  • イタリア語は綴りと読みがほぼ一対一なので、決まりを覚えると知らない単語も読めます。

h は発音しない文字で、ch・gh のように c と g をカ行・ガ行にするために使われます。ho（持っている）は「オ」と読みます。

6よくある間違い

要点

  • 「Una brusketta, per favore.」ではなく「Una bruschetta, per favore.」
  • 「Un cafè, per favore.」ではなく「Un caffè, per favore.」
  • 「Grazie mile.」ではなく「Grazie mille.」
誤 正 理由
Una brusketta, per favore. Una bruschetta, per favore. 「スケ」の音は sche と書きます（ch はカ行）。ブルスケッタと読みます。
Un cafè, per favore. Un caffè, per favore. caffè は f が2つで、最後に è を付けます。
Grazie mile. Grazie mille. mille は l が2つで「ミッレ」と詰めて読みます。

よくある質問

「やあ・じゃあね」はイタリア語で何と言いますか

「Ciao.」（チャオ）。ci は「チ」と読みます。親しい相手にだけ使います。

綴りを聞くときは、何と言いますか

「Come si scrive?」（コメ・スィ・スクリーヴェ）。意味は「どう書きますか」です。scrivere は「書く」。Come si scrive? で綴りを尋ねられます。

「アクセント記号と強く読む位置」では、何を押さえればよいですか

イタリア語の単語は、多くが後ろから2つ目の音節を強く読みます（a-MI-co、ri-sto-RAN-te）。最後を強く読む語にはアクセント記号を付けます（caffè、città）。

「Una brusketta, per favore.」はなぜ間違いですか

正しくは「Una bruschetta, per favore.」です。「スケ」の音は sche と書きます（ch はカ行）。ブルスケッタと読みます。
