演奏会のチケットと座席（英語）——ロンドンのロイヤル・アルバート・ホールで、チケットの受け取りから休憩まで

演奏会では、窓口でのチケットの受け取り、クローク、座席、休憩中の会話までが一続きです。劇場ならではの言葉（stalls、interval、programme）を覚えます。

1要点

  • 予約したチケットの受け取りは I'd like to pick up my tickets.
  • 1階席はイギリスでは stalls、休憩は interval（アメリカでは intermission）
  • 休憩中の感想は It was wonderful. と過去形で

2キーフレーズ

要点

  • 「I'd like to pick up my tickets.」予約したチケットを受け取るは pick up です。
  • 「What time does it end?」does のあとは原形です。
  • 「Yes, it was wonderful.」終わった前半なので過去形 was です。
英語 日本語 使う場面
I'd like to pick up my tickets. チケットを受け取りたいです。 窓口で
The name is Tanaka. 名前は田中です。 予約名を伝えるとき
Where is the cloakroom? クロークはどこですか。 コートを預けるとき
Could you show me my seat? 席を教えていただけますか。 座席を探すとき
We're in row twelve. 12列目です。 席を伝えるとき
Is there an interval? 休憩はありますか。 開演前に
Could I have a programme, please? プログラムをいただけますか。 プログラムを買うとき
What time does it end? 何時に終わりますか。 終演時間を聞くとき
Yes, it was wonderful. ええ、すばらしかったです。 休憩中に感想を言うとき
Yes, it's my first time. I'm from Japan. はい、初めてです。日本から来ました。 初めてかと聞かれたとき

2-1解説

  • The name is Tanaka.：The name is 〜 で予約の名前を伝えられます。
  • Where is the cloakroom?：ヨーロッパの劇場では cloakroom とよく言います。
  • Could you show me my seat?：show me で「案内して」です。
  • We're in row twelve.：列は row です。
  • Is there an interval?：イギリスでは interval、アメリカでは intermission です。
  • Could I have a programme, please?：イギリスでは programme と綴ります。
  • Yes, it's my first time. I'm from Japan.：「初めて」は it's my first time です。

4文法ポイント

要点

  • I'd like to ＋動詞

「〜したい」は I'd like to ＋動詞の原形で丁寧に言えます。I want to も通じますが、窓口では I'd like to が自然です。名詞だけなら I'd like 〜（I'd like two tickets）です。

例文 日本語
I'd like to pick up my tickets. チケットを受け取りたいです。
I'd like to sit near the aisle. 通路側に座りたいです。
I'd like two tickets for tonight. 今夜のチケットを2枚お願いします。

5文化メモ

要点

  • ロンドンのロイヤル・アルバート・ホールでは、席の区分に stalls、circle、いちばん上の gallery といった名前が使われ、夏のプロムス（BBC Proms）ではアリーナとギャラリーに当日の立ち見席があります。

ヨーロッパの劇場では、開演前にコートをクロークに預けるのがふつうで、休憩のベルが鳴ると席に戻ります。

6よくある間違い

要点

  • 「I want to receive my ticket.」ではなく「I'd like to pick up my tickets.」
  • 「It is wonderful.」ではなく「It was wonderful.」
  • 「I'm first time.」ではなく「It's my first time.」
誤 正 理由
I want to receive my ticket. I'd like to pick up my tickets. チケットを受け取るは pick up です。
It is wonderful. It was wonderful. 終わった演奏のことは過去形です。
I'm first time. It's my first time. 「初めて」は it を主語にします。

よくある質問

「チケットを受け取りたいです」は英語で何と言いますか

「I'd like to pick up my tickets.」。予約したチケットを受け取るは pick up です。

初めてかと聞かれたときは、何と言いますか

「Yes, it's my first time. I'm from Japan.」。意味は「はい、初めてです。日本から来ました」です。「初めて」は it's my first time です。

「I'd like to ＋動詞」では、何を押さえればよいですか

「〜したい」は I'd like to ＋動詞の原形で丁寧に言えます。I want to も通じますが、窓口では I'd like to が自然です。

「I want to receive my ticket.」はなぜ間違いですか

正しくは「I'd like to pick up my tickets.」です。チケットを受け取るは pick up です。
