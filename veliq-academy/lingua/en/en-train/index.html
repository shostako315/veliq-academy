駅・切符（英語）——ロンドンの駅で、オックスフォード行きの切符を買う

切符売り場では、行き先・片道か往復か・何時の列車かを伝えます。ホームの番号と乗り換えも聞ければ、一人で移動できます。

1要点

  • 切符は A return to Oxford, please.（片道は single）
  • 時刻は When's the next train to 〜? で聞ける
  • ホームは Which platform does it leave from?

2キーフレーズ

要点

  • 「A single to Oxford, please.」行き先は to で言います。
  • 「Which platform does it leave from?」does のあとは原形の leave です。
  • 「How long does it take?」does のあとは原形です。
英語 日本語 使う場面
A return to Oxford, please. オックスフォードまで往復1枚お願いします。 切符を買うとき
A single to Oxford, please. オックスフォードまで片道1枚お願いします。 片道を買うとき
When's the next train to Oxford? オックスフォード行きの次の列車は何時ですか。 時刻を聞くとき
Which platform does it leave from? 何番線から出ますか。 ホームを聞くとき
Do I need to change trains? 乗り換えは必要ですか。 乗り換えを確かめるとき
Is this seat taken? この席は空いていますか。 座るとき
Does this train stop at Reading? この列車はレディングに止まりますか。 停車駅を確かめるとき
How long does it take? どのくらいかかりますか。 所要時間を聞くとき
Is it cheaper off-peak? 混雑時間外だと安くなりますか。 料金を確かめるとき
Excuse me, this is my seat. すみません、そこは私の席です。 予約席にほかの人がいたとき

2-1解説

  • A return to Oxford, please.：イギリスでは往復を return、片道を single と言います。
  • When's the next train to Oxford?：When's は When is を短くした形です。
  • Do I need to change trains?：乗り換えは change trains と複数形です。
  • Is this seat taken?：taken は「ふさがっている」です。
  • Does this train stop at Reading?：stop at 〜 で「〜に止まる」です。
  • Is it cheaper off-peak?：off-peak は混雑時間外の料金です。
  • Excuse me, this is my seat.：Excuse me で丁寧に切り出します。

要点

  • 切符：single・return・ticket machine・off-peak・first class・reservation
  • 駅：platform・departure・arrival・delay・timetable
  • 列車で：carriage・seat・change・stop・luggage rack

4文法ポイント

要点

  • How long does it take?

所要時間は How long does it take? で聞きます。答えは It takes about an hour. です。疑問文で does を使ったら、動詞は take のまま（-s を付けない）にします。

例文 日本語
How long does it take? どのくらいかかりますか。
It takes about an hour. 1時間ほどかかります。
How long does it take to Oxford? オックスフォードまでどのくらいかかりますか。

5文化メモ

要点

  • イギリスの鉄道では、同じ区間でも時間帯（peak / off-peak）や買う時期で料金が大きく変わります。

ロンドン市内の地下鉄やバスは、改札でクレジットカードやスマートフォンをかざすだけで乗れます。

6よくある間違い

要点

  • 「One ticket go and back.」ではなく「A return, please.」
  • 「Which platform it leaves?」ではなく「Which platform does it leave from?」
  • 「Do I need to change train?」ではなく「Do I need to change trains?」
誤 正 理由
One ticket go and back. A return, please. 往復は return です。
Which platform it leaves? Which platform does it leave from? 疑問文は does を使い、最後に from を置きます。
Do I need to change train? Do I need to change trains? 乗り換えは trains と複数形です。

よくある質問

「オックスフォードまで往復1枚お願いします」は英語で何と言いますか

「A return to Oxford, please.」。イギリスでは往復を return、片道を single と言います。

予約席にほかの人がいたときは、何と言いますか

「Excuse me, this is my seat.」。意味は「すみません、そこは私の席です」です。Excuse me で丁寧に切り出します。

「How long does it take?」では、何を押さえればよいですか

所要時間は How long does it take? で聞きます。答えは It takes about an hour. です。

「One ticket go and back.」はなぜ間違いですか

正しくは「A return, please.」です。往復は return です。
